# 短视频《盯住中间的点 20 秒，黑白画会变彩色》

> 这张画一直是黑白的。

用户说"最近的这几个一点也不火 很烂"，这一支换了做法：不再是一分半的讲解，而是约 ⟨DUR⟩ 的**体验类**竖屏短视频——第一秒就让人参与，看的人自己的眼睛就是实验。做法上和以前哪里不一样、为什么，见 `脚本.md` 开头。

- **旁白有配音**：CosyVoice 3 合成的女声。盯点的 20 秒里不出字幕（字幕一出，眼睛就会去读，错觉就没了），屏幕上方一直写着"盯住中间的点 20 秒、看见不存在的颜色"；之后字幕按配音的逐字时间出现
- 角色台词出在游戏对话框里，不配音，只有打字音
- 有音效和环境声，**没有配乐**
- 角色用用户给的 12×8 像素小怪："你"在画里举着气球；讲原理时，眼睛里管颜色的三种细胞画成三个戴安全帽的小怪工人（管红、管绿、管蓝）

片子讲的是：

- **盯点（0~20 秒）**：一张颜色很怪的像素画（橙色的天、蓝色的太阳、紫色的草地），中间一个点。"盯住中间这个点，别眨眼……20 秒后，这张怪颜色的画会变成黑白的，可你看到的，会是彩色的。"
- **变成黑白画**：画面换成黑白，大多数人会看到蓝天、绿草、红房子。"其实，这张画一直是黑白的"——取色笔取出来，天、草、屋顶都是灰的；眨一下眼，颜色就没了。
- **为什么**：盯着一个颜色看久了，眼睛里管这个颜色的细胞会累；画面一变灰，累了的还没缓过来，没累的就占了上风：橙色的天看成蓝的，紫色的草看成绿的。颜色是眼睛自己补上去的（Zaidi 等 2012：残像的信号在视网膜里就产生了）。
- **没看到？**：手机亮度调到最高，盯住中间的点、别眨眼，从头再看一遍。看到彩色的，评论区扣 1。

## 怎么做出来的

流程、工具和踩过的坑见仓库根目录的 `做视频经验.md`（这种格式见第十九节）。

- **那张画**：`源码/props.js` 的 `drawPicture()` 在 108×192 的缓冲上画原图（大块的纯色，残像才明显；天和草地的亮度拉开，变黑白以后还分得清），`pictures()` 一个像素一个像素算出负片（红绿蓝都反过来）和黑白（按亮度换成灰）两个版本。
- **盯点的 20 秒**：`源码/scenes1.js` 的 `illusion()`。画面一动不动，只有点外面一圈进度走满；换图那一刻点和上方的字都不动。
- **旁白配音**：`源码/narrate_cosy.py`（CosyVoice 3 合成，FunASR 转写核对、逐字对时间）。盯点的几句按配音实测的长度排停顿："最后五秒"正好在换图前 5 秒。
- **声音**：`源码/audio.py` 用 numpy 合成：很轻的屋里底噪、最后几秒的心跳、换图那一下的"叮"、取色、眨眼、工人的"嘿咻"……短促的音效都放在旁白的停顿里（`工具/sfx_check.py` 查过）。
- **字体**：缝合像素字体 Fusion Pixel 12px、得意黑 Smiley Sans，均为 SIL OFL。构建时从 npm 下载并校验 sha256，不放进仓库。

## 重新生成

配音已经在 `源码/voice_cv3/` 里，不用再合成：

```bash
cd 源码
pip install numpy scipy
mkdir -p out && NODE_PATH=$(npm root -g) ./build.sh > out/build.log 2>&1   # 输出 out/黑白画变彩色.mp4 和 out/旁白文案.txt
```

预览某几个时间点的单帧：

```bash
NODE_PATH=$(npm root -g) node render.cjs preview 1,21,40 out/preview
```
