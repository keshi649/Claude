# 短视频《原始人为什么不近视？》

> 你的眼睛没有坏，它只是在等太阳。

一支约 2 分 26 秒的竖屏像素风科普短视频，讲**进化错配**里最多人有份的一种：近视。开头先推翻常识："原始人不近视，是因为没手机？"只对一半。六十年前的北极没有手机，因纽特人的近视率照样在一代人里从不到 3% 涨到一半以上。接着把眼球画成一处工地：眼球要边长边对焦，强光让视网膜释放多巴胺，像工头吹哨叫停施工。这条"光够亮就停工"的规则写于几十万年的户外生活，搬进教室后就失灵了：教室的真实亮度和日落时差不多，哨子不响，眼球就长过了头。最后用广州的随机对照实验和《近视防治指南》给出攻略：白天在户外待够两小时。

参考片用"餐厅经营游戏"讲 AI Agent。本片只借鉴它的讲法（游戏顶栏的资源读数、对话框、DEBUG 透视、VS 分屏、录像带回放、获得道具、系统报错），没有用参考片里的任何角色和素材。主角是用户提供的像素小怪，其余角色是它换颜色、换帽子，道具都是本片自己画的。

## 怎么做出来的

- **配音**：`源码/voice.py` 里有全部台词。旁白由 edge-tts（微软神经语音，云希）合成，按词边界算出每段字幕的起止时间，写进 `timeline.json` 和 `timeline.js`。角色台词是游戏对话框，不配音，占用的时间按字数估算。画面和声音都按这份时间轴对齐，改一句台词，前后的画面会自动跟着挪。
- **画面**：`core.js`（工具、像素缓冲、像素字、游戏界面组件、字幕）、`sprites.js`（像素小怪和各种道具）、`scenes1~3.js`（各场景）、`main.js`（场景编排、转场、顶栏读数、逐帧入口）。世界按"像素"画在小画布上再最近邻放大，所以每一帧的像素格都是整齐的。`frame(t)` 只依赖时间 t。`render.cjs` 用 Playwright 逐帧截图，交给 ffmpeg 编码。
- **声音**：`源码/audio.py` 用 numpy 合成 8-bit 配乐（带限方波、4-bit 三角波低音、噪声鼓），每一段换一种情绪（好奇、施工、草原、实验室、低保真教室、夜班、希望、阳光），外加几十个游戏音效：打字音、盖章、倒带、哨子、上课铃、获得道具等。旁白开口时，音乐自动压低约 10 dB。
- **字体**：缝合像素字体 Fusion Pixel 12px（界面、对话框）、得意黑 Smiley Sans（字幕），均为 SIL OFL。构建时从 npm 下载并校验 sha256，不放进仓库。

## 重新生成

```bash
cd 源码
pip install numpy scipy edge-tts
NODE_PATH=$(npm root -g) ./build.sh      # 输出到 源码/out/原始人为什么不近视.mp4，以及 …_无配音.mp4
```

预览某几个时间点的单帧：

```bash
NODE_PATH=$(npm root -g) node render.cjs preview 1.3,30,85 out/preview
```

配音缓存在 `源码/voice/`，不进仓库。只有缺失或改动过的句子会重新合成。
