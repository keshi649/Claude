# MV《鸳鸯戏》（像素小怪版）

一支 61 秒的横屏像素动画 MV，配《鸳鸯戏》DJ 版（词：家浚，曲：家浚 / 乐金震，编曲：DJ 哈市小鹏）。用户的要求：不参考之前的作品、前后不加配音、就是一支 MV、用像素小怪（12×8 的小怪模型）。横屏、"照歌词讲小怪的爱情"是用户选的。

**故事**：粉色的小娘子在烛灯下、西窗边等进京赶考的小情郎（原来橙色的那只小怪，戴书生巾）。举杯邀月、两地同一个月亮；回忆里他写字、弹琴、背着书箱走远；京城考场里他奋笔疾书。她研墨写信"盼君早归"，一滴墨晕开成水墨山水，鹧鸪叼着信飞走；月下弹琴，弦断了，断弦变成一根红线飞去京城。drop：金榜展开，第一名"克劳德"就是他，乌纱帽、大红花上身，骑白马游街；她甩着红袖跳舞，月洞门里出现他的身影。三巡酒、月上枝头、屋顶上依偎、满天孔明灯，池塘里的鸳鸯从一只变成两只。他把那根红线系在两人手上，春来花开、花轿过桥、梨花像雪落满楼、拜天地、夫妻对拜碰了头；最后雪落满头，两只小怪白了头。

## 怎么做出来的

- **歌词**：从用户发来的歌词视频（.mov）里读出 17 句歌词，按 10fps 量文字边缘得到每句出现的时刻。
- **逐字时间**（`align.py`）：Demucs 分人声，torchaudio 的 MMS 强制对齐（拼音按字母对齐），每句单独开窗、对两遍；频谱上核对过，挤错的 4 个字（"再""等""你""金"）按同节奏的句子和换气的凹口手工校正。写进 `lyrics.js`。
- **节拍**（`analyze.py`）：128 BPM，四拍一小节（1.875 秒）。底鼓每拍都有、分不出强拍，看鼓停的地方定的：加花落在小节最后一拍，breakdown（23.7 秒）和 drop（31.2 秒）都从强拍开始，所以第 0 小节在 1.194 秒。镜头基本一小节一个，切在小节线上。
- **画面**：全部是代码画的像素画。每帧先画在 480×270 的像素缓冲上（按像素填矩形、圆、多边形、抖动渐变，不用抗锯齿），再放大 4 倍；`frame(t)` 只依赖时间，`render.cjs` 用 Playwright 逐帧截图交给 ffmpeg，4 路并行。
  - `core.js`：像素缓冲、颜色、Bayer 抖动、像素字（Fusion Pixel 12px）和像素化的毛笔字（马善政楷书，取阈值）、光晕、暗角、副歌每拍的"泵"。
  - `monster.js`：像素小怪和行头：发髻步摇红袖襦裙、书生巾玉佩、乌纱帽大红花、凤冠霞帔、白头发白胡子、头顶落雪；路人的斗笠、小帽、双丫髻。
  - `world.js`：夜空、月亮、远山、水面倒影、飞檐翘角的屋顶、绣楼（西窗）、粉墙黛瓦、灯笼、梅树、柳树、鸳鸯、蜡烛、古琴、花瓣、雪、萤火虫；夜、灯会、春日、雪夜四套配色。
  - `shots1~3.js`：31 个镜头；`main.js`：镜头表、转场（像素溶解、闪白）、逐字歌词、水印、片尾、封面。
- **声音**（`mix.py`）：只有原曲，从 −7.5 LUFS 降到 −16 LUFS，不加配音、不加音效。
- **字体**（都是 SIL OFL）：缝合像素字体 Fusion Pixel 12px、马善政楷书。构建时下载并校验 sha256，不放进仓库。

## 重新生成

歌曲音频不放进仓库。把用户发来的视频里的音轨转成 `源码/audio/song.wav`：

```bash
cd 源码
mkdir -p audio && ffmpeg -i 原视频.mov -vn -c:a pcm_s16le -ar 44100 -ac 2 audio/song.wav
pip install numpy scipy
NODE_PATH=$(npm root -g) ./build.sh      # 输出 out/鸳鸯戏.mp4（超过 30 MB 会自动切成几段）
```

`timing.js`、`lyrics.js` 已经在仓库里。换了音源才需要重跑分析和对齐（要 demucs、librosa、torch、torchaudio、pypinyin、soundfile）：

```bash
python3 analyze.py     # 分人声、找节拍 → timing.js
python3 align.py       # 逐字对齐歌词 → lyrics.js（第一次会下载 MMS 对齐模型，约 1.2 GB）
```

预览某几个时间点的单帧：`NODE_PATH=$(npm root -g) node render.cjs preview 0,31.5,57.0 out/preview`
