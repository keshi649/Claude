# 短视频《原始人为什么不胖？》

> 你没那么馋，也没那么懒。

进化错配系列的第四支，接着《原始人为什么不近视？》《原始人为什么不用拔智齿？》《原始人为什么不过敏？》。一支约 2 分 22 秒的竖屏像素风科普短视频：**字幕就是旁白，但旁白不配音**；角色台词出在游戏对话框里，也不配音，只有打字音（和第一集一样）；有音效，**没有配乐**。

这一集先复盘了前三集：第一集数据好，第二、三集不行。量下来，差别主要在开头和"跟观众有没有关系"：第一集第 4 秒就推翻常识、主角是"你"、只给一条马上能照做的建议；后两集开头是静态画面，反常识的点到第 46~55 秒才出来，研究和外国名字也更多。完整的对比表和这一集的 7 处改动写在 `脚本.md` 开头。

片子一开头，"你"替观众说出最常见的答案："因为人家天天打猎、跑来跑去呗！"第 3.5 秒盖章"只对一小半"：坦桑尼亚的哈扎人今天还靠打猎采集过日子，男人一天走 11 公里，可一天烧掉的热量跟欧美城里人差不多。线索在"你"手里那袋薯片的背面：配料表。接着把身体画成一家公司：**财务部**管每天花多少能量，运动多了会在别处悄悄省回来；**采购部**还照着几十万年前的规矩办事，见到吃的先吃再说；野外的食物自带刹车，吃到一半**饱腹警报**就响了。如今很多食物是工厂设计出来的，又软又香、又甜又油，几口就下肚，警报还没响热量已经超了。美国国立卫生研究院让 20 个人住进实验室吃了 4 周：超加工那两周每天多吃 500 大卡、涨了将近 1 公斤，吃原样饭菜那两周反而掉了将近 1 公斤。最后给出一条能马上照做的攻略：多吃看得出原样的食物；配料表一长串、厨房里没有的少买；含糖饮料换成白水或茶；运动照样要做，但减肥主要靠吃。

## 怎么做出来的

- **旁白与时间轴**：`源码/narration.py` 里有全部旁白和对话框台词。每句旁白先用语音合成按正常语速（约每秒 5 个字）试读一遍，用逐词时间把字幕一段段排好；试读的声音不进成片。对话框按每秒 14 个字打出来，打完停 0.75 秒。结果写进 `timeline.json` 和 `timeline.js`，画面和声音都按它对齐。
- **画面**：`core.js`（工具、像素缓冲、像素字、游戏界面组件、旁白字幕、第一集样式的对话框）、`sprites.js`（像素小怪和行头，这一集加了胖一圈的身材、帽檐和头带）、`props.js`（原样食物和超加工食品、薯片袋、饱腹警报铃铛、跑步机、体重秤、货架、传送带、餐盘、篝火、猴面包树，以及财务部、采购部、哈扎猎人、上班族、"你"）、`scenes1~3.js`（各场景）、`main.js`（场景编排、转场、倒带 / 快进、逐帧入口）。`frame(t)` 只依赖时间 t。`render.cjs` 用 Playwright 逐帧截图，交给 ffmpeg 编码。
- **声音**：`源码/audio.py` 用 numpy 合成游戏音效（对话框打字音、盖章、计步器、跑步机、咔嚓、大口吃东西、铃铛"叮"、打呼、倒带 / 快进、外卖电动车……）和很轻的环境声（草原、城市、办公室、实验室、篝火）。按 EBU R128 定在约 −18 LUFS（和前几集"只有音效"版一致），最后做真峰值限幅。没有旁白配音，也没有配乐。
- **旁白文案**：`源码/export.py` 从时间轴导出 `旁白文案.txt`。
- **字体**：缝合像素字体 Fusion Pixel 12px（界面、对话框）、得意黑 Smiley Sans（字幕），均为 SIL OFL。构建时从 npm 下载并校验 sha256，不放进仓库。

## 重新生成

```bash
cd 源码
pip install numpy scipy edge-tts
NODE_PATH=$(npm root -g) ./build.sh      # 输出到 源码/out/：成片 mp4、旁白文案.txt；超过 30 MB 会自动切成几段
```

预览某几个时间点的单帧：

```bash
NODE_PATH=$(npm root -g) node render.cjs preview 2,20,90 out/preview
```
