# 短视频《超过的车，为什么总在红灯追上你？》

> 你一脚油门超过去的车，下一个红灯又停在你旁边——不是巧合，是数学。跑得快，不如赶得巧。

用户说"你自由发挥做一个短视频，不要参考之前的题材，我发抖音上"。这一支选了一个以前没做过的交通题，约 1 分 17 秒 的竖屏像素风科普短视频：

- **旁白有配音**：CosyVoice 3 合成的女声，字幕按配音的逐字时间出现
- 角色台词出在游戏对话框里，不配音，只有打字音
- 有音效和环境声，**没有配乐**
- 角色用用户给的 12×8 像素小怪："你"戴红领巾、开红车；"他"是蓝色、戴鸭舌帽（本片新加的造型）的同款小怪，开薄荷绿的车，手里总有个保温杯

片子讲的是：

- **开头**：红灯前，刚被你超过的那辆车慢悠悠开过来，停在你旁边，举起保温杯："又见面了～"——"巧合吧！"第 2.98 秒盖章"不是巧合"，配音接着念"不是巧合，是数学"。今年真有一篇论文（Boland 2026，《皇家学会开放科学》）算过这件事，名字取自恐怖片：你拼命跑，杀手慢慢走，却总能追上你（闪电一亮，原来是他和保温杯）。然后出一道选择题：过一个红灯，他追上你的可能有多大？A 一成 / B 四成 / C 九成。
- **你领先 10 秒，红灯一分钟**：你超过他领先 10 秒，可一个红灯动不动就是一分钟（两根条差 6 倍）；你停下来等，领先一点点被吃掉，红灯还没完他就到了——"清零"。
- **像转一次转盘**：你到路口时红绿灯在哪一秒全凭运气；转到红灯里、离变绿还不止 10 秒，他就追得上。红灯占一半，减掉这一小截：50% − 8% = 42%，选择题的答案是 B。
- **连过几个路口**：按论文的公式自己模拟了 40 万次：连过 3 个路口七成多，过 8 个差不多九成。
- **为什么总觉得甩不掉**：甩开他的时候，他被红灯拦在后面，你根本看不见；被追上的时候，他就停在你旁边。所以你记住的全是"又是你"。
- **红灯定律·开车卡**：
  - 冒险超车：平均只省几秒
  - 红灯越多：领先越容易清零
  - 下次超车：看他几个路口追上你
- **结尾**：傍晚的红灯前你们俩并排，绿灯一亮一起开走——转给开车最急的那个朋友：跑得快，不如赶得巧。

## 怎么做出来的

流程、工具和踩过的坑见仓库根目录的 `做视频经验.md`（这一支的做法在第二十二节）。

- **数字**：`源码/sim.py` 按论文摘要里的模型（固定周期的红绿灯，被追上的可能 = 红灯占比 − 领先秒数 ÷ 一轮秒数）模拟 40 万次，固定种子，几秒跑完。片中"42%""七成多""差不多九成"和地图上的 8 个百分比都是它打印出来的。
- **旁白配音**：`源码/narrate_cosy.py`。
  - CosyVoice 3（Fun-CosyVoice3-0.5B-2512 的 RL 版）零样本合成女声。
  - 每句用 FunASR 转写回来按拼音核对，读错就换随机种子重来。
  - 多音字（转、塞、片、数）看了音高曲线（`工具/tone_check.py`）；"恐怖片"的"片"第一版念平了，标成 piàn 换种子重合成。
  - 最后用时间戳模型给每个字对上时间。
- **时间轴**：`源码/narration.py` 里有全部旁白和对话框台词，读配音的逐字时间排字幕，写进 `timeline.json` / `timeline.js`。
- **画面**：`frame(t)` 只依赖时间 t；`render.cjs` 用 Playwright 逐帧截图，交给 ffmpeg 编码。
  - `sprites.js`：像素小怪。这一支加了鸭舌帽。
  - `props.js`：侧面看的街道（两车道、斑马线、带倒计时的红绿灯、店铺、行道树、长椅、消防栓、猫）、侧面的小汽车（窗里坐着开车的小怪）、保温杯、恐怖片的夜路、幸运转盘（6 像素一格逐格算颜色）、俯视的小车、软木板上的照片。
  - `scenes1~3.js`：各个场景。`scenes1.js` 的 `street()` 画一条街上的车和行人，开头、超车、开车卡、结尾都用它。
  - `core.js`、`main.js`：工具、字幕、对话框、转场、逐帧入口。
  - 关键的字都放在安全区里，字幕中心在 x=500。
- **声音**：`源码/audio.py` 用 numpy 合成。
  - 音效：盖章、贴纸、闪电和闷雷、低沉的"咚"、题板弹出、思考倒计时、倒带、转盘的呼呼声和棘轮、算式的"叮"、答对的升级音、快门、变灯的"嘀"、喇叭"嘀嘀"。
  - 环境声：白天的街、发动机（只留 220 Hz 以下）、恐怖片的风和低嗡、节目棚、傍晚的街和虫鸣。
  - 混音：说话时音效压低约 8 dB；短促的音效都放在字和字之间的空隙、句前停顿或句尾之后（渲染前用 `工具/sfx_check.py` 按配音的逐字时间查过）；成片约 −16 LUFS，做真峰值限幅。
- **旁白文案**：`源码/export.py` 从时间轴导出 `旁白文案.txt`。
- **字体**：缝合像素字体 Fusion Pixel 12px、得意黑 Smiley Sans，均为 SIL OFL。构建时从 npm 下载并校验 sha256，不放进仓库。

## 重新生成

配音已经在 `源码/voice_cv3/` 里，不用再合成：

```bash
cd 源码
pip install numpy scipy
mkdir -p out && NODE_PATH=$(npm root -g) ./build.sh > out/build.log 2>&1   # 输出 out/超过的车总在红灯追上你.mp4 和 out/旁白文案.txt
python3 sim.py                                                               # 片中的百分比
```

改了旁白要重新合成那几句（新容器先跑 `bash ../../工具/setup_tts.sh` 搭环境）：

```bash
/home/user/tts/venv/bin/python narrate_cosy.py /home/user/tts/CosyVoice /home/user/tts/models/CV3-RL e3 g1   # 只合成编号是 e3、g1 的两句
```

预览某几个时间点的单帧：

```bash
NODE_PATH=$(npm root -g) node render.cjs preview 2,20,40 out/preview
```
