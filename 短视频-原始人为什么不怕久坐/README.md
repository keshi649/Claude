# 短视频《原始人为什么不怕久坐？》

> 原始人也爱歇着，只是他们的腿，从来不会下班一整天。

进化错配系列的新一集，一支约 1 分 28 秒的竖屏像素风科普短视频：

- **旁白有配音**：CosyVoice 3 合成的女声，字幕按配音的逐字时间出现
- 角色台词出在游戏对话框里，不配音，只有打字音
- 有音效和环境声，**没有配乐**
- 角色用用户给的 12×8 像素小怪："你"戴红领巾；哈扎人是换了肤色、戴头带的同款小怪（他们是今天的人，不画成"原始人"）；系列里的卡通"原始人"戴骨头发饰。肌肉工人、椅子、沙发、工厂这些是本片自己画的

片子讲的是：

- **开头**：办公室里，"你"窝在椅子上刷手机："天天打猎，哪坐得住！"第 3.15 秒盖章"也歇 10 小时"。
- **证据**：科学家给哈扎人腿上绑了传感器，他们一天不走动将近 10 小时，跟你坐着的差不多；可他们很少"坐出病"，血脂、血糖都很健康。线索：秘密就在你屁股底下。
- **他们怎么歇**：哈扎人没有椅子，歇着的时候不少时间是蹲着、跪着。蹲着时腿上的肌肉还在上班；你往椅子上一靠，腿上的肌肉几乎全下班了。
- **肌肉一下班**：腿上的肌肉是身体里的用糖大户，它一下班，饭后的糖就在血里堵车。实验里每坐 20 分钟起来慢走 2 分钟，饭后血糖少涨了约四分之一。
- **进化错配**：椅子、沙发、汽车座椅让腿一下班就是一整天；哈扎人每天还要快走、干活一个多小时。一项 100 万人的研究：每天动够 1 小时，久坐多出来的风险基本就抵消了。
- **别让腿下班的小办法**：
  - 每坐 20 分钟，起来走 2 分钟
  - 坐着时，脚跟抬一抬
  - 快走、爬楼，每天攒够 1 小时

## 怎么做出来的

做法和《味道是舌头尝的，还是鼻子闻的？》一样，流程、工具和踩过的坑见仓库根目录的 `做视频经验.md`。

- **旁白配音**：`源码/narrate_cosy.py`。
  - CosyVoice 3（Fun-CosyVoice3-0.5B-2512 的 RL 版）零样本合成女声。
  - 每句用 FunASR 转写回来按拼音核对，读错就换随机种子重来。
  - 多音字再看一眼音高曲线（`工具/tone_check.py`）。
  - 最后用时间戳模型给每个字对上时间。
- **时间轴**：`源码/narration.py` 里有全部旁白和对话框台词，读配音的逐字时间排字幕，写进 `timeline.json` / `timeline.js`。
- **画面**：`frame(t)` 只依赖时间 t；`render.cjs` 用 Playwright 逐帧截图，交给 ffmpeg 编码。
  - `sprites.js`：像素小怪。这一集加了蹲着、跪着、坐在地上三种姿势，和踮脚跟。
  - `props.js`：办公室、办公椅、沙发、汽车座椅、草原营地、传感器、肌肉工人（上班戴安全帽、下班戴睡帽打呼）、肌肉出力表、血管里的糖块车和肌肉工厂、血糖曲线、天平、一格格的小人。
  - `scenes1~3.js`：各个场景。
  - `core.js`、`main.js`：工具、字幕、对话框、转场、逐帧入口。
  - 关键的字都放在安全区里，字幕中心在 x=500。
- **声音**：`源码/audio.py` 用 numpy 合成。
  - 游戏音效：办公椅吱呀、盖章、传感器"嘀"、肌肉工厂的机器声、卷帘门、糖块车按喇叭、打呼、勾选……
  - 很轻的环境声：办公室、草原和篝火、城市。
  - 混音：
    - 说话时音效压低约 8 dB。
    - 短促的音效不压在旁白字头上（渲染前用 `工具/sfx_check.py` 按配音的逐字时间查过）。
    - 成片约 −16 LUFS，做真峰值限幅。
- **旁白文案**：`源码/export.py` 从时间轴导出 `旁白文案.txt`。
- **字体**：缝合像素字体 Fusion Pixel 12px、得意黑 Smiley Sans，均为 SIL OFL。构建时从 npm 下载并校验 sha256，不放进仓库。

## 重新生成

配音已经在 `源码/voice_cv3/` 里，不用再合成：

```bash
cd 源码
pip install numpy scipy
mkdir -p out && NODE_PATH=$(npm root -g) ./build.sh > out/build.log 2>&1   # 输出 out/原始人为什么不怕久坐.mp4 和 out/旁白文案.txt
```

改了旁白要重新合成那几句（新容器先跑 `bash ../../工具/setup_tts.sh` 搭环境）：

```bash
/home/user/tts/venv/bin/python narrate_cosy.py /home/user/tts/CosyVoice /home/user/tts/models/CV3-RL s2 n3   # 只合成编号是 s2、n3 的两句
```

预览某几个时间点的单帧：

```bash
NODE_PATH=$(npm root -g) node render.cjs preview 2,20,90 out/preview
```
