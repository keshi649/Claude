# 短视频《刚吃完饭，怎么又饿了？》

> 不是没吃饱：是大脑没记住你吃过。

用户说"这个睡眠的有意思，在做一个关于饮食的吧，依旧要反常规"。约 ⟨DUR⟩ 的竖屏像素风科普短视频：

- **旁白有配音**：CosyVoice 3 合成的女声，字幕按配音的逐字时间出现
- 角色台词出在游戏对话框里，不配音，只有打字音
- 有音效和环境声，**没有配乐**
- 角色用用户给的 12×8 像素小怪："你"戴红领巾；大脑里记账的小人戴绿色遮光帽檐和眼镜；馋虫是本片画的
- 一个比喻讲到底：大脑里有本账，吃饭时记账的小人也在看手机，"午饭"那行就空着，馋虫就压不住

片子讲的是：

- **开头**：中午的办公桌，外卖吃完了，"你"还在刷手机，饱腹度一下掉光："刚吃完饭，怎么又饿了？"——"肯定没吃饱！"第 ⟨stamp⟩ 秒盖章"大脑忘了"。失忆的人吃完午饭，不到半小时再端一份，照样又吃，多半还吃了第三顿。你没失忆，可吃饭时盯着手机，大脑也没记下这一顿。怪事在后头：多吃的，不在这一顿，在下一顿。
- **实验**：英国科学家让两组人吃一样的午饭，一组边吃边玩电脑游戏、一组专心吃；半小时后尝饼干，边玩的吃了 52 克，专心的只吃了 27 克，还觉得没那么饱、记不清吃了啥。饱不饱，不光看胃：大脑里还有本账，记着"刚吃过"，才压得住馋。
- **反过来也灵**：想吃零食前，先花 5 分钟回想中午吃了什么，就会少吃一些。——"中午……吃了啥来着？"
- **攻略卡**：吃饭时放下手机（刷剧、打游戏都算）；想吃零食前，先回想上一顿（吃了什么，什么味道）。
- **结尾**："原来我不是馋，是没记住！"——"评论区说说：你吃饭离得开手机吗？"

## 怎么做出来的

流程、工具和踩过的坑见仓库根目录的 `做视频经验.md`。

- **旁白配音**：`源码/narrate_cosy.py`（CosyVoice 3 合成，FunASR 转写核对、逐字对时间）。
- **画面**：`frame(t)` 只依赖时间 t；`render.cjs` 用 Playwright 逐帧截图，交给 ffmpeg 编码。
  - 背景画在 216×384 的像素缓冲上、放大 5 倍；小怪按 15 倍画，和背景的像素对齐。
  - `props.js`：中午的办公室（窗外的城、百叶窗、挂钟、便利贴、隔板后探头的同事、绿植）、办公桌（显示器、键盘、外卖盒、奶茶）、拿在手里的手机、饱腹度、大脑里的账本和记账的小人、馋虫、明亮的餐厅、餐盘、心理学实验室、晚上的家；米饭、青菜、鸡腿、饼干、薯片等食物小图标。
  - `sprites.js`：像素小怪（这一支用了遮光帽檐、眼镜、手机、嚼东西的嘴）。
  - `scenes1~3.js`：各个场景；封面在 `scenes1.js` 的 `coverArt`。
- **声音**：`源码/audio.py` 用 numpy 合成：肚子"咕～"、盖章、咔嚓一口薯片、往上长的滑音、"叮"、"噗"、弹出；办公室、明亮的餐厅、实验室、大脑里、晚上的家的环境声。短促的音效都不压旁白的字头（`工具/sfx_check.py` 查过）。
- **字体**：缝合像素字体 Fusion Pixel 12px、得意黑 Smiley Sans，均为 SIL OFL。构建时从 npm 下载并校验 sha256，不放进仓库。

## 重新生成

配音已经在 `源码/voice_cv3/` 里，不用再合成：

```bash
cd 源码
pip install numpy scipy
mkdir -p out && NODE_PATH=$(npm root -g) ./build.sh > out/build.log 2>&1   # 输出 out/刚吃完饭怎么又饿了.mp4 和 out/旁白文案.txt
```

预览某几个时间点的单帧：

```bash
NODE_PATH=$(npm root -g) node render.cjs preview 1,20,45 out/preview
```
