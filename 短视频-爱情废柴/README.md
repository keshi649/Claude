# MV《爱情废柴》复古 RPG 版

> 如果失恋是一局 RPG：存档 1"两个人"读不出来了，职业从"恋人"变成"废柴"，Boss 叫「你的笑容」，Lv.99。

一支 4 分 39 秒的横屏像素动画 MV，配用户发来的周杰伦《爱情废柴》。没有配音、没有音效，只有原曲，成片和歌一样长。

**怎么定下来的**：用户先要画风的想法（"先告诉我想法 不要做"），我给了四个方向；用户说"各个方向你画几帧我先看看再决定"，四个方向共画了九张样张（`样张/`）；
看到一半用户说"你自己画人物吧 这个像素小怪太丑了"，人物全部换成自己画的一男一女；最后用户选了"复古 RPG"。

**设定**（详见 `脚本.md`）：把"爱情废柴"当成游戏职业，整支 MV 是一局 16 位风格的 RPG。歌词不另加字幕，全部打在游戏的对话框里，唱到哪个字打出哪个字；
歌词里说什么，游戏里就真的发生什么——"要不要拍成 MV"是系统菜单里的一项，"剧情是你在写"是剧本编辑器的编剧栏，"哭个痛快"是一个会回血的技能，"眼泪打转 转不回来"是一只倒不回去的钟。

- **开头 15 秒**：显像管开机 → 片名四个字砸下来 → 读取存档 1"两个人"失败 → 七段回忆闪过 → "「你」离开了队伍"，职业：恋人 → 废柴 → 第 12 章 圣诞节。
- **三遍副歌三个意思**：第一遍是 Boss 战，一路挨打，Game Over；第二遍她先手逃走，他一直点"再来一次"；第三遍不打了，办一场演唱会，承认自己是废柴（升级了），存档。
- **伏笔**：读不出来的存档 1、队友栏的"空"、道具栏里的半张合照、丢不掉的红围巾、被八倍速快进的回忆、散场时回头的白帽子……对照表在 `脚本.md`。片尾："？？？ 请求加入队伍。"

## 怎么做出来的

- **一套像素网格**：整片画在 480×270 上（一个像素 = 成片里 4×4），出片时最近邻放大到 1920×1080。
- **画面和光晕分两层**：浏览器每帧出一张 480×540 的图，上半张是像素画面，下半张是"会发光的东西"（灯、窗、火、烟花、光束）。ffmpeg 里把上半张硬放大，下半张模糊后 screen 叠回去，再加暗角——像素边是硬的，光是软的。
- **逐帧只看时间**：`frame(t)` 只依赖 t，无头 Chromium 4 路并行，8378 帧约半分钟画完；时间主要花在最后的 1080p 编码上（约 8 分钟）。
- **人物**（`chars.js`）：`chibi()` 按身高现画的两头身像素人——28 像素高的路人、110 像素的 Boss、170 像素的大特写是同一个函数，细节跟着身高加。眼睛 9 种、嘴 5 种、举手、拿麦、走路、坐、背影、围巾飘、积雪、眼泪、侧光。
- **歌词时间**（`kara.py`、`kara2.py` → `timing.json`）：原 MV 带卡拉 OK 字幕（唱过的字变蓝）。逐帧数上下两行蓝色像素擦到了哪一列，60 段正好对上 60 个短句，算出每个字开唱的时刻（精度一帧）。
- **节拍**：148 BPM。主歌每小节一个动作，镜头按歌词切；间奏每两小节一段回忆。
- **声音**：只有原曲，线性降 2.2 dB（−13.8 → −16 LUFS），不剪不挪。

## 重新生成

歌曲不放进仓库。把用户发来的原 MV（960×544，279.3 秒）放到 `源码/audio/song.mp4`：

```bash
cd 短视频-爱情废柴/源码
python3 kara.py audio/song.mp4 out/kara_raw.json && python3 kara2.py   # 可选：重新量歌词时间（timing.json 已在仓库里）
bash build.sh                                                           # 产物 out/爱情废柴.mp4
node render.cjs cover out/cover.png                                     # 封面
node render.cjs sheet out/看.png 4 15 16.5 67.6 88.6                    # 预览：几个时刻拼一张图
```

构建的时候不要改 `build.sh`：bash 是边读边执行的，改了会从半行开始读。

## 自查

方法论的自查表是给讲解类短视频的（盖章、"你"的次数、攻略卡、研究出处），MV 用不上；下面是 MV 能量的几项。

| 项 | 结果 |
|---|---|
| 时长 | 279.27 秒，和原曲一样长；不加画外音、不另加片尾时间 |
| 前 20 秒切镜头 | 分镜里 14 次（开机 → 片名 → 读档 → 前情提要里 7 段之间 6 次 → 离队 → 章节卡 → 圣诞镇 → 过街）；`measure.sh` 量到 13 次 |
| 响度、真峰值 | −16.0 LUFS，−1.4 dBTP |
| 大小 | 66.9 MB，只发完整版 |
| 每秒一帧通看 | 做了两遍（`out/rev/`）：第一遍后把右侧的数字面板往左挪、给两个偏空的界面镜头加了内容、去掉压住脚的回合条 |
| 安全区 | `safe_check.sh` 抽了 12 帧（片名、圣诞镇、剧本、哼歌、盖章、音游、KTV、封麦、升级、钟楼、存档、片尾）：歌词窗、片名、盖章、数字都在安全区里；右侧按钮区里只有队友栏、小地图、时钟这类装饰 |
| 四边黑边 | `edge_check.py`：只有开机那一帧和几个转黑转场的瞬间 |
| 水印、片尾 | 右上角"甜菜"全程（开机、片尾彩蛋两个镜头除外，它们画面里本来就有"甜菜"）；片尾"甜菜 出品"、"画面由 Claude 用代码生成 · AI 生成内容" |
| 不出现的东西 | "点起一根烟"画成烟花棒；没有抽烟的画面 |
