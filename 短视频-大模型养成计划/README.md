# 短视频《大模型养成计划》

> AI 为什么会一本正经地胡说八道？——我们亲手养一只 AI 看看。

一支 3 分 43 秒的竖屏科普短视频，做成像素风的养成游戏。仿照的是一支讲 Agent / MCP / Skill 的「AI 美食街」短视频：把模型拟人化、游戏 HUD、对话框、DEBUG 线框视角、旁白 + 字幕，一路玩梗。

开场是那个经典翻车：问 AI「林黛玉倒拔垂杨柳是怎么回事」，它真能编出一整段。它在骗你吗？不是，它只是被养成了这样。然后从一颗蛋开始养：

1. **出生**：脑子里是上千亿个随机数，开口就是「锟斤拷烫烫烫」，跟猫踩键盘差不多。
2. **第一课 · 预训练**：规则只有一条，猜下一个字。床前明月——饼？挨罚。光！奖励。然后把整个互联网喂给它：十几万亿个 token，顺便学会了「家人们谁懂啊」。
3. **基座模型**：问它「今天天气怎么样」，它回「明天天气怎么样」——它在接龙。
4. **支线 · token**：它看到的不是字，是一块一块的 token。所以 strawberry 里数出两个 r，9.11 比 9.9 大。
5. **第二课 · 微调**：猫老师教它别接龙了，你是个助手。它学会了一句经典台词：「作为一个 AI 语言模型……」
6. **第三课 · 人类打分**：人挑更好的回答。可人类爱听好话——「您说得太对了！」这毛病叫谄媚，2025 年真有一次更新因此被紧急撤回。
7. **脑内视图**：它见过林黛玉，也见过倒拔垂杨柳，本能是把话接下去；脑子里没有「查证」按钮，训练时蒙一个还可能得分。这就是幻觉。
8. **修好之后**：配上搜索、学会说「我不确定」，林黛玉终于不拔树了（鲁智深扛着树从后面路过）。
9. **毕业典礼**：DeepSeek、ChatGPT、Claude、Gemini、豆包、Kimi、通义千问、Llama、Grok 同届毕业，老师不同，脾气也不同。

结尾盖章：「以上内容由 AI 生成，仅供参考。」

## 怎么做出来的

- **台词与配音**：`源码/script.py` 里是全部台词，分旁白、「你」、「小模」三个说话人。它用离线 TTS（Kokoro v1.1-zh，经 sherpa-onnx 调用）逐句合成配音，量出每句的实际长度，排出每一幕、每一句、每个音效提示点的时间，写进 `timeline.js`（给画面）和 `timeline.json`（给声音）。「小模」的声音是把一个女声升调 3 个半音。每句配音都用语音识别（SenseVoice）回听核对过。
- **画面**：所有像素画都画在一张 270×480 的小画布上，再放大 4 倍，像素才是方的；文字和 UI 面板画在 1080×1920 的高清层。`core.js` 是像素画工具（扫描线画圆、多边形、Bayer 抖动渐变）、精灵缓存与自动描边、字幕、对话框、HUD、属性条、印章；`sprites.js` 用一个 Q 版小人模板画出全部角色（发型、发色、眼睛、衣服、配饰各不相同）和道具，没有任何外部图片；`scenes1.js`～`scenes3.js` 是各幕；`main.js` 负责 HUD 状态、像素方块转场和逐帧入口 `frame(t)`。`render.cjs` 用 Playwright 逐帧截图交给 ffmpeg。
- **声音**：`源码/audio.py` 用 numpy 合成 8-bit 配乐（方波琶音与旋律、三角波低音、噪声鼓），每一幕一种曲风：开场是安静的小调琶音，预训练是轻快的 C 大调，支线是探险曲，人类打分是带摇摆的综艺味，脑内视图是压暗的合成器琶音，毕业典礼是号角。音效有发送消息、破壳、乱码、猫叫、答错的蜂鸣、答对的叮、翻书、计数器、显卡起火、网络梗气泡、刀切 token、上课铃、升级、投币、鼓掌、警报、故障、盖章。
- **字体**：思源黑体 Noto Sans SC（字幕、标题）和融合像素字体 Fusion Pixel Font 12px（UI、对话框），都是 SIL Open Font License，构建时自动下载，不放进仓库。像素字体在 npm 上只有按 Unicode 区块切开的 WOFF2，`fonts.py` 把简体中文的 78 个分片合成一个 TTF。
- **事实**：每个数字和梗的出处与边界见 `脚本.md` 的「关于事实与边界」。

## 重新生成

```bash
cd 源码
pip install numpy scipy soundfile sherpa-onnx fonttools brotli huggingface_hub
NODE_PATH=$(npm root -g) ./build.sh      # 输出到 源码/out/大模型养成计划.mp4
```

第一次会下载 TTS 模型（约 400 MB）。4 核机器上画面 4 路并行渲染约 4 分钟。其他用法：

```bash
NODE_PATH=$(npm root -g) node render.cjs preview 20,95,172 out/preview   # 若干时间点的单帧 PNG
NODE_PATH=$(npm root -g) node render.cjs cover 24.5 ../封面.jpg           # 不带字幕的封面
NODE_PATH=$(npm root -g) node render.cjs check                           # 每帧都跑一遍，只查报错
```
