# 短视频《地球的尺寸》

> 你手里的每一把尺子，都藏着地球的尺寸。

一支 4 分 30 秒的横屏科普视频，讲人类怎样一步步量出地球有多大。它仿照的是 Iwanau 的《运气的形状》（讲概率论的诞生）：暖黑底、金色年份、红色文献印章，没有配音，字幕和配乐讲故事；每一章用一个年份、一个人、一次具体的测量讲清一个道理。

开场先抛出一个可疑的整数：绕地球一圈约 40 000 公里，北极到赤道正好 10 000 公里，「像是有人故意凑的」。——确实有人。接着从一根木棍讲起：

1. **公元前 240 · 埃拉托色尼**：赛伊尼的井底见日，亚历山大的木棍有 7.2° 的影子。7.2° 是一圈的 1/50，乘以 5000 斯塔德，得到 25 万斯塔德。
2. **724 · 南宫说与一行**：河南平原上的四根八尺表，526 里影子只差二寸多，老说法「千里差一寸」被史书判了两个字：**妄矣**。每往北 351 里 80 步，北极高一度。
3. **1615 · 斯涅尔 / 1669 · 皮卡尔**：只量一条边，其余全靠角度，33 个三角形连成一条链；再给测角仪装上望远镜，一度子午线是 57 060 托阿斯。
4. **1736 · 橘子还是柠檬**：牛顿说地球是扁的，卡西尼说是长的。法国派远征队去北极圈和赤道，结果越往北一度越长，牛顿赢了。伏尔泰写了两行诗挖苦凯旋的莫佩尔蒂。
5. **1792 · 米**：大革命时期各地的尺子长短不一，科学院决定把北极到赤道的子午线分成一千万份，一份叫一米。德朗布尔和梅尚量了七年，梅尚到死都藏着一个对不上的数据，米原器最后也短了 0.2 毫米。

结尾解开开头的谜：1983 年起米改由光速定义，长度却特意保持不变。所以绕地球一圈刚好约 4 万公里，不是巧合，是人类先量了地球，再用地球做了尺子。子午圈被拉直，变成一把尺子。

## 怎么做出来的

- **字幕与时间轴**：`源码/script.py` 里是全部字幕，每条写明显示几秒。它算出每一幕、每条字幕的起止时间，写进 `timeline.js`（给画面）和 `timeline.json`（给声音）。改一句字幕的时长，后面的画面和音效会自动跟着挪。
- **画面**：`core.js` 负责背景（暗金底、固定不动的纸面颗粒、浮尘；颗粒要是逐帧变化，成片会大到放不进仓库）、左上角会滚动的年份、右上角的文献卡和「文献」红印、底部逐字浮现的字幕和水印；`scenes1.js`～`scenes3.js` 分别是开场与第一章、第二三章、第四五章与结尾；`main.js` 负责幕间溶解和逐帧入口。`frame(t)` 只依赖时间 t，`render.cjs` 用 Playwright 逐帧截图，再交给 ffmpeg 编码。
- **声音**：`源码/audio.py` 用 numpy 合成全部配乐和音效。每章一种织体：开场是钟摆嘀嗒和稀疏的钢琴，第一章是竖琴琶音，唐代是古琴似的五声拨弦，荷兰是大键琴，远征是定音鼓脉冲，大革命是 C 小调钢琴，结尾落回 F 大调。音效包括木棍落地、井底的亮光、×50 的计数嘀嗒、四根表立起的木声、「妄矣」盖章、33 个三角形的音阶、铂金尺的长鸣、梅尚的笔声等。
- **字体**：思源宋体 Noto Serif SC、Cormorant Garamond、Cinzel，都是 SIL Open Font License，构建时自动下载，不放进仓库。Cormorant 默认是旧式数字，`fonts.py` 用 fonttools 把它的齐线数字写进 cmap，年份才和参考片一样整齐。
- **事实**：每个数字的出处和边界见 `脚本.md` 的「关于事实与出处」。示意性的图形（北极星的角度差、子午椭圆的扁度、三角链的点位、法国地图、笔记的笔迹、各地尺子的长短）在画面上都标了「示意」或「已放大」。

## 重新生成

```bash
cd 源码
pip install numpy scipy fonttools
NODE_PATH=$(npm root -g) ./build.sh      # 输出到 源码/out/地球的尺寸.mp4
```

4 核机器上大约 15 分钟（画面 4 路并行渲染约 12 分钟，最后编码约 3 分钟）。预览某几个时间点的单帧：

```bash
NODE_PATH=$(npm root -g) node render.cjs preview 20,28,98 out/preview   # 带字幕的单帧 PNG
NODE_PATH=$(npm root -g) node render.cjs cover 29 ../封面.jpg            # 不带字幕的封面
```
