# 《还是分开》Claude 版歌词 MV 脚本

- **规格**：横屏 1920×1080，30fps，72 秒（片头 2 秒点烟 + 歌曲片段 65.1 秒 + 尾声 4.9 秒）
- **歌曲**：张叶蕾《还是分开》，从"你掐灭没吸的烟"唱到"最后却看着车门在我面前，用力地关"
- **主角**：Clawd 是"我"，照着发来的模型图画：身体 8×6 格，两侧手臂 2×2，四条腿，1×1 的方眼睛。"你"是一只鼠标指针，也就是屏幕那头的用户。它没有脸，只会走，而且箭头永远朝一个方向，不回头
- **一句话**：一首分手歌，在 Claude 这里是字面意思。烟头是 Claude 转圈的那颗 ✻，你按了 Esc；你在输入框里敲了 /exit；你的结局跑了 99 遍测试，全是"分开"，0 个例外。最后车门关上，会话结束。Clawd 坐在路灯下说："……那我再等一下下。"
- **配色**："我"这个字永远是 Clawd 的暖橘色，"你"永远是冷蓝色

## 从参考片学了什么，没照抄什么

参考片是一支 Clawd 歌词 MV（喻言《蠢货》那一段，水印是「知洲」）。这次只学方法，场景全部重新编。

学到的方法：

1. **逐字踩点**：每个字在开口的那一刻砸下来，从大到正常，带一点模糊。重点字另外处理：挤出厚度、盖章、变色、发抖。
2. **歌词按字面拍**：每一句都变成一个画面梗，而且多半是电脑和 Claude Code 的梗。
3. **Clawd 不说话**：表情全靠那两只方眼睛，哭、慌、眯眼、X 眼、爱心眼。
4. **四角固定的 HUD**：左上歌名，右上小节数和四拍灯，左下时间码，底部进度条，右下水印。水印从"知洲"换成了 **"甜菜"**，旁边那串飘起来的 z 换成了一颗会跟着拍子点头的像素小甜菜。
5. **深浅交替**：深色点阵底和浅色纸面底轮流出现，换场落在乐句上，副歌每小节强拍镜头轻轻推一下。

刻意没照抄的：

- 参考片开头是在终端里敲 `claude` 启动；这支的开头是一根烟，烟头就是 Claude 转圈的那颗 ✻。
- 参考片的 Yes/No 确认框、一摞报错窗口、封号横幅、魔镜、满屏实例，这支都没用。
- 参考片的结尾是 `claude.instances = 1,048,576` 加一句俏皮话；这支的结尾是会话结束，路灯下只剩 Clawd 一个。

## 歌曲结构（`源码/analyze.py` 算出来的）

- 节拍：134.0 BPM，全曲没有漂移。和弦是 IV–V–iii–vi（C# 大调：F#–G#–Fm–A#m），每小节换一个和弦，所以第 0 小节的强拍定在 1.188 秒。一小节 = 1.791 秒。
- 0–33.9 秒是主歌（"你掐灭没吸的烟"到"竟是空白"），28–30.6 秒和 32–34.5 秒各有一小段只剩伴奏。
- 34.5 秒进副歌（"我和你猜了又猜"），一直唱到 64.5 秒"关"字拖完。原片段在 65.1 秒被剪断。
- 逐字时间：Demucs 分出人声 → 三遍 Whisper（small / medium / large-v3）和原视频字幕交叉核对歌词 → wav2vec2 中文模型 CTC 强制对齐 → 吸附到 ±90 ms 内的人声 onset。挤在一起的字（间隔不到 75 ms）按十六分音符摊开。每个字比开口早 0.05 秒（1.5 帧）弹出，看起来才是"踩在"字上。

## 跟着音乐动的东西

- **每两拍点一次头**：Clawd 的身体起伏按两拍一次（`bob`）。
- **重拍**：副歌（34.5–62.7 秒）每小节强拍，整个镜头轻轻推一下。
- **HUD**：小节数从第 0 小节的强拍开始数，四拍灯一拍亮一格；时间码是歌曲时间。
- **换场**都落在乐句之间，大多在这一句第一个字之前 0.15–0.25 秒。
- **震屏和闪白**落在"灭""抓""喊""决定""分""吵""关"这些字上。

## 声音

- 原曲片段原样使用，不做改动。开头 15 毫秒淡入防爆音；原片段在 65.1 秒被硬剪断，所以提前 0.5 秒淡出。
- 片头 2 秒是程序合成的：打火机"咔嚓"两下、火苗窜起来的一口气、烟头细细的噼啪声、一点房间底噪。
- 尾声补上：车开走的低沉引擎声（越开越远）、夜里的虫鸣、终端打字声、气泡弹出的"啵"、Clawd 那句话的打字声。
- 两遍 loudnorm，用线性增益把整体响度统一到 −14 LUFS。
