# MV《失眠飞行》

> 凌晨三点，你也还没睡吗？

一支 3 分 31 秒（211.5 秒） 的横屏动画 MV，配《失眠飞行》（接个吻，开一枪 / 沈以诚 / 薛黛霏）整首。故事、角色、场景都是原创的，画面全部由代码逐帧画出来。

**故事**：两个分开了的人，都在凌晨三点睡不着。

- **女声段落**：她的"失眠飞行"。床飞出窗外，去收集氧气，掉进雾里，坠进心形的城市。
- **男声段落**：他的现实。又到了给她热牛奶的时间，电影还停在 1:12:05，镜子里一圈黑眼圈，抱着她送的那只小怪玩偶。
- **第一遍副歌**：她的梦。和他一起闯进森林、潜入海底、看日出到日落、穿过格林威治和时间。在钟表隧道里两人的手松开了，她在人海里找到他、抱住他，他化成了光点。
- **第二夜**：她的小指上多了一根红线，他的玩偶活了过来，拉着他飞出窗外。
- **第二遍副歌**：两个人同时在梦里飞，却各在半边画面，在人海里背对背擦肩而过。
- **间奏**：两只像素小怪玩偶从两扇窗里飞出来，沿着红线搭起一座像素的鹊桥。
- **桥段**：白天的雨。他路过那家咖啡店，停下来等；打出"对不起"又删掉；想起拉过钩"一起去看日出"。他抬头闭眼，雨停在半空，变成了星星。
- **最后一遍副歌**：换他飞。他穿过森林和海底，沿着鹊桥跑过日出日落，所有的钟停在 3:47。人海往两边分开，他抱住了她。
- **歌停了**：凌晨 3:47，两部手机同时亮起，两个人在同一秒发出了"睡了吗？"。

画面上的歌词按演唱**逐字亮起**（女声的句子带粉色的光，男声带蓝色的光），换场都落在小节线上。开头和结尾两句画外音用 CosyVoice 3 配了女声。玩偶用的是甜菜之前视频里的 12×8 像素小怪。

## 怎么做出来的

- **歌曲分析**
  - `源码/analyze.py`：Demucs 分出人声和伴奏；在 onset 包络上搜出节拍（94.995 BPM，全曲不漂移），按伴奏低频定强拍；人声、伴奏的音量包络和每拍力度写进 `timing.js`。按音高分出男女声：女声唱主歌 A、前两遍副歌和"我想和你"，男声唱主歌 B、桥段和最后一遍副歌，故事就按这个分。
  - `源码/align.py`：歌词行从用户发来的抖音视频画面里读出来。逐字时间用 torchaudio 的 MMS 强制对齐（拼音按字母对齐）：主歌两遍对齐后取平均，副歌三遍逐句开窗对齐取中位数，写进 `lyrics.js`。
- **画面**：`frame(T)` 只依赖时间，`render.cjs` 用 Playwright 逐帧截图交给 ffmpeg，4 路并行渲染。
  - `core.js`：工具、缓动、噪声、颜色、文字、音乐包络、纹理（星空、银河、雾、云、颗粒、暗角）、月亮、流星、雨、漂浮的光点。
  - `chars.js`：角色。二维骨骼的侧身（头、躯干、胳膊、腿，按姿势表摆动作，算得出手在哪儿，好让两个人手拉手）、正面半身、背影，像素小怪玩偶和它的像素形态。每个角色先画到离屏画布上，再按场景打光：环境色染色、背光一侧压暗、迎光一侧描亮边。
  - `world.js`、`world2.js`：城市（三层楼，窗户和光晕在开头生成一次）、屋顶、心形的城市、霓虹街、湖、玄关；会发光的森林、海底（光柱、水母、鲸）、云海上的一天、格林威治天文台、钟表隧道、教堂、广场和人海。
  - `props.js`、`props2.js`：她的卧室、飞起来的床、泡泡和罐子、纸条、他的厨房、笔记本电脑、镜子、拍立得；红线、河和桥、蒲公英、高架桥、伞、衣柜、起雾的窗、手机聊天界面、书桌。
  - `scenes1~6.js`：60 个镜头，按小节排好。
  - `test.html` + `test.js`：角色测试页，各种姿势、正面半身、走路跑步、玩偶摆在一张图上看（`PAGE=test.html node render.cjs preview 0,1,2 out/test`）。
  - `main.js`：镜头表和转场（冲进去、甩镜头、穿云、闪白、水波、漏光、虚化、红蓝错位……）、逐字亮起的歌词、水印、柔光、调色、暗角、颗粒、封面。
- **声音**：`源码/mix.py`。原曲剪掉开头的数字静音原样使用；两句画外音（`narrate_cosy.py`，CosyVoice 3 + FunASR 核对）；numpy 合成的音效和环境声，有人声时让开；成片 −16.1 LUFS，真峰值 −1.0 dBTP。
- **字体**（都是 SIL OFL）：霞鹜文楷、思源宋体、思源黑体、龙藏体、志莽行书。构建时下载并校验 sha256，不放进仓库。

## 重新生成

歌曲音频不放进仓库。把整首歌（3:26.9，开头有 1.4 秒静音）转成 `源码/audio/song.wav`：

```bash
cd 源码
mkdir -p audio && ffmpeg -i 你的音频.m4a -vn -ac 2 -ar 44100 audio/song.wav
pip install numpy scipy
NODE_PATH=$(npm root -g) ./build.sh      # 输出 out/失眠飞行.mp4，超过 30 MB 再切成 out/失眠飞行_1.mp4 …
```

`timing.js`、`lyrics.js` 和 `voice_cv3/` 已经在仓库里。换了别的音源（比如开头的静音长度不一样）才需要重跑分析和对齐，这一步要 demucs、librosa、torchaudio、pypinyin：

```bash
pip install demucs librosa torch torchaudio pypinyin soundfile
python3 analyze.py     # 分人声、找节拍 → timing.js
python3 align.py       # 逐字对齐歌词 → lyrics.js（第一次会下载 MMS 对齐模型，约 1.2 GB）
```

画外音要重新合成的话，先在后台跑 `bash ../../工具/setup_tts.sh`，再：

```bash
/home/user/tts/venv/bin/python narrate_cosy.py /home/user/tts/CosyVoice /home/user/tts/models/CV3-RL
```

预览某几个时间点的单帧（成片时间）：

```bash
NODE_PATH=$(npm root -g) node render.cjs preview 0,3.9,44.5,207 out/preview
```
