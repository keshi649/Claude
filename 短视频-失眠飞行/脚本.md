- **规格**：横屏 1920×1080，30fps，3 分 31 秒（211.5 秒）（整首歌 3:25.6，剪掉开头 1.3 秒的数字静音；歌唱完以后接 3.4 秒尾声和 2.5 秒片尾卡）
- **歌曲**：《失眠飞行》接个吻，开一枪 / 沈以诚 / 薛黛霏，整首（用户发来的音频，3:26.9）
- **一句话**：两个分开了的人，都在凌晨三点睡不着。女声段落是她的"失眠飞行"——床飞出窗外，梦里和他一起飞；男声段落是他的现实——热牛奶、没看完的电影、她送的玩偶。最后一遍副歌换他飞过去找她；歌停了，凌晨 3:47，两部手机同时发出"睡了吗？"
- **角色**：
  - **她**：长头发、粉色睡衣
  - **他**：短头发、灰色卫衣
  - **两只玩偶**：用户给的 12×8 像素小怪做成的毛绒玩偶。他那只橙色的是她送的（"你送的玩偶依然陪在身边"），她自己留着粉色那只。魔法发生时眼睛会亮，飞起来时变回真正的像素方块
- **风格**：夜里的蓝紫色调，月光、窗灯、萤火虫、雾、柔光（bloom）、固定的胶片颗粒和暗角。回忆是暖黄色、有漏光；桥段是白天的灰蓝色雨天
- **字幕**：底部居中的歌词，按演唱逐字亮起（女声的句子带粉色的光，男声带蓝色的光）；副歌里唱到的关键词（森林、海底、日出、日落、格林威治、时间、教堂、人海、拥抱你）在背景里用毛笔大字闪一下

## 歌曲是怎么分析的

- **节拍**：`源码/analyze.py`。在 onset 包络上网格搜索恒定速度和相位，得到 94.995 BPM、第 0 小节强拍在 0.178 秒（歌曲时间）。各段的相位偏差都在 ±12 毫秒以内，全曲没有漂移。哪一拍是强拍，按伴奏轨低频的 onset 统计。
- **谁唱哪一句**：Demucs 分出人声，用 pyin 测每句的音高中位数。
  - 主歌 A、前两遍副歌和"我想和你"在 300 Hz 上下，是女声（薛黛霏）
  - 主歌 B、桥段和最后一遍副歌在 150 Hz 上下，是男声（沈以诚）

  故事就按这个分：女声的段落拍她，男声的段落拍他；最后一遍副歌是男声唱的，所以换他飞过去。
- **歌词和逐字时间**：`源码/align.py`。
  - 歌词行：从用户发来的抖音视频画面里读出来（画面上滚动的歌词，LRC 比实际开口早约 0.5 秒）。
  - 逐字时间：人声轨 + torchaudio 的 MMS 强制对齐（汉字转成不带声调的拼音按字母对齐）。主歌唱了两遍，两遍各自对齐后按小节平移到一起：大部分字两遍相差不到 0.12 秒，差得多的取得分高的那遍。
  - 副歌：女声副歌伴唱多，整段对齐会在第四句跑偏。改成每句按"这句的强拍前 1.45 秒到两小节后"开窗单独对齐，三遍取中位数（三遍的同一个字基本相差在 0.05 秒以内）。
- **歌曲结构**（歌曲时间，`bar(n)` = 0.178 + 2.5265 n 秒）：

- **原曲**：整首原样使用，只剪掉开头 1.30 秒的数字静音（歌曲第 1.42 秒才有声音），结尾补 0.25 秒淡出。
- **画外音**：两句，CosyVoice 3 合成的女声（语速 0.95，加一点混响）：
  - 开头"凌晨三点，你也还没睡吗？"：前奏里念，人声第一次开口之前念完；念的时候前奏压低约 3 dB。短促的音效不压字头：钟的嘀嗒放在"凌"之前（0.02 秒）、"点"和"你"之间（1.22 秒）和念完以后；玩偶眼睛亮起来只垫一层没有起音的微光声；风铃等"吗"念完（2.55 秒）再响
  - 结尾"你失眠的时候，在想谁？"：歌唱完以后念；念的时候钟停，片尾卡也不再加"叮"
- **音效和环境声**：numpy 合成（`源码/mix.py`），没有另加配乐。有人声的地方压低约 8 dB，短促的音效尽量放在两句之间的空隙里。
  - 开头：屋里的底噪、钟的嘀嗒、玩偶眼睛亮起来的微光声和风铃、窗户被风推开、床浮起来、冲出窗外的风声
  - 主歌：风、泡泡、雾、往下掉的风声、微波炉的"叮"（歌曲 27.86 秒，正好在两句之间）、倒带
  - 副歌：入水、鲸鱼的叫声、钟表的嘀嗒、抱住时的钟声
  - 间奏：流星、天亮的鸟叫；像素小怪是 8 位游戏的声音（"咻"、像素烟花、搭方块的"哔"），和甜菜之前的像素小怪视频一个味道
  - 桥段：一直下雨，第 73 小节雨停在半空，雨声一下子断掉，接着一阵倒放的闪光声
  - 尾声：屋里的底噪、钟、手机打字、发送、震动、收到消息的"叮"
- **响度**：成片 −16.0 LUFS，真峰值 −0.9 dBTP（4 倍过采样找峰值，限幅到 −1.0 dBTP；混好以后是 −18.9 LUFS，整体加 3.0 dB，限幅器只在 0.3% 的采样上动了手，最多 3.3 dB）。
