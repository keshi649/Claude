# 短视频《为什么总是对方下手重？》

> 小时候跟同桌打闹，都说对方下手重——其实你俩可能都没撒谎。

用户说"再做一个有意思一点的"，这一支是进化错配系列以外的题，约 1 分 28 秒的竖屏像素风科普短视频：

- **旁白有配音**：CosyVoice 3 合成的女声，字幕按配音的逐字时间出现
- 角色台词出在游戏对话框里，不配音，只有打字音
- 有音效和环境声，**没有配乐**
- 角色用用户给的 12×8 像素小怪："你"戴红领巾；"他"是蓝色、头上翘一撮毛的同款小怪；实验里的两个志愿者是绿色、黄色的；大脑里管"音量"的小人（粉色、戴耳机）和科学家（白大褂、眼镜）是本片新加的造型

片子讲的是：

- **开头**：客厅里"你"和"他"打闹，一下比一下重："为什么总是对方下手重？"——"他就是下手重啊！"第 2.85 秒盖章"你还手更重"。
- **证据**：科学家让两个人轮流按对方的手指，要求"按得一样重"，结果平均每一轮都比上一轮重了近四成；两个人却都以为自己是照着按的。线索：答案跟"挠自己不痒"是同一个。
- **挠自己为什么不痒**：大脑里有个管"音量"的小人，你一动手，它提前拿到"预告单"，对上了就把"痒"静音；别人挠你没有预告，音量全开。实验里机器人照着你左手的动作挠你的右手心，不怎么痒；科学家偷偷让它慢 0.2 秒，大多数人根本没察觉，却觉得痒多了，跟别人挠的差不多。
- **回到打闹**：你按出去的力，大脑给它静音了差不多一半。你觉得一样重，其实重了一截；对方也这样，就越打越重。"所以每次都是他先下狠手！"——他也是这么想你的。
- **大脑静音键的使用说明**：
  - 怕痒：把手搭在对方手上，让大脑以为是你自己在动（医生给怕痒的人检查时用的小技巧）
  - 打闹还手：只用你觉得的一半力
  - 觉得对方下手重：先想想，你可能也一样
- **结尾**：教室里两个同桌，"你先打的！""你打得重！"——你俩可能都没撒谎。

## 怎么做出来的

做法和《原始人为什么不怕久坐？》一样，流程、工具和踩过的坑见仓库根目录的 `做视频经验.md`。

- **旁白配音**：`源码/narrate_cosy.py`。
  - CosyVoice 3（Fun-CosyVoice3-0.5B-2512 的 RL 版）零样本合成女声。
  - 每句用 FunASR 转写回来按拼音核对，读错就换随机种子重来。
  - 多音字再看一眼音高曲线（`工具/tone_check.py`）。
  - 最后用时间戳模型给每个字对上时间。
- **时间轴**：`源码/narration.py` 里有全部旁白和对话框台词，读配音的逐字时间排字幕，写进 `timeline.json` / `timeline.js`。
- **画面**：`frame(t)` 只依赖时间 t；`render.cjs` 用 Playwright 逐帧截图，交给 ffmpeg 编码。
  - `sprites.js`：像素小怪。这一支加了耳机、白大褂、笑出的眼泪，和面无表情、张嘴大笑、咬牙三种嘴型。
  - `props.js`：客厅、教室、黑底聚光灯；伸出去的手臂、"啪"、枕头、羽毛、挠痒的波浪线、"哈哈哈"；大脑小剧场（管音量的小人、推子、一排灯、喇叭、预告单）；力度表、放大的手指；摇把手和挠手心的两台机器人、延迟旋钮、秒表；课桌和中间那条粉笔线。
  - `scenes1~3.js`：各个场景。`scenes1.js` 里的 `brawl()` 按一张"谁在第几秒打、多重"的表画打闹。
  - `core.js`、`main.js`：工具、字幕、对话框、转场、逐帧入口。
  - 关键的字都放在安全区里，字幕中心在 x=500。
- **声音**：`源码/audio.py` 用 numpy 合成。
  - 游戏音效："啪"、枕头"砰"、盖章、挠痒的沙沙声、8 位风的"哈哈哈"、推子的滑音、机器人的电机声、拧旋钮、"对不上"的嘀嘟、上课铃……
  - 很轻的环境声：客厅、实验室、屋里、黑底舞台、教室。
  - 混音：
    - 说话时音效压低约 8 dB。
    - 打闹的"啪""砰"只放在旁白开口之前、停顿里和对话框的时候（对话框不配音）；旁白念着的时候，打闹只有画面。
    - 渲染前用 `工具/sfx_check.py` 按配音的逐字时间查过，短促的音效不压在旁白字头上。
    - 成片约 −16 LUFS，做真峰值限幅。
- **旁白文案**：`源码/export.py` 从时间轴导出 `旁白文案.txt`。
- **字体**：缝合像素字体 Fusion Pixel 12px、得意黑 Smiley Sans，均为 SIL OFL。构建时从 npm 下载并校验 sha256，不放进仓库。

## 重新生成

配音已经在 `源码/voice_cv3/` 里，不用再合成：

```bash
cd 源码
pip install numpy scipy
mkdir -p out && NODE_PATH=$(npm root -g) ./build.sh > out/build.log 2>&1   # 输出 out/为什么总是对方下手重.mp4 和 out/旁白文案.txt
```

改了旁白要重新合成那几句（新容器先跑 `bash ../../工具/setup_tts.sh` 搭环境）：

```bash
/home/user/tts/venv/bin/python narrate_cosy.py /home/user/tts/CosyVoice /home/user/tts/models/CV3-RL b2 g3   # 只合成编号是 b2、g3 的两句
```

预览某几个时间点的单帧：

```bash
NODE_PATH=$(npm root -g) node render.cjs preview 2,20,80 out/preview
```
