# 短视频《原始人为什么不蛀牙？》

> 伤你牙的，不只是那杯奶茶，还有那一下午。

进化错配系列的第六支。一支约 1 分 55 秒的竖屏像素风科普短视频：

- **旁白有配音**：CosyVoice 3 合成的女声，字幕按配音的逐字时间出现
- 角色台词出在游戏对话框里，不配音，只有打字音
- 有音效和环境声，**没有配乐**

从这一集起，每集都配旁白。

选题照方法论先打分，挑了新颖和反直觉都高的一个：同一杯奶茶，慢慢抿比一口气喝完更伤牙。打分表在 `脚本.md` 开头。

片子讲的是：

- **开头**："你"说出最常见的答案："因为他们没糖吃呗！"第 2.85 秒盖章"只对一半"。
- **证据**：考古学家统计过，原始人的牙，每 100 颗里蛀的不到 2 颗；种地以后涨到 10 颗上下。另一半答案，藏在"你"手里这杯奶茶的喝法里。
- **牙每天都在被拆、被补**：
  - 拆牙的是细菌：你一吃甜的，它们也开饭，吃完吐出酸，把牙溶掉一点点。
  - 补牙的是口水：先把酸冲淡，再把钙一点点补回去。
  - 每吃一回甜的，酸要闹上半小时左右，口水才补得上。蛀牙，就是拆得比补得快。
- **几十万年前**：甜的很少碰上，碰上了就一次吃完；一天里大部分时间，口水都在补牙。
- **如今**：早饭、零食、奶茶、饮料、夜宵，一天来好几回。
- **第二次反转**："考考你：同一杯奶茶，20 分钟喝完和一下午小口抿，哪个更伤牙？"答案是慢慢抿：前者牙泡在酸里 1 个钟头左右，后者泡了一下午。
- **攻略**：
  - 最要紧的是少吃几回：甜的集中吃，跟着饭一起吃完，别一下午抿
  - 吃完喝几口清水
  - 早晚用含氟牙膏刷牙
  - 牙疼、有洞就去看牙医

## 怎么做出来的

- **旁白配音**：`源码/narrate_cosy.py`。
  - **模型**：Fun-CosyVoice3-0.5B-2512 的 RL 版，Apache-2.0 许可。
  - **声音**：用 CosyVoice 仓库自带的一段女声提示音零样本合成，语速 1.1 倍。
  - **数字和多音字**：念的时候数字写成汉字；"种地"的"种"用拼音标成 zhòng。
  - **查读错**：每句合成完，用 FunASR（Paraformer 中文）转写回文字，按拼音和原稿比对。读错、漏读、多读就换个随机种子重来，最多 3 次。
  - **字幕对时间**：FunASR 的时间戳模型 fa-zh 给每个字对上时间。
  - 结果存在 `源码/voice_cv3/`：每句一个 wav，加一个逐字时间的 json。
- **时间轴**：`源码/narration.py` 里有全部旁白和对话框台词。
  - 它读配音的逐字时间，把字幕一段段排好。`'/'` 把太长的一段字幕排成两行，每行不超过 12 个字。
  - 对话框按每秒 18 个字打出来，打完停 0.45 秒。
  - 结果写进 `timeline.json` 和 `timeline.js`，画面和声音都按它对齐。
- **画面**：`frame(t)` 只依赖时间 t；`render.cjs` 用 Playwright 逐帧截图，交给 ffmpeg 编码。
  - `core.js`：工具、像素缓冲、像素字、游戏界面组件、旁白字幕、对话框。
  - `sprites.js`：像素小怪和行头。这一集加了咧嘴笑（白牙 / 蛀牙）、坏笑的眉毛和细菌身上的斑点。
  - `props.js`：大磨牙（牙釉质砖墙）、糖块、酸滴、钙砖、口水浪、奶茶、清水、蜂巢、野果、办公桌、洗手间……
  - `scenes1~3.js`：各个场景。
  - `main.js`：场景编排、转场、倒带 / 快进、逐帧入口。
  - 关键的字（标题、字幕、对话框、盖章）都放在安全区里，不让平台右侧的按钮和顶上的频道栏挡住。字幕的中心往左挪到 x=500。
- **声音**：`源码/audio.py` 用 numpy 合成。
  - 游戏音效：打字音、盖章、吸奶茶、糖块落下、细菌啃糖、酸滋滋、口水冲过来、砌砖、钟表滴答、蜜蜂、答题的"叮咚"、刷牙……
  - 很轻的环境声：奶茶店、嘴里、草原、办公室、洗手间。
  - 混音：人声去掉 80 Hz 以下、轻压缩；说话时音效和环境声压低约 8 dB，短促的音效不压在旁白的字头上；成片约 −16 LUFS，最后做真峰值限幅。
- **旁白文案**：`源码/export.py` 从时间轴导出 `旁白文案.txt`。
- **字体**：缝合像素字体 Fusion Pixel 12px（界面、对话框）、得意黑 Smiley Sans（字幕），均为 SIL OFL。构建时从 npm 下载并校验 sha256，不放进仓库。

## 重新生成

配音已经在 `源码/voice_cv3/` 里，不用再合成：

```bash
cd 源码
pip install numpy scipy
mkdir -p out && NODE_PATH=$(npm root -g) ./build.sh > out/build.log 2>&1   # 输出 out/原始人为什么不蛀牙.mp4 和 out/旁白文案.txt；超过 30 MB 会自动切成几段
```

改了旁白要重新合成那几句（环境怎么搭见 `narrate_cosy.py` 开头）：

```bash
venv/bin/python narrate_cosy.py CosyVoice目录 模型目录 s2 m3   # 只合成编号是 s2、m3 的两句
```

预览某几个时间点的单帧：

```bash
NODE_PATH=$(npm root -g) node render.cjs preview 2,20,90 out/preview
```
