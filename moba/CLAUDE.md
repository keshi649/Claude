# 晶核争锋 —— 原创 5v5 MOBA 网页游戏

浏览器里运行的 2D 俯视角 5v5 MOBA（玩法参考三路推塔类手游）。所有英雄、技能、野怪、装备的名称和美术均为原创，全部程序绘制，不使用外部图片 / 音频。

## 技术栈

- TypeScript 7（strict）+ Vite 8 + PixiJS 8（WebGL），测试用 Vitest 5
- 依赖版本全部锁死在 `package.json`
- 无外部素材：单位、建筑、特效都用 Graphics 几何图形 + 配色 + 粒子绘制；界面用 DOM/CSS

## 常用命令（在 `moba/` 目录下）

| 命令 | 作用 |
|---|---|
| `npm run dev` | 开发服务器，监听局域网（`vite --host`，端口 5173），手机同一 Wi-Fi 下访问 `http://<电脑IP>:5173` |
| `npm run build` | 类型检查 + 生产构建 |
| `npm run typecheck` | 只做类型检查 |
| `npm test` | 运行全部单元测试 |

**任何时候 build、typecheck、test 都必须通过。**

URL 参数：`?seed=数字` 指定随机种子。

## 架构约定

1. **逻辑与渲染分离**：`sim/` 不得引用 DOM、Pixi、`render/`、`ui/`、`input/`。表现层只读 World 状态与事件，从不回写。
2. **唯一写入口**：玩家输入和（将来的）AI 都编译成 `Command`，由 `World.step(commands)` 在 tick 开头执行。调试操作也走 `debug` 命令。
3. **固定步长**：逻辑 30 tick/s（`BALANCE.tickRate`），`FixedStepLoop` 用累积器推进；渲染按 alpha 在 `prevPos` 与 `pos` 之间插值。
4. **确定性**：逻辑层所有随机数都用 `world.rng`（可设种子的 mulberry32），禁止 `Math.random` / `Date.now`。同种子 + 同命令流 → 快照完全一致（有单测保证）。表现层（粒子、震屏）可以用 `Math.random`。
5. **实体是纯数据**：实体里只存配置 id，不存配置对象引用，便于 `snapshot()` 序列化。
6. **数据驱动**：英雄的属性、技能、被动、增益全部写在 `data/heroes/*.ts`；技能由声明式效果树组成（projectile / dash / area / zone / damage / heal / shield / cc / buff / blink / if…），由 `sim/skills/effects.ts` 解释执行。**新增英雄只加配置文件并在 `heroes/index.ts` 注册，不改引擎代码。**
7. **表现参数也在数据里**：区域特效颜色 / 风格（slash / slam / spin …）、弹道外观、打击力度（impact 0/1/2）写在效果配置上，渲染层通用解释。
8. **打击感只在表现层**：闪白、顿帧（冻结受击 / 攻击单位的渲染位置 40~90ms）、震屏都在 `render/renderer.ts`，逻辑不停帧。
9. **空间网格**：`SpatialHash`（4m 格）每 tick 在执行命令前和移动后各重建一次，索敌、范围技能、碰撞都走它。
10. 代码注释、界面文字、本文件都用中文。

## 设计决策（需求未写明、自行决定的细节）

- **单位制**：逻辑层用米。地图 120×120 米；英雄移速约 3.8 米/秒；沿中路从泉水走到敌方泉水约 150 米 ≈ 40 秒（单测校验路径长度在 130~175 米）。
- **地图对称**：沿河道对角线 y=x 镜像（不是中心对称），这样每一条路对双方都是公平的。蓝方基地在左下，红方在右上。
- **墙体用胶囊折线**（一串点 + 厚度）。碰撞是圆对线段，贴墙滑动天然平滑、凸角不卡；移动按 0.2 米小步推进，高速位移也不穿墙。
- **导航网格** 0.5 米一格，墙体按 0.6 米净空膨胀；建筑作为动态障碍登记（被摧毁时可移除）。A* 用八方向、禁止擦墙角、拉绳平滑，起点能直线看到终点时直接返回。
- **镜头**：每米像素 = min(屏宽/28, 屏高/15)，横屏约显示 28×15 米；指数平滑跟随。
- **防御公式**：实际伤害 = 原伤害 × 600 ÷ (600 + 有效防御)；有效防御 = 防御 × (1 − 百分比穿透) − 固定穿透，最低为 0。
- **上限**：冷却缩减上限 40%，每秒最多攻击 2.5 次，暴击伤害默认 200%，移速被减速后不低于 1.2 米/秒。
- **控制规则**：眩晕 / 击飞叠加时取更长的，不累加；多个减速只取最强的；硬控和击退打断施法前摇、普攻前摇和主动位移；建筑和无敌单位免疫控制。
- **普攻**：按住攻击键会持续发送攻击命令，命令保持 0.25 秒。目标在“射程 + 3 米”内按“英雄 > 小兵 / 野怪 > 建筑”选取，同级取最近；补刀键只打小兵和野怪、优先血量最低。攻击指令期间摇杆移动让位给攻击（追击或站定出手），前摇期间不能移动。
- **技能手感**：
  - 后摇可以被移动或普攻取消。
  - 前摇、蓄力或冲刺期间按下的技能会排队，结束后自动释放（有效期为剩余忙碌时间 + 0.4 秒）。
  - 二段技能的冷却在窗口结束或放完最后一段时才开始计算。
- **点按技能**：自动瞄准射程 +1.5 米内最近的敌方英雄（训练木桩视为英雄）；没有英雄时朝最近的非建筑敌人，再没有就朝当前面向方向。
- **普通技能等级上限**：⌈英雄等级 / 2⌉，最高 6 级；大招在 4 / 8 / 12 级各可加 1 点，最高 3 级。
- **电脑操作**（需求未指定的部分）：
  - C = 补刀；Ctrl+Q/E/R = 技能加点；Esc 或右键 = 取消瞄准。
  - ` 或 F1 开关调试面板（手机上用右上角“调”按钮）。
- **触屏**：
  - 浮动摇杆：左下区域任意位置按下即以按下点为中心，死区 12%。
  - 技能拖动：拖动 90 像素对应满施法距离，移动 14 像素以内视为点按。
  - 取消区：拖动技能时出现在技能区左上方。
- **头顶血条**：自己绿色、友军蓝色、敌方红色；英雄血条每 1000 生命一格刻度，左侧显示等级。
- **训练场（M1）**：
  - 英雄 4 级出生，三个技能各 1 级，剩 1 个技能点可以练习加点。
  - 中路基地前有 4 个木桩和 1 个来回巡逻的移动木桩（用来练预判）。
  - 木桩不会死亡，4 秒没挨打就回满血，被击退后会走回原位。
  - 建筑在 M1 只是地图元素（不可选中、无敌），M2 启用攻防。
- **联机方向**：计划采用服务器权威。sim 可在 Node 中运行，Command 和快照都可以序列化；将来客户端只上传命令。
