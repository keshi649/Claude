# 晶核争锋 —— 原创 5v5 MOBA 网页游戏

浏览器里运行的 2D 俯视角 5v5 MOBA（玩法参考三路推塔类手游）。所有英雄、技能、野怪、装备的名称和美术均为原创，全部程序绘制，不使用外部图片 / 音频。

## 技术栈

- TypeScript 7（strict）+ Vite 8 + PixiJS 8（WebGL），测试用 Vitest 5
- 依赖版本全部锁死在 `package.json`
- 无外部素材：地面贴图、树木、岩石、草丛用 Canvas 2D 程序生成；角色 / 建筑用 Graphics 部件拼装并做骨骼式动画；特效用加色混合粒子；音效用 Web Audio 合成；界面用 DOM/CSS + 内联 SVG 图标

## 常用命令（在 `moba/` 目录下）

| 命令 | 作用 |
|---|---|
| `npm run dev` | 开发服务器，监听局域网（`vite --host`，端口 5173），手机同一 Wi-Fi 下访问 `http://<电脑IP>:5173` |
| `npm run build` | 类型检查 + 生产构建 |
| `npm run typecheck` | 只做类型检查 |
| `npm test` | 运行全部单元测试 |
| `npm run sim -- --games 20 --blue hard --red easy` | 无界面模拟：10 个 AI 对打多局，输出胜率、平均时长、各英雄 KDA / 补刀 / 经济（参数：`--games` `--blue` `--red` `--seed` `--max` 分钟 `--verbose`） |

**任何时候 build、typecheck、test 都必须通过。**

URL 参数：`?seed=数字` 随机种子；`?mode=training` 训练场（默认正式对局）；`?hero=duoshan|lifeng|yeya|lanxi|qingling|zhiying`；`?summoner=blink|smite|heal|sprint`；`?difficulty=easy|normal|hard` 敌方 AI 难度；`?solo=1` 正式对局里只有玩家一人（没有 AI）。调试面板里也能切换英雄与模式。

## 架构约定

1. **逻辑与渲染分离**：`sim/` 不得引用 DOM、Pixi、`render/`、`ui/`、`input/`。表现层只读 World 状态与事件，从不回写。
2. **唯一写入口**：玩家输入和 AI 都编译成 `Command`，由 `World.step(commands)` 在 tick 开头执行。调试操作也走 `debug` 命令。
3. **固定步长**：逻辑 30 tick/s（`BALANCE.tickRate`），`FixedStepLoop` 用累积器推进；渲染按 alpha 在 `prevPos` 与 `pos` 之间插值。
4. **确定性**：逻辑层所有随机数都用 `world.rng`（可设种子的 mulberry32），禁止 `Math.random` / `Date.now`。同种子 + 同命令流 → 快照完全一致（有单测保证）。表现层（粒子、震屏）可以用 `Math.random`。
5. **实体是纯数据**：实体里只存配置 id，不存配置对象引用，便于 `snapshot()` 序列化。
6. **数据驱动**：英雄的属性、技能、被动、增益全部写在 `data/heroes/*.ts`；技能由声明式效果树组成（projectile / dash / area / zone / damage / heal / shield / cc / buff / blink / if…），由 `sim/skills/effects.ts` 解释执行。**新增英雄只加配置文件并在 `heroes/index.ts` 注册，不改引擎代码。**
7. **表现参数也在数据里**：区域特效颜色 / 风格（slash / slam / spin …）、弹道外观、打击力度（impact 0/1/2）写在效果配置上，渲染层通用解释。
8. **打击感只在表现层**：闪白、顿帧（冻结受击 / 攻击单位的渲染位置 40~90ms）、震屏都在 `render/renderer.ts`，逻辑不停帧。
9. **2.5D 只是表现**：逻辑层仍是俯视 2D。渲染时地面按 TILT=0.72 纵向压缩，直立物体按世界 y 做纵深排序；输入的屏幕坐标用 `camera.screenToWorld` 换回地面坐标。
10. **空间网格**：`SpatialHash`（4m 格）每 tick 在执行命令前和移动后各重建一次，索敌、范围技能、碰撞都走它。
11. **AI 与玩家对等**：AI 只能通过 `ai/perception.ts`（本队 `visibleMask`）获取敌方信息，只输出与玩家完全相同的 `Command`，不能直接改 World。AI 用自己的种子随机数，整局对打可复现。
12. 代码注释、界面文字、本文件都用中文。

## 设计决策（需求未写明、自行决定的细节）

- **单位制**：逻辑层用米。地图 120×120 米；英雄移速约 3.8 米/秒；沿中路从泉水走到敌方泉水约 150 米 ≈ 40 秒（单测校验路径长度在 130~175 米）。
- **地图对称**：沿河道对角线 y=x 镜像（不是中心对称），这样每一条路对双方都是公平的。蓝方基地在左下，红方在右上。
- **墙体用胶囊折线**（一串点 + 厚度）。碰撞是圆对线段，贴墙滑动天然平滑、凸角不卡；移动按 0.2 米小步推进，高速位移也不穿墙。
- **导航网格** 0.5 米一格，墙体按 0.6 米净空膨胀；建筑作为动态障碍登记（被摧毁时可移除）。A* 用八方向、禁止擦墙角、拉绳平滑，起点能直线看到终点时直接返回。
- **地图对称（第二条轴）**：上半野区只写一份，下半野区沿中路 x+y=120 反射生成，所以上下两个野区、两条边路也彼此对称。
- **视角（对标王者荣耀）**：2.5D 斜视角，地面纵向压缩 0.72；每米像素 = min(屏宽/30, 屏高/(16×0.72))，横屏约显示 30 米宽；英雄位于屏幕 56% 高度处（前方视野更多）；指数平滑跟随。
- **遮挡**：树木、草丛、单位按世界 y 排序；挡在自己英雄前面的树和草会变半透明，不会把人挡住。
- **手感**：自己的英雄按当前速度外推渲染位置，抵消一个逻辑帧（33ms）的输入延迟；近战普攻前摇 0.2 秒；正面顶到墙体圆头或建筑时会沿切线滑开（平直墙面不滑）。
- **防御公式**：实际伤害 = 原伤害 × 600 ÷ (600 + 有效防御)；有效防御 = 防御 × (1 − 百分比穿透) − 固定穿透，最低为 0。
- **上限**：冷却缩减上限 40%，每秒最多攻击 2.5 次，暴击伤害默认 200%，移速被减速后不低于 1.2 米/秒。
- **控制规则**：眩晕 / 击飞叠加时取更长的，不累加；多个减速只取最强的；硬控和击退打断施法前摇、普攻前摇和主动位移；建筑和无敌单位免疫控制。
- **普攻**：按住攻击键会持续发送攻击命令，命令保持 0.25 秒。目标在“射程 + 3 米”内按“英雄 > 小兵 / 野怪 > 建筑”选取，同级取最近；补刀键只打小兵和野怪、优先血量最低。攻击指令期间摇杆移动让位给攻击（追击或站定出手），前摇期间不能移动。
- **技能手感**：
  - 后摇可以被移动或普攻取消。
  - 前摇、蓄力或冲刺期间按下的技能会排队，结束后自动释放（有效期为剩余忙碌时间 + 0.4 秒）。
  - 二段技能的冷却在窗口结束或放完最后一段时才开始计算。
- **点按技能**：自动瞄准射程 +1.5 米内最近的敌方英雄（训练木桩视为英雄）；没有英雄时朝最近的非建筑敌人，再没有就朝当前面向方向。
- **普通技能等级上限**：⌈英雄等级 / 2⌉，最高 6 级；大招在 4 / 8 / 12 级各可加 1 点，最高 3 级。
- **界面布局（对标王者荣耀）**：左上小地图；右上比分、KDA、时间、设置（音效 / 全屏 / 调试 / 操作说明）；左下摇杆；右下普攻大按钮，三个技能环绕；补刀在普攻左下、推塔在右上；回城、恢复、召唤师技能在技能区左侧一排。界面按屏幕尺寸整体缩放（CSS 变量 `--ui`）。
- **电脑操作**（需求未指定的部分）：
  - C = 补刀，Z = 推塔（只打建筑），V = 恢复；Ctrl+Q/E/R = 技能加点；Esc 或右键 = 取消瞄准；1 / 2 / 3 = 进攻 / 撤退 / 集合信号。
  - F 召唤师技能和 Q/E/R 一样：按住瞄准、松开释放。
  - ` 或 F1 开关调试面板（手机上在右上角设置菜单里）。
- **触屏**：
  - 浮动摇杆：左下区域任意位置按下即以按下点为中心，死区 12%，外圈箭头指示方向。
  - 技能轮盘：按下技能时以按钮为中心出现轮盘（半径约为按钮直径 1.4 倍），拖满轮盘 = 满施法距离；移动 12 像素以内视为点按。
  - 取消施法区：拖动技能时出现在技能区左上方。
- **回城 / 恢复 / 召唤师技能**（从 M3 提前到这次重做）：
  - 回城：引导 6 秒，移动、施法、普攻、受伤、受控都会打断。
  - 恢复：5 秒内回复 30% 生命与法力，受伤即中断，冷却 40 秒。
  - 召唤师技能：默认瞬影（向指定方向瞬移 4.5 米，可越过薄墙，冷却 100 秒），由 `data/summoners.ts` 数据驱动。
- **头顶血条**：自己绿色、友军蓝色、敌方红色；英雄血条每 200 生命一小格、每 1000 一大格，左侧等级框，上方名字；回城时显示进度条。
- **音效**：Web Audio 合成（挥砍、命中、暴击、重击、技能、冲刺、瞬移、升级、失败提示、回城），按与自己英雄的距离衰减；首次触摸 / 按键后解锁；静音状态存在 localStorage。
- **手机渲染分辨率**上限 1.5 倍（电脑 2 倍），节省 GPU 填充率。
- **训练场（M1）**：
  - 英雄 4 级出生，三个技能各 1 级，剩 1 个技能点可以练习加点。
  - 英雄直接出生在中路基地前的木桩旁：4 个木桩和 1 个来回巡逻的移动木桩（用来练预判）。
  - 木桩不会死亡，4 秒没挨打就回满血，被击退后会走回原位。
  - 建筑在 M1 只是地图元素（不可选中、无敌），M2 启用攻防。
- **兵线（M2）**：
  - 第一波 12 秒出，之后每 30 秒一波：3 近战 + 2 远程，每 3 波加 1 个炮车；敌方某路高地塔倒下后，己方这一路每波额外出 1 个超级兵。
  - 小兵属性每分钟成长（生命 +5%、攻击 +4%），沿路线路点前进，追击后自动回到最近的前方路点。
  - 小兵索敌：7 米内“小兵 > 英雄 > 建筑”，同级取最近；敌方英雄 2 秒内在附近攻击了己方英雄时转火该英雄；超出 10 米放弃追击。
- **防御塔（M2）**：
  - 射程 8 米（水晶 8.5 米）。
  - 索敌：有敌方英雄在塔下攻击己方英雄时立即转火；否则保持当前目标；没有目标时优先小兵，其次英雄。
  - 连续命中同一英雄每次 +40%，最多 3 层（2.2 倍），换目标清零。
  - 同一路前一座塔未倒时后面的塔无敌（血条变暗并显示盾牌）；己方至少一座高地塔倒下后水晶才能被攻击。
  - 普攻自动索敌会跳过无敌的建筑。塔被摧毁后留下废墟，寻路障碍随之移除。
- **泉水**：半径 7.5 米，己方每秒回复 15% 生命与法力，敌方英雄每秒受到 1500 真实伤害。
- **经济与经验（M2）**：
  - 每秒自然增长 3.5 金币；补刀得小兵金币（近战 40 / 远程 35 / 炮车 70 / 超级兵 60）。
  - 击杀英雄 200 金币；终结 3 连杀以上的敌人，额外 70 ×（连杀数 − 2），最多 350；助攻者平分赏金的 50%，每人至少 40。
  - 推塔：进攻方每人 100，最后一击的英雄再加 150。
  - 经验：敌方单位死亡时，12 米内的己方英雄分享（多一个人总经验 +15% 再平分）；升级所需经验 = 160 + 90 ×（等级 − 1）。
  - 击杀归属：由英雄击杀则归他；被塔 / 小兵补掉时归 10 秒内最后一个伤害过他的敌方英雄；10 秒内伤害过的其他敌方英雄算助攻。
  - 多杀：10 秒内连续击杀计数（双杀、三杀……）。
- **死亡与复活**：复活时间 = 5 + 2.4 ×（等级 − 1）秒（15 级约 39 秒）；死亡时画面变灰，显示倒计时；复活时满血满蓝回到泉水。
- **胜负**：任一方水晶被摧毁即结束，逻辑停止推进，显示结算（时长、KDA、补刀、金币、等级），可再来一局。
- **装备（M3）**：24 件（9 基础件、6 合成件、3 双鞋、6 成装 / 打野成装），全部原创名称；图标是程序绘制的字 + 色块。合成时已有部件自动抵扣；出售返还 60%；开局 300 金币；6 格装备栏；随时随地可以购买（对标手游）。
- **推荐购买**：每个英雄配置 `build`（成装顺序）；按顺序找第一件没有的成装，买得起就买它，买不起就降级到它最先缺的、买得起的部件。金币足够时左侧出现一键购买按钮。
- **召唤师技能（M3）**：瞬影、猎击（只能对小兵 / 野怪，800~1640 真实伤害，冷却 45 秒）、愈合（自己和身边友军英雄回 10% 最大生命 + 固定值）、疾驰（3 秒 +50% 移速）。
- **蓄力技能**：按下技能键即开始蓄力（移速减半），松开时按当前瞄准释放；满蓄力自动释放；拖到取消区 / Esc 取消并返还法力、不进冷却。
- **战绩面板**：电脑按住 Tab，手机点右上角比分；显示双方等级、KDA、补刀、经济、装备、复活倒计时。
- **训练场（M3）**：伤害统计（5 秒伤害、DPS、总计，可重置）；调试面板可调木桩双抗（0/100/300/600）、加金币、切换英雄与模式。
- **野区（M4）**：
  - 每方营地：苔甲蜥（1 大 2 小）、灰鬃狼群（1 大 2 小）、两处石羽鸮（3 只，远程）、澄蓝灵鹿（蓝增益）、焰心巨像（红增益）；20 秒首次刷新，普通营地 70 秒、增益 90 秒重生。

- **视野（M4）**：
  - 视野半径：英雄 9、小兵 6、先锋 7、塔 9、水晶 10、泉水 12 米；墙体不遮挡视野。建筑始终可见。
  - 草丛：草丛里的单位对敌方隐身，除非敌方有单位（非建筑）在同一片草丛；在草丛里攻击 / 施法 / 造成伤害会暴露 1.2 秒。

  - 表现：战争迷雾是一张 0.5 米一格的画布，压暗全图后按本队视野源挖出柔和的圆；看不见的敌人不渲染、小地图不显示；自己人在草丛里半透明；小地图同样叠加迷雾，只显示视野内的营地。
- **AI（M5）**：
  - 两层结构：决策层是效用 AI，每 0.3~0.8 秒（按难度）给“对线 / 打野 / 游走 / 团战 / 撤退 / 回城 / 守塔 / 抓人 / 打龙 / 推进”打分，取最高分（叠加难度噪声，当前目标 +0.07 防抖）；执行层每帧按目标生成命令，放技能、换目标、躲技能只在“反应帧”做（间隔按难度）。
  - 局部战力：有效生命 × 输出的平方根，按 12 米内可见的敌我英雄求和；刚在附近消失的敌人按 0.8 个自己计入（防草丛埋伏）；在己方塔下时把塔算作一名英雄。优势比超过难度阈值才开团，敌方塔下阈值 ×1.7。
  - 分路：按定位对五个位置的偏好分枚举全部排列取最优；打野带猎击、游走带愈合，其余带瞬影；同队英雄不重复。
  - 对线：站在己方最前排小兵后 1.5（近战）/ 3（远程）米；不进敌方塔范围，除非塔下有 ≥2 个己方小兵、附近没有敌方英雄且没有刚消失的敌人；塔锁定自己时立刻退出；补刀按“普攻预计伤害 × 难度系数”判断能否一击；敌方英雄在射程附近时用带 poke 标签的技能消耗。
  - 技能使用完全由技能配置里的 `ai.tags` 驱动（poke / aoe / engage / gapclose / escape / shield / heal / execute / farm）：大招范围技能等能打到 2 人（残血例外），斩杀技能等目标 45% 血以下，撤退时用位移技能反向拉开，治疗 / 护盾给附近最残的友军；蓄力技能随机 0.4~1.2 秒后松手。**新英雄只要给技能打好标签，AI 自动会用。**
  - 召唤师技能：瞬影在残血被追时反向闪、或追击 20% 血以下的目标；猎击在大野怪 / Boss 血量低于猎击伤害时补掉；愈合在 30% 血以下；疾驰用于逃跑和追击。
  - 队伍计划（每秒一次）：对面死 2 人、或 5 / 10 分钟后人数占优时去打龟 / 龙（3 / 4 人）；Boss 附近出现的敌人多于我方参与人数就放弃；7 分钟后全队抱团推敌方最外、最残的一路（已站在某路塔前时不换路）；人数领先 ≥2 时趁复活时间强推（塔下 4 人以上、血量过半可以扛塔）；2 名以上敌方英雄进攻己方建筑时全队回防（水晶、高地优先）。
  - 打野只刷本方野区，猎击留给大怪；3 级后打野 / 游走会去抓 40 米内、不在敌方塔下的可见敌人。
  - 回城：没有敌人时血量 < 40% 或法力 < 15%（装备随处可买，所以不为买装备回城）；在泉水里回到 90% 才出门。
  - 躲技能：弹道即将命中或站在敌方延迟范围技能里时侧向 / 反向移动（按难度概率触发）。
  - 三档难度（`ai/difficulty.ts`）：

    | | 决策间隔 | 反应间隔 | 瞄准误差 | 预判 | 决策噪声 | 躲技能 | 开团优势比 | 拉扯 |
    |---|---|---|---|---|---|---|---|---|
    | 简单 | 0.8 秒 | 0.6 秒 | 1.6 米 | 否 | ±0.35 | 0 | 1.5 | 否 |
    | 普通 | 0.5 秒 | 0.3 秒 | 0.7 米 | 是 | ±0.15 | 35% | 1.2 | 是 |
    | 困难 | 0.3 秒 | 0.13 秒 | 0.25 米 | 是 | ±0.05 | 80% | 1.05 | 是 |

  - 玩家对局：玩家在蓝方，4 个友军 AI 固定普通难度，5 个敌方 AI 用 `?difficulty=` 指定的难度（M6 起在局外界面选择）。
  - 调试面板“显示 AI 当前决策”：每个 AI 头顶显示当前目标和得分最高的三个目标；“显示视野范围”画出双方视野圈和草丛。
- **M2 对标重做（兵线 / 防御塔 / 经济 / 胜负表现）**：

    - 雷牙 · 迅雷刺客：雷闪冲刺、裂空爪减速、天雷降锁定击飞；被动击杀刷新雷闪。
    - 灼羽 · 焰翎法师：焰矢爆炸、炎阵持续灼烧、陨火延迟大范围眩晕；被动技能附加灼烧。

- **M4 对标重做（野区 / 视野）**：

- **击杀播报**：屏幕上方居中横幅（击杀者头像 · 标题 · 被击杀者头像），己方蓝底金字、敌方红底；优先级 多杀（双杀~五杀）> 第一滴血 > 终结 > 连杀称号（3 势不可挡、4 锐不可当、5 所向披靡、6+ 独步天下，原创措辞）> 普通“击败”；一方英雄全部阵亡时追加“团灭”；Boss 被击杀也走播报。最多积压 3 条，优先丢弃普通击杀。每类播报配合成音效（己方上行、敌方下行、多杀琶音）。
- **结算评分（1~16 分）**：3 + 参团率×4 + 英雄伤害占比×6 + 承伤占比×3 + 经济占比×3 + 推塔伤害占比×2 + 治疗护盾占比×2 + 击杀×0.25 − 死亡×0.35，胜方 +1；胜方最高分 MVP、败方最高分“败方 MVP”。新增统计：对建筑伤害、给队友的治疗 + 护盾量。
- **性能**：逻辑层 200+ 单位（含 10 个 AI）每帧约 1ms；渲染层 CPU 每帧约 1ms（240 单位、镜头内 36 个）；单位的头顶 / 脚下特效只在有内容时重画，血条按数值变化缓存。调试面板“压力测试 +120 小兵”在三路为双方各刷一批小兵对推。
- **M6 对标重做（整体体验）**：
  - 语音播报：用浏览器自带的语音合成（Web Speech API，不是音频文件）朗读播报：开场“欢迎来到晶核争锋”、第一波兵线“全军出击”、第一滴血 / 多杀 / 连杀 / 终结 / 团灭、推塔、Boss、自己击杀（“击败敌人”）或阵亡（“你已阵亡”）、胜利 / 失败。重要播报会打断次要播报；浏览器不支持时静默。设置里可关。
  - 设置面板（主菜单与局内齿轮菜单都能打开，立即生效，存本机）：音效、语音播报、画质（渲染分辨率：高 = 电脑 2 倍 / 手机 1.5 倍，中 = 1.5 / 1.15，低 = 1）、镜头距离（近 1.12 / 标准 1 / 远 0.85 倍）、显示帧率。
  - 结算：全场单项第一的金牌称号（输出、承伤、经济、推塔、辅助、补刀，每个称号只给一人）；经济差曲线（每 10 秒一个点，中线以上蓝方领先、以下红方领先，标出最大领先）。
  - 历史战绩：每局结束记录（英雄、胜负、KDA、评分、MVP、难度、时长、时间），最多 30 条，主菜单查看场次、胜率、MVP 次数、平均评分。只存本机。
  - 加载页随机小提示；第一波兵线出发时“全军出击”大播报。
- **联机方向**：计划采用服务器权威。sim 可在 Node 中运行，Command 和快照都可以序列化；将来客户端只上传命令。
