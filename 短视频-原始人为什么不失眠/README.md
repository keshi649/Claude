# 短视频《原始人为什么不失眠？》

> 你的身体没有坏，它只是还在等每天夜里都会来的凉风。

进化错配系列的第五支。一支约 2 分 4 秒的竖屏像素风科普短视频：

- **字幕就是旁白，但旁白不配音**
- 角色台词出在游戏对话框里，也不配音，只有打字音
- 有音效，**没有配乐**

另有一版 **旁白配音版**（约 2 分 12 秒）：
- 旁白用开源语音大模型 CosyVoice 3 配成女声，字幕按真实配音的逐字时间出现
- 对话框照旧不配音
- 仍然没有配乐

这一集先从选题下手。第一集火在题材新颖、反直觉、大家感兴趣；第四集照搬了第一集的结构，还是没火。所以这次先给几个候选题打分，挑了新颖和反直觉都最高的一个。打分表在 `脚本.md` 开头。

片子讲的是：

- **开头**："你"说出最常见的想法："天一黑就睡，一睡十个钟头呗！"第 3.5 秒盖章"全错"。
- **证据**：科学家给非洲和南美三个部落的人戴上手环。他们天黑 3 个多小时才睡，一晚只睡 6 个多小时，可几乎不失眠。有两个部落的话里，连"失眠"这个词都没有。
- **秘密在温度**：
  - 身上有个"睡眠开关"，它认的信号是体温往下掉；手和脚是散热口。
  - 野外每天太阳一落，气温一路往下掉，人跟着睡着，在最冷的时候醒来。
  - 如今墙厚了，有暖气、有空调，卧室一整夜一个温度，开关等不到信号。
- **第二次反转**：要帮身体降温，答案是洗个热水澡。汇总 17 项研究的荟萃分析显示，睡前 1~2 小时洗个 40 度出头的热水澡，平均能早 10 分钟睡着。原因是洗完以后手脚血管全开，热量散得更快。
- **攻略**：
  - 睡前 1~2 小时洗个热水澡
  - 卧室凉一点，被子别太厚
  - 长期睡不好就去看医生

## 怎么做出来的

- **旁白与时间轴**：`源码/narration.py` 里有全部旁白和对话框台词。
  - 每句旁白先用语音合成按正常语速（约每秒 5 个字）试读一遍，用逐词时间把字幕一段段排好；试读的声音不进成片。
  - `'/'` 把太长的一段字幕排成两行，每行不超过 12 个字。
  - 对话框按每秒 14 个字打出来，打完停 0.75 秒。
  - 结果写进 `timeline.json` 和 `timeline.js`，画面和声音都按它对齐。
- **画面**：`frame(t)` 只依赖时间 t；`render.cjs` 用 Playwright 逐帧截图，交给 ffmpeg 编码。
  - `core.js`：工具、像素缓冲、像素字、游戏界面组件、旁白字幕、对话框。
  - `sprites.js`：像素小怪和行头，这一集加了睡帽和熬夜的黑眼圈。
  - `props.js`：夜空、月亮、篝火、温度计、睡眠开关、床、空调、暖气、夜城的窗、淋浴、热浪、手环、羊……
  - `scenes1~3.js`：各个场景。
  - `main.js`：场景编排、转场、倒带 / 快进、逐帧入口。
  - 关键的字（标题、字幕、对话框、盖章）都放在安全区里，不让平台右侧的点赞按钮和顶上的频道栏挡住。
- **声音**：`源码/audio.py` 用 numpy 合成。
  - 游戏音效：打字音、盖章、呼噜、手环嘀嘀、开关咔哒、降温的下滑音、空调、翻身、羊叫、淋浴……
  - 很轻的环境声：夜里的虫鸣和风、篝火、空调、水声。
  - 按 EBU R128 定在约 −18 LUFS，最后做真峰值限幅。没有旁白配音，也没有配乐。
- **旁白配音版**：`源码/narrate_cosy.py`。
  - **模型**：Fun-CosyVoice3-0.5B-2512 的 RL 版，Apache-2.0 许可。
  - **声音**：用 CosyVoice 仓库自带的一段女声提示音零样本合成，语速 1.1 倍。
  - **数字和多音字**：念的时候数字写成汉字；"睡着"用拼音标成 zháo。
  - **查读错**：每句合成完，用 FunASR（Paraformer 中文）转写回文字和原稿比对。读错、漏读、多读就换个随机种子重来，最多 3 次。最后 25 句都对上了，只剩"认 / 任""它 / 他"这类同音字转写不出来。
  - **字幕对时间**：用 FunASR 的时间戳模型 fa-zh 给每个字对上时间，字幕按真实配音出现。
  - **结果**：配音存在 `源码/voice_cv3/`，有 wav，也有逐字时间的 json。`narration.py --voice cv3` 按它排时间轴，`audio.py --voice` 把它混进去。
  - **混音**：人声去掉 80 Hz 以下、轻压缩。说话时音效和环境声压低约 6 dB。
- **旁白文案**：`源码/export.py` 从时间轴导出 `旁白文案.txt`。
- **字体**：缝合像素字体 Fusion Pixel 12px（界面、对话框）、得意黑 Smiley Sans（字幕），均为 SIL OFL。构建时从 npm 下载并校验 sha256，不放进仓库。

## 重新生成

```bash
cd 源码
pip install numpy scipy edge-tts
mkdir -p out && NODE_PATH=$(npm root -g) ./build.sh > out/build.log 2>&1   # 输出到 源码/out/：成片 mp4、旁白文案.txt；超过 30 MB 会自动切成几段
```

旁白配音版（配音已经在 `voice_cv3/` 里，不用再合成；要重新合成见 `narrate_cosy.py` 开头的说明）：

```bash
mkdir -p out && VOICE=cv3 NODE_PATH=$(npm root -g) ./build.sh > out/build.log 2>&1   # 输出 out/原始人为什么不失眠_旁白配音.mp4
```

预览某几个时间点的单帧：

```bash
NODE_PATH=$(npm root -g) node render.cjs preview 2,20,90 out/preview
```
