# MV《才二十三》

> 23 岁的进度条，才走了 23%。

一支 3 分 47 秒的横屏动画 MV，配方大同《才二十三》整首。画风学的是知洲发来的那支《红豆》动画 MV：复古扁平插画、纸纹和网点、唱片机开场、竖排片名配红色方印、每段换一个场景。角色、场景和故事都是原创的。

主角是一根红白条纹的生日蜡烛"小烛"，头上的火苗就是它的心情。前半段编曲很轻，它过着 23 岁普通的一天：闹钟响三遍、挤早高峰、周报改到第 8 版、刷朋友圈越刷越小、日历一页页撕掉。音乐停下的那一小节，火苗灭了。全乐队进来的那一拍，它站在生日蛋糕上重新点亮，然后同样的地方换一种活法：地铁开出隧道开上海面，周报折成纸飞机，四季里飞了一圈，天台上开派对。最后它发现人生进度条才走到 23%，后面还有那么长。

画面上**不放歌词**，底部纸条是原创旁白。换场都落在小节线上，小烛唱歌时嘴巴的开合跟着人声的音量走。

## 怎么做出来的

- **节拍和段落**：`源码/analyze.py` 在 onset 包络上搜索恒定速度和相位，得到 166.5 BPM、第 0 拍 0.170 秒，全曲没有漂移；再用 Demucs 把人声和伴奏分开，只取音量包络（不做任何听写），找出安静的前半段、73.7 秒全乐队进来、两处静音和尾奏。结果写在 `源码/timing.js`，画面都读这一份。
- **画面**：
  - `core.js`：工具、配色、字体、纸纹和网点、放射光芒、纸条字幕、方印、云、星星、钟等道具。
  - `chars.js`：小烛（表情、火苗、胳膊腿、派对帽、围巾）、三个朋友、灰色通勤人。
  - `scenes1.js`：唱片机、片名、早上、早高峰、工位、刷手机、日历、天台、身高尺。
  - `scenes2.js`：生日蛋糕、骑车、海上地铁、纸飞机、四季飞行。
  - `scenes3.js`：天台派对、进度条、台阶、许愿、拍立得回顾、片尾。
  - `main.js`：镜头表、转场（闪白、彩色横条、圆形遮罩、推、甩、红条擦除、叠化）、纸纹暗角、重拍推镜。

  `frame(T)` 只依赖时间。`render.cjs` 用 Playwright 逐帧截图，交给 ffmpeg 编码。
- **声音**：原曲整首原样使用。`源码/mix.py` 用 numpy 在开头合成 3 秒唱片机预备（脚步、马达、唱针落下、黑胶底噪），结尾补一点唱片空转的底噪，最后用两遍 loudnorm 统一响度。
- **字体**：马善政毛笔楷书、站酷快乐体、思源黑体、思源宋体、Fredoka（均为 SIL OFL）。构建时自动下载，不放进仓库。

## 重新生成

歌曲音频不放进仓库。把整首歌（3:42，人声从 1 秒处开始）转成 `源码/audio/song.wav`：

```bash
cd 源码
mkdir -p audio && ffmpeg -i 你的音频.m4a -vn -ac 2 -ar 44100 audio/song.wav
pip install numpy scipy
NODE_PATH=$(npm root -g) ./build.sh      # 输出到 源码/out/才二十三.mp4
```

`timing.js` 已经在仓库里。换了别的音源（比如开头多了几秒）才需要重跑分析，这一步要 librosa 和 demucs：

```bash
pip install librosa demucs
python3 analyze.py
```

预览某几个时间点的单帧（成片时间，等于歌曲时间加 3 秒）：

```bash
NODE_PATH=$(npm root -g) node render.cjs preview 8.6,76.8,130,203.5 out/preview
```
