# 短视频《换个地方就睡不着，怪床吗？》

> 不怪床：是你的左脑在站岗。

用户说"还是做一个关于睡眠的吧 要反常规"。约 ⟨DUR⟩ 的竖屏像素风科普短视频：

- **旁白有配音**：CosyVoice 3 合成的女声，字幕按配音的逐字时间出现
- 角色台词出在游戏对话框里，不配音，只有打字音
- 有音效和环境声，**没有配乐**
- 角色用用户给的 12×8 像素小怪："你"戴红领巾和睡帽；左脑里站岗的小人戴保安帽、拿手电筒；祖先戴毛皮帽。鸭子是本片画的
- 每个画面多铺几层、每层都有在动的东西（`做视频经验.md` 第二十、二十二节）；开头埋了伏笔（床头上睁着一只眼的小黄鸭，后面"答案在鸭子身上"、池塘里两头的鸭子、结尾闭上眼）

片子讲的是：

- **开头**：夜里的酒店房间，"你"睡不着："换个地方就睡不着，怪床吗？"——"对，我认床！"第 ⟨stamp⟩ 秒盖章"左脑在站岗"。科学家让人头一回在实验室过夜：左脑睡得比右脑浅；"嘀、嘀、嘀……嘟！"一有怪声，左脑反应大得多，人也醒得更快；一周后再来，就撤岗了。
- **为什么要站岗**：鸭子睡成一排，两头的睁着朝外的那只眼，半个大脑睡、半个放哨，这样睡的时间比中间的多一倍半；科学家猜这是保命的本事——在陌生的地方，头一晚最危险。"可我住的是酒店啊！"大脑可不管，它只认"这地方没睡过"。
- **第一晚**：53 项研究汇总，第一晚入睡慢、醒得多、睡得少，第二晚就和后面几晚差不多。**考试前一天才住进酒店，考前那一晚正好是左脑站岗的第一晚。**
- **攻略卡**：去外地考试、面试——提前两天住进去；第一晚没睡好，别慌；带副耳塞。
- **结尾**："原来不是我矫情！"——"是你的左脑太尽责。评论区说说，你在哪儿睡得最差？"

## 怎么做出来的

流程、工具和踩过的坑见仓库根目录的 `做视频经验.md`。

- **旁白配音**：`源码/narrate_cosy.py`（CosyVoice 3 合成，FunASR 转写核对、逐字对时间）。
- **画面**：`frame(t)` 只依赖时间 t；`render.cjs` 用 Playwright 逐帧截图，交给 ffmpeg 编码。
  - 背景画在 216×384 的像素缓冲上、放大 5 倍；小怪按 10 倍或 15 倍画，和背景的像素对齐。
  - `props.js`：夜里的酒店房间（窗外的城、窗帘、空调、挂画、房门、床头、床头柜、电子钟、手机）、大脑（左右两半）和站岗的小人、睡眠实验室和脑电波形、夜里的池塘和正面的绿头鸭、芦苇里的狐狸、山洞和篝火、论文、行李箱、考卷、耳塞。
  - `sprites.js`：像素小怪（这一支用了睡帽、保安帽、毛皮帽）。
  - `scenes1~3.js`：各个场景；封面在 `scenes1.js` 的 `coverArt`。
- **声音**：`源码/audio.py` 用 numpy 合成：实验里的"嘀、嘀、嘀……嘟！"、盖章、日历翻页、打呼、小黄鸭"吱"、鸭子"嘎"、手电筒咔嗒、"嘀嘀"警示、纸落下的沙沙声；空调和车流、实验室设备、池塘的蛐蛐和蛙叫、篝火和狼嚎、早上的鸟叫。短促的音效都不压旁白的字头（`工具/sfx_check.py` 查过）。
- **字体**：缝合像素字体 Fusion Pixel 12px、得意黑 Smiley Sans，均为 SIL OFL。构建时从 npm 下载并校验 sha256，不放进仓库。

## 重新生成

配音已经在 `源码/voice_cv3/` 里，不用再合成：

```bash
cd 源码
pip install numpy scipy
mkdir -p out && NODE_PATH=$(npm root -g) ./build.sh > out/build.log 2>&1   # 输出 out/换个地方就睡不着怪床吗.mp4 和 out/旁白文案.txt
```

预览某几个时间点的单帧：

```bash
NODE_PATH=$(npm root -g) node render.cjs preview 1,20,45 out/preview
```
