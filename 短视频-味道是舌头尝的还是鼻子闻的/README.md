# 短视频《味道是舌头尝的，还是鼻子闻的？》

> 舌头只管酸甜苦咸鲜，剩下的千百种味道，是鼻子替你尝的。

一支约 1 分 38 秒的竖屏像素风科普短视频，不属于进化错配系列：

- **旁白有配音**：CosyVoice 3 合成的女声，字幕按配音的逐字时间出现
- 角色台词出在游戏对话框里，不配音，只有打字音
- 有音效和环境声，**没有配乐**
- 角色用用户给的 12×8 像素小怪："你"戴红领巾，这一集加了个小鼻子；其他人是换了颜色、帽子的同款小怪

片子讲的是：

- **开头**：糖果店里，"你"把一颗草莓糖丢进嘴里："当然是舌头！"第 3.27 秒盖章"是鼻子"。
- **证据**：捏住鼻子吃一颗草莓糖，只尝得出甜，尝不出草莓味；一松手，草莓味才冒出来。
- **舌头只认得五种味道**：酸、甜、苦、咸、鲜。
  - 草莓味、咖啡味、巧克力味，舌头一个都不认识。
  - 舌头像一盒 5 色的颜料，鼻子里有约 400 种气味受体。
- **鼻子的两扇门**：前门是鼻孔，后门在嗓子眼上面。
  - 嚼东西、咽下去的时候，香气从嘴里往上，走后门钻进鼻子。
  - 大脑却把这股香气记在舌头头上，所以你以为是尝出来的。
  - 感冒鼻塞时吃什么都没味：舌头好好的，是后门堵了。
- **第二次反转**：香气还能骗过舌头。同样的糖水，闻着草莓香喝着更甜；同样淡的盐水，闻着酱油香喝着更咸。
- **吃得更香的小办法**：
  - 慢慢嚼，让香气走后门
  - 少糖少盐，用香料来补
  - 感冒没味，别猛加盐

## 怎么做出来的

做法和上一支《为什么你总觉得别人在看你？》一样，流程、工具和踩过的坑见仓库根目录的 `做视频经验.md`。

- **旁白配音**：`源码/narrate_cosy.py`。
  - CosyVoice 3（Fun-CosyVoice3-0.5B-2512 的 RL 版）零样本合成女声。
  - 每句用 FunASR 转写回来按拼音核对，读错就换随机种子重来。
  - 多音字再看一眼音高曲线（`工具/tone_check.py`）。
  - 最后用时间戳模型给每个字对上时间。
- **时间轴**：`源码/narration.py` 里有全部旁白和对话框台词，读配音的逐字时间排字幕，写进 `timeline.json` / `timeline.js`。
- **画面**：`frame(t)` 只依赖时间 t；`render.cjs` 用 Playwright 逐帧截图，交给 ffmpeg 编码。
  - `sprites.js`：像素小怪。这一集加了鼻子、鼻夹、吐舌头和嚼东西的嘴。
  - `props.js`：糖果店、剖开的脑袋（鼻腔、嘴、嗓子眼、嗅觉区）、大舌头、大鼻子、五味徽章、颜料盒和 400 色调色板、杯子和香气、香料罐、门。
  - `scenes1~3.js`：各个场景。
  - `core.js`、`main.js`：工具、字幕、对话框、转场、逐帧入口。
  - 关键的字都放在安全区里，字幕中心在 x=500。
- **声音**：`源码/audio.py` 用 numpy 合成。
  - 游戏音效：糖纸、嚼糖、吸气闻香、鼻夹弹开、咽下去、盖章……
  - 很轻的环境声：糖果店、房间、食堂。
  - 混音：
    - 说话时音效压低约 8 dB。
    - 短促的音效不压在旁白字头上。
    - 成片约 −16 LUFS，做真峰值限幅。
- **旁白文案**：`源码/export.py` 从时间轴导出 `旁白文案.txt`。
- **字体**：缝合像素字体 Fusion Pixel 12px、得意黑 Smiley Sans，均为 SIL OFL。构建时从 npm 下载并校验 sha256，不放进仓库。

## 重新生成

配音已经在 `源码/voice_cv3/` 里，不用再合成：

```bash
cd 源码
pip install numpy scipy
mkdir -p out && NODE_PATH=$(npm root -g) ./build.sh > out/build.log 2>&1   # 输出 out/味道是舌头尝的还是鼻子闻的.mp4 和 out/旁白文案.txt
```

改了旁白要重新合成那几句（新容器先跑 `bash ../../工具/setup_tts.sh` 搭环境）：

```bash
/home/user/tts/venv/bin/python narrate_cosy.py /home/user/tts/CosyVoice /home/user/tts/models/CV3-RL s2 n3   # 只合成编号是 s2、n3 的两句
```

预览某几个时间点的单帧：

```bash
NODE_PATH=$(npm root -g) node render.cjs preview 2,20,90 out/preview
```
