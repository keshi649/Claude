# MV《误闯天家》（像素小怪版）

> 小怪误闯天家，佛前茶一口没敢喝。

一支 29.7 秒的竖屏（1080×1920）像素动画 MV，配用户发来的"误闯天家"那段戏腔（《辞九门回忆》，编曲：名龙）。主角是之前视频里的 12×8 像素小怪（Claude），故事、画面、歌词样式都是这一支新做的，画面全部由代码逐帧画出来。

**故事**（一句歌词两个镜头，切点都落在字头上）：

- **误闯天家**：小怪一拍一步走到一扇巨大的朱红天门前，伸出指尖戳了一下（抖音手势舞的"指尖推门"）——门轰地洞开，金光涌出。里面是浮在云上的金瓦宫殿，御道两边站满金色的仙人；小怪一拍转一次眼睛"茫然张望"，"家"字所有仙人一齐转头盯着它。
- **劝余放下手中砂**：白胡子老仙人弯下腰，指指它怀里那捧金砂，掌心往下一压；它抱紧砂直摇头——砂还是从指缝漏了下去，镜头跟着砂穿过云海，底下是人间夜里的灯火。
- **张口欲唱声却哑**：云上的戏台，它两臂一张开嗓，出来的音符是灰的，裂开、碎成灰，头顶冒出一个"……"，赶紧捂住嘴。
- **粉面披衣叫个假**：变装——大粉扑拍上脸、红戏服从天而降、金冠翎子水袖一起出来，戏台中央亮相；可铜镜里照出来的，是没化妆、没穿戏服的自己，掉了一滴眼泪。
- **怜余来安座下**：仙人们围过来摸摸它的头，招来一朵云垫子；殿里一排仙人在蒲团上入定，它也盘腿合掌——隔一拍就偷偷睁一只眼。
- **不敢沾染佛前茶**：大佛爷（放大 4 倍的金色小怪）入定，茶壶一抖一抖地斟茶（"佛前茶抖腕"），茶碗滑到它面前；它两只手一上一下地抖，把碗推了回去。茶汤里映着一个小月亮。
- **只作凡人赴雪月风花**：它朝佛爷一拜，行头全飞上了天，变回原来的样子，转身从云边纵身一跳——身后一轮大月亮，雪一起飘下来；一阵风，它"噗"地坐进人间的雪地里，梅花一拍开一簇，它抬头看着月亮笑了。

歌词竖排在画面上角，像素化的毛笔字，唱到哪个字哪个字"盖"下来，一句唱完像砂一样散掉。没有画外音、没有加音效，只有这首歌。

## 怎么做出来的

- **节拍和逐字时间**：`源码/analyze.py`。Demucs 分出人声；伴奏低频起音拟合出 129.18 BPM 的拍网格；torchaudio 的 MMS 强制对齐（汉字转成不带声调的拼音）每句单独开窗，得到每个字开唱的时刻。画了人声频谱逐字核对过。结果在 `timing.json` / `timing.js`。
- **画面**：`frame(t)` 只依赖时间，`render.cjs` 用 Playwright 逐帧截图交给 ffmpeg，4 路并行渲染（整片约 35 秒）。
  - `core.js`：时间、工具、像素缓冲和像素图元、像素毛笔字（小号字画出来、二值化、描边、再放大 3 倍）、半透明的光。
  - `sprites.js`：像素小怪 `clawd()` 和本片的行头（粉面、戏服、金冠、一捧砂、合掌、盘腿），光环、水袖、翎子、披帛、远处的小仙人。
  - `world.js`：天家的天、祥云、云海、宫殿和金瓦屋顶、灯笼、光芒、金砂、音符、心、蒲团；人间的夜空、月亮、雪、梅枝、小镇、雪坡。
  - `shots1.js`、`shots2.js`：17 个镜头。
  - `main.js`：镜头表、歌词（竖排、逐字落下、散成砂）、片尾落款、水印、暗角、封面。
- **声音**：只用原曲，降到 −16 LUFS（原曲 −6.9 LUFS、真峰值 +1.0 dBTP，整体降 9.1 dB），开头 10 毫秒淡入、最后 0.8 秒淡出。
- **字体**：马善政毛笔楷书（SIL OFL），构建时下载并校验 sha256，不放进仓库。

## 重新生成

歌曲不放进仓库。把用户发来的那段 `.mov`（29.74 秒，开头一行"编曲：名龙"）放到 `源码/song.mov`，然后：

```bash
cd 源码
# 逐字时间已经在 timing.json 里；想重新算：/home/user/mvenv/bin/python analyze.py song.mov --spec out/spec.png
NODE_PATH=$(npm root -g) ./build.sh        # 输出 out/误闯天家.mp4 和 out/封面.jpg
```
