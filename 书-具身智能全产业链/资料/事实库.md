- π0.7（官网 2026-04-16）：训练提示里加入四类条件——多样的语言、"怎么做"的元数据（速度、质量）、控制模态（关节或末端）、视觉子目标图（测试时可由世界模型生成）。称出现"组合泛化的最初迹象"。空气炸锅例子：零样本只完成一部分，"几次失败的起步后做了一部分，没有做完"；加逐步语言指导后变好；再微调高层策略才能自主做完。官方没找到直接对应的训练片段。浓缩咖啡、叠衣、折盒：成功率和归一化吞吐"持平或超过" π*0.6 专用模型（图表数值未在文字中给出）。UR5e 双臂零数据叠衣：成功率与平均 375 小时经验的遥操作员在原机器人上首次尝试的成功率相当。等级 B（公司自述），阶段 R/D。
- MEM（arXiv 2603.03596，2026-03）：短期视频记忆（视频编码器压缩）＋长期文本记忆；装在 π0.6 上；演示收拾整间厨房，最长约 15 分钟。等级 B。
- RLT（官网 2026-03-19；论文 arXiv 2604.23073）：把 VLA 内部表征压成"RL token"，小型 actor-critic 在其上做在线强化学习，学的是对 VLA 动作的修正。四个任务：电动螺丝刀拧 M3 螺丝、扎带、网线插入、电源线插入；最精细阶段提速"最多 3 倍"。作者 Charles Xu、Jost Tobias Springenberg、Michael Equi、Ali Amin、Adnan Esmail、Sergey Levine、Liyiming Ke。等级 B。
- Pi API Beta（2026-10-13）：托管微调＋托管推理，候补名单，未公布价格；早期伙伴部署在日本、瑞士、美国，多数走云端推理，公司自己提到部分现场网络连接有问题。等级 C（多家媒体转述；官网原文待抓取）。
