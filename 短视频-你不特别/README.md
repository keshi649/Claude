# 短视频《你不特别》

> 你不特别，但你的此刻是真的。

一支 2 分 40 秒的竖屏短视频，讲的是：心情低落时，人像戴上了一副深色墨镜——专挑灰暗的东西看，还觉得自己的难过独一无二。把镜头拉远、把时间拉长，会发现这份难过是"经典款"，连"我看透了"这个念头也是。斯多葛派、庄子、佛陀、加缪都看到过"你没那么特别"，却没有一个人因此觉得一切都没意义。

| 文件 | 说明 |
|---|---|
| `你不特别.mp4` | 成片：1080×1920，30fps，H.264 + AAC，160 秒 |
| `封面.jpg` | 封面（取自片尾） |
| `脚本.md` | 分镜脚本、全部字幕，以及引文出处说明 |
| `源码/` | 生成视频用的全部代码 |

## 怎么做出来的

- **画面**：`源码/film.js` 用 Canvas 2D 把每一帧画出来，`frame(t)` 只依赖时间 t，所以同一个 t 永远画出同一张图。`render.cjs` 用 Playwright 逐帧截取，再交给 ffmpeg 编码。
- **声音**：`源码/audio.py` 用 numpy 合成钢琴、铺底、八音盒、口哨和各种音效，时间点与画面对齐，最后加混响并做响度处理（约 −15 LUFS）。
- **字体**：霞鹜文楷 LXGW WenKai（SIL Open Font License），构建时自动下载，不放进仓库。

## 重新生成

```bash
cd 源码
NODE_PATH=$(npm root -g) ./build.sh      # 输出到 源码/out/你不特别.mp4
```

预览某几个时间点的单帧：

```bash
NODE_PATH=$(npm root -g) node render.cjs preview 19,63.5,151 out/preview
```
