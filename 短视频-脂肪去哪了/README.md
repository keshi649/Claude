# 短视频《你减掉的脂肪，去哪了？》

> 出口一直是通的，路，要慢慢走。

一支约 6 分半钟的横屏科普视频，回答"为什么你减肥减不下来"。开场先给一个反直觉的事实：减掉的 10 公斤脂肪，有 8.4 公斤变成二氧化碳从肺里呼出，1.6 公斤变成水（BMJ 2014）——你是用肺在减肥。可从脂肪细胞到肺，一路上有三道关卡，主角小油（一颗脂肪分子）带着观众闯：

1. **冷战的日期戳**：核试验留在空气里的碳-14，被用来给细胞"测出生日期"。结果是：脂肪细胞总数成年后基本不变，减重只是让细胞"瘪下去"，房子拆不掉；细胞里的油则一直在换，脂肪不是仓库，是一条河。
2. **会说话的脂肪**：从两只连在一起的老鼠，到瘦素，到大脑里一小撮"饥饿神经元"——用一束光就能让吃饱的小鼠狂吃。人减重之后，这套警报系统一年后还没回到原来的水平：那种饿，不是你软弱。
3. **脂肪的记忆**：2024 年《自然》的研究发现，减重两年后，脂肪组织的基因活动仍带着肥胖的痕迹。它是不是复胖的原因，还需要更多证据。

再加一个双胞胎彩蛋（同样多吃，增重最多的是最少的三倍），以及"怎么办"的三件小事：把警报的音量调小、把"保持"当成长期战斗、必要时去医院评估。最后回到那十公斤：二氧化碳飘进空气，明年春天，也许变成一片叶子。

## 怎么做出来的

- **配音**：`源码/voice.py` 里有全部台词。它调用 edge-tts（微软神经语音）合成每一句：旁白是云希，小油是云夏。再根据词边界算出每句、每段字幕的起止时间，写进 `timeline.json` 和 `timeline.js`。画面和声音都按这份时间轴对齐，所以改一句台词，前后的画面会自动跟着挪。
- **画面**：`core.js`（工具、文字、论文卡片、字幕），`art.js`~`art4.js`（小油、脂肪细胞、小鼠、大脑、神经元、DNA、双胞胎……），`scenes1~5.js`（开场、三道关卡、双胞胎、怎么办、结尾），`main.js`（转场、章节卡、顶部路线条、逐帧入口）。`frame(t)` 只依赖时间 t。`render.cjs` 用 Playwright 逐帧截图，交给 ffmpeg 编码。
- **声音**：`源码/audio.py` 用 numpy 合成十几种律动（测验、冷战的低鸣、实验室、警报、明亮的结尾……）和几十个音效。旁白开口时，音乐和音效自动让位，人声频段让得更多。
- **字体**：得意黑 Smiley Sans、思源黑体 Noto Sans SC（均为 SIL OFL）。构建时自动下载，不放进仓库。
- **事实**：每项数据的论文、样本量和边界见 `脚本.md` 的"关于事实与出处"。凡是示意性的图形（曲线形状、细胞个数、基因条纹、双胞胎柱子的高度），画面上都标了"示意"。

## 重新生成

```bash
cd 源码
pip install numpy scipy edge-tts
NODE_PATH=$(npm root -g) ./build.sh      # 输出到 源码/out/脂肪去哪了.mp4
```

4 核机器上大约要 20 分钟（画面 4 路并行渲染约 14 分钟，最后编码约 6 分钟）。预览某几个时间点的单帧：

```bash
NODE_PATH=$(npm root -g) node render.cjs preview 4.6,60,300 out/preview   # 带字幕的单帧 PNG
NODE_PATH=$(npm root -g) node render.cjs cover 4.6 ../封面.jpg              # 不带字幕的封面
```

配音缓存在 `源码/voice/`，不进仓库。只有缺失或改动过的句子会重新合成。
