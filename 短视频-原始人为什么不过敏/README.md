# 短视频《原始人为什么不过敏？》

> 他们的保安，见过世面。

进化错配系列的第三支，接着《原始人为什么不近视？》《原始人为什么不用拔智齿？》。一支约 2 分 46 秒的竖屏像素风科普短视频：**字幕就是旁白，但旁白不配音**；8 句角色台词有配音；有音效，**没有配乐**。

两百年前，花粉症还是罕见病；如今中国大城市里，大约每 6 个成年人就有 1 个过敏性鼻炎。片子把免疫系统画成"鼻腔检查站"的保安队：病毒、细菌来了该打就打，可花粉、尘螨、花生只是路过的良民；过敏就是保安认错了人，拉响了警报。为什么认错？一百五十年前的英国医生就发现，天天跟花粉打交道的农民反而很少得花粉症。答案在保安的训练里：小时候要靠泥土、动物、哥哥姐姐带来的各种微生物"陪练"，现代生活太干净，陪练少了。证据有阿米什和哈特派两群农民的哮喘对比、两家灰尘护不护得住小鼠，以及花生的 LEAP 试验（从小吃花生的宝宝过敏少得多）。最后给出攻略：手照样要洗；辅食里的鸡蛋、花生不用刻意推迟（花生给酱或泥）；高风险的宝宝先问医生；已经过敏的找医生，有的人可以做脱敏治疗。

| 文件 | 说明 |
|---|---|
| `原始人为什么不过敏.mp4` | 成片：1080×1920，30fps，H.264 + AAC，约 166 秒。字幕是旁白（不配音），声音是音效、环境声和 8 句角色台词，没有配乐 |
| `旁白文案.txt` | 全部旁白（35 句），按段落排好，每句前面是开始的时间。字幕按正常语速排过，照着念就能对上画面，也和角色台词错开 |
| `封面.jpg` | 封面：大标题 + 正在打喷嚏的小怪，不带字幕（在 `源码/` 里运行 `node render.cjs cover 2.4 ../封面.jpg` 生成） |
| `脚本.md` | 开头 3 秒的设计、分镜、全部旁白和台词，以及每个事实的出处 |
| `源码/` | 生成视频用的全部代码 |

## 怎么做出来的

- **旁白与时间轴**：`源码/narration.py` 里有全部旁白和角色台词。每句旁白先用语音合成按正常语速（约每秒 5 个字）试读一遍，用逐词时间把字幕一段段排好；试读的声音不进成片。角色台词用微软 Edge 在线语音合成（edge-tts）配音，每个角色一种声音。结果写进 `timeline.json` 和 `timeline.js`，画面和声音都按它对齐。
- **画面**：`core.js`（工具、像素缓冲、像素字、游戏界面组件、旁白字幕、对话气泡）、`sprites.js`（像素小怪和行头）、`props.js`（花粉、病毒、细菌、尘螨、花生、陪练微生物、警报灯、检查站、牛、马、狗、谷仓、农场、宝宝、小鼠……）、`scenes1~3.js`（各场景）、`main.js`（场景编排、转场、顶栏、逐帧入口）。`frame(t)` 只依赖时间 t。`render.cjs` 用 Playwright 逐帧截图，交给 ffmpeg 编码。
- **声音**：`源码/audio.py` 用 numpy 合成几十个游戏音效（8 位喷嚏、哨子、警报、牛叫、马蹄、拖拉机、消毒喷雾、升级音……）和很轻的环境声，再把角色台词放在气泡弹出的那一刻，说话时音效自动压低一点。音效床按 EBU R128 定在约 −18 LUFS（和前两集"只有音效"版一致），最后做真峰值限幅。没有旁白配音，也没有配乐。
- **旁白文案**：`源码/export.py` 从时间轴导出 `旁白文案.txt`。
- **字体**：缝合像素字体 Fusion Pixel 12px（界面、对话气泡）、得意黑 Smiley Sans（字幕），均为 SIL OFL。构建时从 npm 下载并校验 sha256，不放进仓库。

## 重新生成

```bash
cd 源码
pip install numpy scipy edge-tts
NODE_PATH=$(npm root -g) ./build.sh      # 输出到 源码/out/：成片 mp4、旁白文案.txt；超过 30 MB 会自动切成几段
```

预览某几个时间点的单帧：

```bash
NODE_PATH=$(npm root -g) node render.cjs preview 2,20,90 out/preview
```
