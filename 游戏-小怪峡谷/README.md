# 小怪峡谷（王者荣耀式 5V5 像素对战）

> 用户原话："做一个王者荣耀游戏"。

一个打开就能玩的网页游戏（单个 HTML 文件，`小怪峡谷.html`），玩法照王者荣耀的 5V5：三条路、每路三座塔、水晶、小兵、野区、小龙大龙、回城、闪现、出装、升级解锁技能、击杀播报。你在蓝方，另外 9 个英雄是电脑。英雄是甜菜视频里的 Claude 像素小怪，换颜色、加帽子和武器分成 6 个职业；画面、字幕、按钮全是像素风。

名字没用"王者荣耀"：那是腾讯的名字和商标，发布出去的网页不能用它的名字、图标和英雄形象，所以叫"小怪峡谷"（"峡谷"是玩家对王者地图的叫法），英雄、装备、技能都是新起的名字。

## 怎么玩

- **目标**：推掉右上角红方的水晶。每条路三座塔，外塔倒了才能打里面的；任意一座高地塔倒了，水晶才能打。小兵 0:30 出第一波，以后每 30 秒一波；推掉对面高地塔的那条路会出超级兵。
- **手机**：横着拿（竖着拿时画面自动转 90 度）。左手按住左半屏任意地方是摇杆；右手按住大圆键普攻，自动打范围里血最少的敌人（英雄优先）。技能键点一下自动瞄最近的敌方英雄，按住拖动自己瞄方向 / 落点，拖到"取消"上松手就不放。下面一排是回城、恢复、闪现。
- **电脑**：WASD 移动，J / 空格普攻，1 2 3 放技能（朝鼠标），F 闪现，H 恢复，B 回城，G 集合，P 暂停。
- 右上角：**集合**（旗子，队友过来跟着你、你打什么他们帮着打，25 秒）、**托管**（电脑替你打）、**暂停**（战绩、投降）。左边：金币（点开商店，随时能买，不用回城）、推荐装备（钱够了会闪，点一下就买）。
- 2 级解锁第二个技能，4 级解锁大招，最高 15 级。野区有红 BUFF（普攻减速、灼烧）、蓝 BUFF（冷却缩减、回血），杀了带 BUFF 的英雄会抢过来。河道里小龙 2:00 出现（全队加钱加经验），大龙 6:00 出现（三条路各出一个先锋帮你推塔）。
- 难度：简单 / 普通 / 困难。队友至少是普通水平，对面按难度来；困难时对面每秒金币多 10%。

## 英雄

| 英雄 | 职业 | 常走 | 被动 | 技能 1 | 技能 2 | 大招 |
|---|---|---|---|---|---|---|
| 克劳德（原色小怪 + 红披风 + 大剑） | 战士 | 对抗路 | 造成伤害的 10% 回血 | 旋风斩：转 2 秒砍周围，加速 | 跃击：跳过去砸地，减速 | 断罪：前方重斩，打残血更痛，杀人返还冷却 |
| 铁墩（铁头盔 + 大盾） | 坦克 | 游走 | 受伤减 10%，残血再减 15% | 冲撞：撞到的第一个英雄眩晕 | 铁壁：护盾 + 周围减速 | 震地：跳起砸地，一片敌人眩晕 |
| 影子（深色、黄眼睛、红头带） | 刺客 | 打野 | 对残血英雄多 20% 伤害 | 影袭：冲刺砍一路，杀人刷新 | 隐匿：隐身加速，下一刀加伤 | 千刃：闪到敌人身边连砍 5 刀，期间不可选中 |
| 星星（尖帽子 + 法杖） | 法师 | 中路 | 技能打中英雄后加速 | 星火球：碰到就炸 | 冰晶环：0.7 秒后冻住一圈 | 流星雨：7 颗流星砸一片 |
| 青箭（猎人帽 + 弓） | 射手 | 发育路 | 每第 4 下普攻加伤减速 | 散射：扇形 5 支箭 | 疾步：翻滚 + 攻速 | 穿云箭：飞过半张地图，射中眩晕，越远越久 |
| 糖糖（头顶小花 + 爱心杖） | 辅助 | 游走 | 身边队友持续回血 | 治愈之光：奶自己和血最少的队友 | 缠绕：藤蔓缠住第一个敌人 | 庇护：全队护盾 + 加速 |

你选一个，其余 4 个队友从剩下 5 个里自动排；对面 5 个随机。

## 实测

- 文件：`小怪峡谷.html` 536 KB（像素字体子集 30 KB、29 句播报语音共 187 KB 的 mp3）。打开到标题画面约 1.5 秒（生成整张 2000×2000 的像素地图）。
- 帧率：无头 Chromium 里手机横屏 / 竖屏、电脑都是 60 帧。模拟每帧约 0.4 毫秒（100 来个单位）。
- 电脑打电脑（`test/simtest.js`，玩家那个位置也换成电脑）：普通难度最后一批 20 局：蓝 8 胜、红 12 胜，没有超时；一局中位 16 分 52 秒（最短 11:17，最长 22:27），平均每局 45 次击杀。前面调数值时的两批（10 局、30 局）和这批加起来 60 局 29:31，两边是平的。简单 16 局蓝方全胜（中位 12:54），困难 16 局 9:7（中位 17:20）。
- 触屏（`test/touch.js`，CDP 多指触摸，横屏、竖屏各跑一遍）：摇杆能走；摇杆按着的同时第二根手指按普攻；拖技能能放；拖到"取消"不放；点技能自动瞄；闪现 320；回城；按小地图看别处、松手回来；暂停键。
- 整局（`test/fullgame.js`）：托管打完一整局到结算画面、再来一局，页面没有报错。

| `src/sprites.js` | 像素画：英雄（12×8 的 Claude 小怪，每块 2×2）、小兵（1×1 的小号小怪，蓝队蓝、红队红）、野怪、塔、水晶、图标、像素数字和像素字 |

## 重新生成

```bash
cd 游戏-小怪峡谷
pip install fonttools brotli
python3 build.py                       # 输出 小怪峡谷.html；第一次会从 npm 下载字体并校验 sha256（fonts/ 不进仓库）
node test/simtest.js 10 1              # 电脑打电脑 10 局：谁赢、几分钟、击杀、掉塔、有没有人卡住
NODE_PATH=$(npm root -g) node test/shots.js 截图目录 phone      # phone / portrait / desktop
NODE_PATH=$(npm root -g) node test/touch.js phone
```

播报语音（要先 `bash 工具/setup_tts.sh` 搭好配音环境）：

```bash
cd voice
/home/user/tts/venv/bin/python make_voice.py /home/user/tts/CosyVoice /home/user/tts/models/CV3-RL [编号 ...]
/home/user/tts/venv/bin/python retake.py /home/user/tts/CosyVoice /home/user/tts/models/CV3-RL double triple quadra penta
/home/user/tts/venv/bin/python pack.py
```

## 用到的别人的东西

- 像素字：缝合像素字体 Fusion Pixel 12px（TakWolf，SIL OFL 1.1，保留字体名"Fusion Pixel"）。取子集算修改，按 OFL 不能再叫这个名字，所以嵌进网页的子集改名 XGPixel，版权和许可证信息留在字体的 name 表里。
- 播报配音：CosyVoice 3（Fun-CosyVoice3-0.5B-2512 的 RL 版，Apache-2.0）合成，FunASR 转写核对。
- 其他（画面、音效、关卡、数值、AI）都是代码现写的。
