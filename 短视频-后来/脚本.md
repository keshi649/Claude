# 《后来》MV 脚本

用户发来刘若英《后来》的抖音歌词视频（1080×1440，5 分 15 秒），说："做一个 mv，不要参考之前的视频，不要加其他的东西只是做 mv，开头的画面可以多变或者加一些特效或者转场等等你要选一个最适合的，要留住人。"

所以这一支：

- **只有原曲**：没有画外音、没有音效、没有另加的片头片尾时间，成片和歌一样长（315.5 秒）。
- **不沿用之前的作品**：故事、画风（扁平插画 + 胶片质感，不是像素风）、人物（自己画的十七岁的她和他、长大后的两个人）、镜头和转场都是新做的；只复用了逐帧渲染的管线（Playwright 截图交给 ffmpeg）和切分工具。
- **竖屏 1080×1920**：用户发来的原视频是竖的（3:4），抖音也是竖着刷。
- **开头 12 秒前奏要留人**：选的是"倒带"——雨夜俯拍的伞海 → 伞下一张旧拍立得 → 雨滴落在照片上荡开水波 → 录像带倒带，后面的剧情一段段倒着闪过、日期戳从 '26 10 24 倒数回 '09 7 17 → 落在十七岁的夏天，慢动作回头一笑 → "咔"的快门定格 → 唱"后来"时片名一笔一笔写出来。理由见下面"开头"一节。
- 水印"甜菜"在右上角，片尾有"甜菜 出品"和"画面：Claude 用代码生成"。

## 歌曲是怎么分析的

- **歌词**（`源码/kara.py`）：原视频是卡拉 OK 式的滚动歌词，正在唱的那一行停在 y 690~775，唱到哪儿哪儿从浅灰（约 225）擦成纯白（255）。逐帧量出每一行停稳的时刻、每一列擦亮的时刻，截图拼起来读出全部 55 句。视频里第一遍副歌写的是"有些人一旦错过就不在"，后面都是"不再"，统一成"不再"。
- **这个版本的结构**（不是原版的完整结构，中间少了一段）：前奏 0~12.2 秒 → 开头副歌（伴奏很轻）12.2~38.5 → 主歌"栀子花 白花瓣"38.5~86.6 → 乐队进来"那时候的爱情"86.6~128 → "如果当时""你都如何回忆我"128~153 → 副歌 153~179.5 → 纯间奏 179.5~204.7 → "你都如何回忆我"、两遍副歌、"永远不会再重来 有一个男孩爱着那个女孩"204.7~282.6 → 尾奏 282.6~315.5。
- **节拍**（`源码/align.py`）：伴奏轨（Demucs 的 no_vocals）的 onset 包络上网格搜，最强的是 149.81 BPM 的八分音符，即 **74.9 BPM**，一小节 3.204 秒；按八分音符位置统计中高频起音，第 0、4 位最强，第 0 小节从 0.113 秒开始。
- **逐字时间**（`源码/align.py`）：Demucs 分出人声，torchaudio 的 MMS_FA 强制对齐（汉字转成不带声调的拼音按字母对齐），每句按歌词视频里"上一句滚走前 0.4 秒到这一句滚走后 0.6 秒"开窗。
  - 9 处"后来"的开口都和人声响度起来的时刻核对过，差 ≤ 0.05 秒。
  - 卡拉 OK 的擦亮是按整句匀速插出来的（有时一下亮好几个字），和对齐比中位数早 0.06 秒、前后差到 0.5 秒的不少，所以只用来开窗、做交叉核对。
  - 副歌唱了四遍：同一句每个字相对句首的时刻取中位数，得分低又偏离 0.3 秒以上、并且卡拉 OK 也站在中位数那边的字才换掉（只有第三遍"可惜你早已远去"的"去"，226.90 → 226.16）。
  - 结果在 `源码/timing.js`（画面读）和 `timing.json`。

## 故事

一句话：**十七岁那年夏天，栀子花落在她的蓝色百褶裙上，他轻声说"爱你"；后来两个人都太倔强，错过了。很多年以后她终于学会了怎么去爱，他早已消失在人海——可那年夏天，确实有一个男孩爱着那个女孩。**

主旨按大家对这首歌的普遍理解：初恋、年少的倔强、错过、后来才懂。时间线用颜色分开：**现在**是冷蓝的雨夜、冬夜；**回忆**是暖黄的夏天，右下角亮着老相机的橙色日期戳 '09 7 17（十七岁、七月十七日）。

贯穿全片的几样东西：

| 东西 | 在哪儿出现 |
|---|---|
| 拍立得 | 开头她在雨里拿着它 → 倒带的入口 → 夏天的那一刻就是这张照片（是他拍的，所以照片里只有她） → 旧书里、她的手上 → 结尾翻过来，背面是他写的"爱你 2009.7.17" |
| 栀子花 | 夏天的花丛 → 他递给她的那一朵 → 吵架时掉进水洼、他捡起来 → 两个人的书里各夹着一朵干花 → 她后来自己养了一盆 → 最后把干花放走，它飞回 2009 年 |
| 星光 | 十七岁的夏夜和吻 → "每当有感叹，总想起当天的星光"：加班、夜车、天桥上，每次抬头都有一颗星 → 结尾升进银河 |
| 人海 | 开头俯拍的伞海里他消失 → "人海"是一片由人组成的海浪，他从海面上走远 → 地铁换乘大厅的人流 → 早晨城市里的人群 |
| 打了又删 | 她打"这些年，你还好吗"又删掉 → 后来才演到他那边：同一时刻，他手机上"对方正在输入…"出现又消失 |

## 开头：怎么留住刷到的人

方法论第 1 关（前 3 秒、前 20 秒切 3 次镜头、抛线索）放到 MV 上：

- **第一帧就在动、就好看**：俯拍雨夜的十字路口，满街深色的伞在斑马线上来回流，只有正中一把米白的伞不动（她），雨从镜头往下落。顶上小字"刘若英 ·《后来》"（0.15~3.3 秒），让认得这首歌的人一眼知道是什么。
- **1.7 秒换到特写**：伞下她手里一张旧拍立得，照片里是阳光、栀子花和一个穿蓝裙子的女孩——为什么下雨天看着一张夏天的照片？
- **3.3 秒倒带**：一滴雨正好砸在照片中间，荡开水波，接录像带倒带（横向错位的条带、扫描线、色差、"◀◀"），后面剧情里的 11 个镜头倒着一闪而过（雪夜人潮、对面列车里的他、人海、手机删字、火车倒回站台、栀子花从水洼里飞回去、吵架、单车、星空下的吻、轻声说爱你、栀子花），越来越快；日期戳从 '26 10 24 一路倒数回 '09 7 17。这一段既是"多变的画面"，也是整支片子的预告。
- **9.7 秒落地**：倒带慢下来停住，闪白，十七岁的夏天，她在栀子花丛前背对镜头，慢慢回头笑着挥手（慢动作、花瓣、阳光）。
- **11.95 秒快门**：白光一闪，画面定住、缩回拍立得里——回到雨夜她的手上。**12.24 秒她唱"后来"**，片名"后"字一笔写出来，13.06 秒唱"来"，"来"字写出来。

前 20 秒切镜头：⟨CUTS⟩。
