# MV《后来》

> 后来，我总算学会了如何去爱。可那年夏天，确实有一个男孩爱着那个女孩。

一支 5 分 15 秒的竖屏插画 MV，配用户发来的刘若英《后来》。故事、人物、镜头都是新做的，画面全部由代码逐帧画出来；没有配音、没有音效，只有原曲，成片和歌一样长。

**故事**：雨夜里，她拿着一张旧拍立得——倒回十七岁的夏天：栀子花落在她的蓝色百褶裙上，他轻声说"爱你"，星空下吻了她。后来两个人都太倔强，毕业那天她躲在站台的柱子后面，没有走出去。很多年以后，她学会了怎么去爱，他早已消失在人海。最后她把照片翻过来，背面是他当年写的"爱你"。

- **开头（前奏 12 秒）**：雨夜俯拍的伞海 → 伞下的拍立得 → 雨滴落在照片上，录像带倒带，后面的剧情倒着闪过，日期戳从 '26 10 24 倒数回 '09 7 17 → 十七岁的她在栀子花前回头一笑，快门定格 → 唱"后来"时片名一笔笔写出来。
- **回忆**是暖黄的夏天，右下亮着老相机的橙色日期戳；**现在**是冷蓝的雨夜、冬夜。
- 歌词按演唱逐字亮起；换镜头落在小节线或歌词开口前。

## 怎么做出来的

- **歌词和逐字时间**：用户发来的是卡拉 OK 式的滚动歌词视频，`源码/kara.py` 逐帧量出每句停稳、每个字被擦亮的时刻；`源码/align.py` 用 Demucs 分出人声、torchaudio 的 MMS_FA 逐句强制对齐，副歌四遍互相核对。结果在 `源码/timing.js`。
- **节拍**：伴奏轨的 onset 包络上网格搜，74.9 BPM，一小节 3.204 秒。
- **画面**：`frame(t)` 只依赖时间，`render.cjs` 用 Playwright 逐帧截图交给 ffmpeg，4 路并行。
  - `core.js`：时间轴、工具、图元、后期（柔光、颗粒、暗角、漏光、色差、录像带倒带、七段数码管日期戳）。
  - `fig.js`：人物（7.3 头身骨架，侧面 / 正面 / 背面，站走跑坐跪躺，十七岁的她和他、长大的两个人、路人；明暗、轮廓光、剪影）。
  - `env.js`：雨、伞、湿地面、散景、拍立得、栀子花和花丛、花瓣、云、星空、银河、萤火虫、城市、手。
  - `scenes1.js`~`scenes7.js`：68 个镜头，按歌的顺序。
  - `main.js`：镜头表、转场、歌词、日期戳、片名、水印、片尾字、封面。
- **声音**（`源码/mix.py`）：只有原曲，按线性增益从 −9.2 调到 −16 LUFS，不剪不挪。
- **字体**：思源宋体、志莽行书、龙藏体、马善政楷书（都是 SIL OFL，Google Fonts 的仓库），构建时下载并校验 sha256，不放进仓库。

## 重新生成

歌曲音频不放进仓库。把用户发来的抖音视频（1080×1440，315.5 秒）放到 `源码/audio/song.mp4`：

```bash
cd 源码
mkdir -p audio && cp 那个视频.mp4 audio/song.mp4
NODE_PATH=$(npm root -g) ./build.sh      # 输出 out/后来.mp4；超过 30 MB 会自动切成 out/后来_1.mp4 …
```

`timing.js` 已经在仓库里。换了音源才需要重新量、重新对齐（要 demucs、librosa、torchaudio、pypinyin）：

```bash
ffmpeg -i audio/song.mp4 -vn -ac 2 -ar 44100 audio/song.wav
python3 -m demucs -n htdemucs --two-stems=vocals -o audio/sep audio/song.wav
mkdir -p audio/stems && cp audio/sep/htdemucs/song/*.wav audio/stems/
python3 kara.py audio/song.mp4    # 从歌词视频量每句的时刻 → kara_chars.json
python3 align.py                  # 逐字对齐 → timing.js（第一次会下载 MMS 对齐模型，约 1.2 GB）
```

预览某几个时间点的单帧：

```bash
NODE_PATH=$(npm root -g) node render.cjs preview 0.5,12.6,73.5 out/pv
```
