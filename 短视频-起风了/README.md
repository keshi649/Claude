# MV《起风了》

> 如果能回到高中，你最想见谁？

一支 5 分 23 秒（323.0 秒）的横屏动画 MV，配《起风了》（买辣椒也用券）整首。讲的是青春和学生时代：故事、角色、场景都是原创的，画面全部由代码逐帧画出来。

**故事**（倒叙）：

- **七年后，回小城**：他坐着绿皮火车回到小城清溪，手里捏着一只发黄的纸飞机，机翼上铅笔写着 2018.6.7。出站前他犹豫了一下，笑自己近乡情怯；走到老街，一阵风把纸飞机吹走了。
- **风吹起了从前**：他追着纸飞机跑进校门——回到了高二开学的那天。天台、运动会的一千米、走廊；纸飞机飘进教室，撞在前排一个女生的马尾上，她回过头，笑了。
- **高中的日子**：上课盯着世界地图发呆、趴在桌上做梦、被粉笔头砸醒、全班哄堂大笑；本子上画满了她；黄昏的天台上弹吉他，她在门口偷偷听；放学后他写了一张纸条折成纸飞机，瞄准她的座位，最后还是塞进了桌肚；太阳雨里他把校服撑在两个人头顶跑；彩虹；黑板旁的倒计时一天天往下翻。
- **七年后的空教室**：楼梯、空荡荡的高三（2）班，课桌上当年刻的像素小怪；墙上的钟倒着转，回到早读课，她在晨光里回头冲他笑。
- **一起的那些日子**：骑车回家、一人一只耳机、晚自习趴在栏杆上看月亮、百日誓师、夜里两扇亮着的窗、第一场雪、元旦晚会、日历翻到 6 月 7 日、拍毕业照时她偏过头看他。
- **毕业**：高考、铃响、满天的试卷、在校服背上签名（她在他背上写了什么，他看不见）、毕业晚会上他弹吉他；散场时她在门口挥手，他把纸飞机背在身后，没拿出来。两列火车擦肩而过，2018 年翻到 2025 年。
- **七年后的她**：她也回来了，站在学校后院的老槐树下，晚风把白色的槐花吹进她的鬓角；树皮上当年刻的小怪长成了一道疤。回忆里，运动会那天她扭了脚，他扶着她走在黄昏的跑道上。她从老家床头的抽屉里拿出一本素描本，里面画的是低着头说话的他。
- **同学聚会**：大家起哄，他终于把纸飞机交给她。拆开，是一张卷子，背面写着"我喜欢你"。风把它吹上了天。她翻开素描本，拇指挪开——画的下面也写着"我喜欢你"，2018 年 6 月。
- **尾奏**：纸在风里折回一只纸飞机，飞进晚霞；七年后再拍一张合影，这回两个人互相看着；天台上，十七岁的他们把一只纸飞机扔向月亮。最后一句："你的青春里，有没有一句没说出口的话？"

画面上的歌词按演唱**逐字亮起**，换场落在小节线和每句的开头上。开头和结尾两句画外音用 CosyVoice 3 配了女声。像素小怪是甜菜之前视频里的 12×8 像素小怪，这次是他画在纸飞机、课桌、本子上的涂鸦，和她书包上的挂件。

## 怎么做出来的

- **歌词和逐字时间**
  - `源码/kara.py`：用户发来的是抖音下载的 m4a，里面带一条竖屏的歌词视频，唱到的字会从白变绿（卡拉 OK）。逐帧量出绿色走到了哪个字，得到每个字开唱的时刻（`kara_chars.json`）；歌词文字是看截图读出来的。
  - `源码/align.py`：Demucs 分出人声，torchaudio 的 MMS 强制对齐（拼音按字母对齐），每句单独开窗。对着人声的频谱看，卡拉 OK 整体比真正开口早 0.25 秒，而对齐的时间正好落在每个字的辅音和换音上，所以以对齐为准；卡拉 OK 挪后 0.25 秒用来给对齐开窗口，对齐把几个字挤在一起时才用它。结果写进 `lyrics.js`。
- **节拍**：`源码/analyze.py`。在 onset 包络上搜出 75.000 BPM（一小节 3.2 秒），各段相位偏差都在 ±6 毫秒以内；按伴奏低频定强拍。人声、伴奏的音量包络和每拍力度写进 `timing.js`。
- **画面**：`frame(T)` 只依赖时间，`render.cjs` 用 Playwright 逐帧截图交给 ffmpeg，4 路并行渲染。
  - `core.js`：工具、缓动、噪声、颜色、文字、音乐包络、纹理（颗粒、暗角、星空、银河、云）、月亮、流星、雨、漂浮的光点。
  - `chars.js`：角色。二维骨骼的侧身（按姿势表摆动作：坐在课桌前、趴桌睡、托腮、弹吉他、骑车、扔纸飞机、挥手、跑……），正面半身（特写），背影；蓝白校服、她的高马尾、七年后的衬衫和开衫长裙、老师、按编号生成的同学。先画到离屏画布上，再按场景打光。
  - `world.js`：夏天的天（积云、太阳、光芒、燕子）、远山、稻田、河、铁桥、绿皮火车、站台、老街、校门、教学楼、操场、河边的路。
  - `world2.js`：教室（侧面看窗户：绿墙裙、吊扇、课桌上一摞摞的书、被风鼓起的窗帘；正面看黑板：倒计时牌、钟、标语）、走廊、天台、火车车厢、她的卧室。
  - `props.js`：纸飞机（新的、发黄的）、吉他、自行车、耳机线、笔记本、素描本里的画、世界地图、满天的试卷、花瓣、雪、彩虹、横幅、照片、粉笔头。
  - `scenes1~5.js`：89 个镜头，按小节和每句歌词排好。
  - `test.html` + `test.js`：角色测试页（`PAGE=test.html node render.cjs preview 0,1,2 out/test`）。
  - `main.js`：镜头表和转场（甩镜头、闪白、虚化、漏光、穿云、倒带……）、逐字亮起的歌词、水印、柔光、调色、暗角、颗粒、封面。
- **声音**：`源码/mix.py`。原曲剪掉开头 0.30 秒的数字静音原样使用；两句画外音（`narrate_cosy.py`，CosyVoice 3 + FunASR 核对）；numpy 合成的音效和环境声（火车、站台、蝉、课间、粉笔头、铃声、太阳雨、翻书、快门、虫鸣……），有人声时让开；成片 −16 LUFS。
- **字体**（都是 SIL OFL）：霞鹜文楷、思源宋体、思源黑体、龙藏体、志莽行书。构建时下载并校验 sha256，不放进仓库。

## 重新生成

歌曲音频不放进仓库。把整首歌（5:21.8，开头有 0.38 秒静音）转成 `源码/audio/song.wav`：

```bash
cd 源码
mkdir -p audio && ffmpeg -i 你的音频.m4a -vn -ac 2 -ar 44100 audio/song.wav
pip install numpy scipy
NODE_PATH=$(npm root -g) ./build.sh      # 输出 out/起风了.mp4，超过 30 MB 再切成 out/起风了_1.mp4 …
```

`timing.js`、`lyrics.js`、`kara_chars.json` 和 `voice_cv3/` 已经在仓库里。换了别的音源（比如开头的静音长度不一样）才需要重跑分析和对齐，这一步要 demucs、librosa、torchaudio、pypinyin：

```bash
pip install demucs librosa torch torchaudio pypinyin soundfile
python3 analyze.py               # 分人声、找节拍 → timing.js
python3 kara.py 抖音视频.m4a      # 从歌词视频里量卡拉 OK → kara_chars.json（只要那条带歌词视频的 m4a）
python3 align.py                 # 逐字对齐歌词 → lyrics.js（第一次会下载 MMS 对齐模型，约 1.2 GB）
```

画外音要重新合成的话，先在后台跑 `bash ../../工具/setup_tts.sh`，再：

```bash
/home/user/tts/venv/bin/python narrate_cosy.py /home/user/tts/CosyVoice /home/user/tts/models/CV3-RL
```

预览某几个时间点的单帧（歌曲时间，成片时间要减 0.30 秒）：

```bash
NODE_PATH=$(npm root -g) node render.cjs preview 0.3,13.5,73.8,166.3,274.6 out/preview
```
