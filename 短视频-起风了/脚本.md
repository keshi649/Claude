## 歌曲是怎么分析的

- **歌词**：用户发来的 m4a 里带一条竖屏的歌词视频（"小白音乐馆"做的），歌词滚动，唱到的字从白变绿。
  - 文字：每一行截一张图，人工读出来，和网上的歌词一致（"措不及防"照视频里的写法）。前 15 行是作词、作曲、编曲等名单。
  - 卡拉 OK 时间：`源码/kara.py` 逐帧量出绿色走到了哪个字（字宽约 27.6 像素），绿色第一次进入某个字的格子就是这个字开唱的时刻。
- **逐字时间**：`源码/align.py`。Demucs 分出人声，torchaudio 的 MMS 强制对齐每句单独开窗。
  - 卡拉 OK 和强制对齐整体差了 0.25 秒（中位数，414 个字），对齐的更晚。画了几句人声的频谱，把两套时间都标上看：对齐的时间正好落在"上"的 sh、"曾"的 c、"世"的 sh 这些辅音和换音上，卡拉 OK 的普遍早一个字左右。所以以对齐为准；卡拉 OK 平移 0.25 秒后，用来给每句开对齐的窗口。
  - 对齐只在唱得快的地方跑偏过："风吹起了从前"的"从前"、两遍"也甘愿赴汤蹈火去走它一遍"的"去走它"，几个字挤在 0.1 秒里，改用平移过的卡拉 OK。两遍副歌同一句的节奏对上了（"蹈火去走它一遍"相对小节线，两遍相差在 0.05 秒以内）。
  - 卡拉 OK 每句开头一两个字是在歌词滚动时变绿的，被遮住了，量不到，这些字只用对齐。
- **节拍**：`源码/analyze.py`。75.000 BPM，一小节 3.2 秒，第 0 小节强拍在 0.612 秒（歌曲时间）；每 30 秒单独搜一次相位，偏差都在 ±6 毫秒以内，全曲没有漂移。每句歌词基本占一小节，全曲 100 小节。

## 声音

- **原曲**：整首原样使用，只剪掉开头 0.30 秒的数字静音（歌曲第 0.38 秒才有声音），结尾补 0.25 秒淡出。
- **画外音**：两句，CosyVoice 3 合成的女声（语速 0.95，加一点混响），都一次合成成功，转写按拼音 0 处出入；"高中"的"中"、"谁""没有""一句"看过音高，声调都对。
  - 开头"如果能回到高中，你最想见谁？"：视频 0.15 秒起，前奏的钢琴里，人声开口（25.8 秒）之前很早就念完了。念的时候原曲压低约 4.5 dB；原曲本身很响（−7.7 LUFS），前奏的钢琴也有 −17 dB 左右，所以画外音放得比上一支 MV 高 6 dB，比钢琴高 8 dB 左右。这段只垫车厢的轰隆声和窗外的风，"咔嗒咔嗒"等念完才开始
  - 结尾"你的青春里，有没有一句没说出口的话？"：歌曲 316.7 秒（成片 5:16.4）起，尾奏最后的钢琴里；念的时候只有夜里的风和虫鸣，片尾卡不加"叮"
- **音效和环境声**：numpy 合成（`源码/mix.py`），没有另加配乐。有人声的地方压低约 8 dB，短促的音效尽量放在两句之间的空隙里。
  - 开头：车厢的轰隆声、车轮过接缝的"咔嗒咔嗒"、窗外的风；片名起风；汽笛；进站的刹车声
