# 短视频《如果太阳变成黑洞》（"如果……会怎样"系列第 2 集）

> 你晒到的阳光，都是 8 分 20 秒前出发的。

"如果……会怎样"系列第二集，约 0 分 54 秒 的竖屏短视频，电影感画风（和第 1 集同一套三维着色器引擎）。

- **旁白有配音**：CosyVoice 3 合成的女声，字幕按配音的逐字时间出现
- 开头的常见答案"地球会被吸进去吗？"由旁白问出，紧接着大字"不会。"（这句不出字幕）
- 有音效和环境声，**没有配乐**

第 1 集的数据（平均只看 21 秒，流失都在"先解释、后给画面"的地方）决定了这一集的做法：

- 第一帧就是最亮的太阳，1 秒内开始缩成黑洞
- 3 秒内推翻常识，第 6 秒出倒计时
- 先给画面再解释，全片 54 秒

片子讲的是：

- **开头**：金色的太阳缩成一个点，镜头冲过去，黑洞背后的银河被弯成一圈。"太阳变成黑洞，地球会被吸进去吗？"——"不会。地球照样绕着它转。"——"可你只剩 8 分 20 秒的阳光。"
- **最后的 8 分 20 秒**：
  - 白天的海，太阳还亮着，倒计时在快进。
  - 上帝视角：太阳最后发出的光是一个往外跑的亮球壳，球壳里面一片黑。它扫过水星、金星，"下一个，就是地球"。
  - 最后三秒，一秒一下。
- **天黑**：倒计时到 0，白天一下子全黑。月亮多亮了一两秒（它反射的光还在路上），然后也灭了，成了挡住星星的一个黑圆。眼睛慢慢适应，满天星星和银河出来了："原来白天，也有满天的星星。"
- **变冷**：海面结冰，温度计往下掉：一周后约 −18°C，一年后约 −73°C（Popular Science 的估算）。
- **深海**：冰壳下面，热泉边的管虫还活着，它们本来就不靠阳光。
- **真实的太阳**：它太轻了，变不成黑洞（要重约 20 倍）。结尾在海上日出上叠一张四条小结的收藏卡："如果只剩 8 分 20 秒的阳光，你想去哪儿？评论区告诉我。"

## 怎么做出来的

流程、工具和踩过的坑见仓库根目录的 `做视频经验.md`（电影感着色器的做法见第二十二节，这一集新加的在第二十三节）。

- **画面**：`源码/js/`。每个镜头一个 WebGL2 全屏着色器，在无头 Chromium（SwiftShader 软件渲染）里逐帧算：
  - `shots/blackhole.js`：太阳（米粒组织、黑子、临边昏暗、日珥）缩成黑洞，引力红移让它越缩越红越暗。光线弯折按史瓦西度规的光子轨道方程在 JS 里用 RK4 积分成表，着色器查表；结尾的"真实的太阳"也用它
  - `shots/orbit.js`：贴近地球（NASA 贴图）看它照样沿轨道转；上帝视角的内太阳系、往外跑的"最后一束光"的球壳、依次变黑的水星和金星
  - `shots/seaday.js`：白天的海（天空、碎金、礁石上的人）、天黑、月亮晚 1.9 秒灭、远处海岸的灯一盏盏亮、银河、结冰的海、日出
  - `shots/vent.js`：深海热泉（2.5D 分层：灯光、黑烟囱、黑烟、管虫、海洋雪）
  - `shots/sky.js`：共用的银河和星星（像素对应的天空角度大时把星星抹开，免得闪）
  - `shots/endcard.js`：质量对比条、收藏卡、片尾卡
  - `main.js`：镜头表、转场、倒计时；`overlay.js`：字幕（按配音的逐字时间，带描边）、标注、出处、水印；`gl.js`：渲染、辉光、调色、颗粒
- **旁白配音**：`源码/narrate_cosy.py`（CosyVoice 3 合成，FunASR 转写核对、逐字对时间）。
- **声音**：`源码/audio.py` 用 numpy 合成。
  - 环境声：太空、黑洞边的嗡鸣、海、冷风、深海。
  - 音效：太阳往里缩、冲向黑洞、倒计时滴答、天黑的闷响、月亮灭、冰裂。
  - 短促的音效都放在旁白的停顿里（`工具/sfx_check.py` 查过）。
- **字体**：思源宋体 Noto Serif SC、Cormorant Garamond（SIL OFL），npm 包。
- **地球贴图**：NASA Blue Marble、夜光、海洋、云（公有领域），由 three-globe 2.45.6 的 npm 包分发；构建时下载并校验 sha256，不放进仓库。

## 重新生成

配音已经在 `源码/voice_cv3/` 里，不用再合成：

```bash
cd 源码
pip install numpy scipy
./build.sh > out/build.log 2>&1      # 输出 out/如果太阳变成黑洞.mp4、out/旁白文案.txt、out/封面.jpg
```

预览某几个时刻的单帧（可以缩小出图）：

```bash
node render.js stills 0.5,2.5,7,23,39 out/pv --scale 0.5
```
