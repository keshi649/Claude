# 《如果太阳变成黑洞》短视频脚本（"如果……会怎样"系列第 2 集）

- **规格**：竖屏 1080×1920，30fps，时长约 0 分 54 秒
- **形式**：
  - **旁白有配音**：CosyVoice 3 合成的女声，字幕按配音的逐字时间一段段出现；旁白全文见 `旁白文案.txt`
  - 开头的常见答案"地球会被吸进去吗？"由旁白问出来，紧接着"不会。"——这句不出字幕，画面上打大字
  - 有音效和环境声，**没有配乐**
- **为什么是这个题**：第 1 集《如果月亮掉下来》数据一般（2 秒跳出 32.67%，完播 5.85%，平均看 21 秒）。流失点在 2.5、15.5、30.5 秒，都落在"好看的东西出来之前先解释"的地方。用户在 7 个候选题里选了这个。按数据改了做法：
  - 第一帧就是最亮的画面（太阳），1 秒内开始变（缩成黑洞）
  - 推翻常识在 3 秒内
  - 第 6 秒出倒计时，让人等到"0"
  - 先给画面，再用一句话解释
  - 全片压到 54 秒（第 1 集 79 秒）
- **风格**：电影感，和第 1 集同一套引擎（三维着色器逐帧算光）。
  - 黑洞背后的星光弯成一圈，是按史瓦西度规的光子轨道算的，不是贴图。
  - 太阳有米粒组织、黑子、临边昏暗；缩小时按引力红移变红变暗。
  - 地球用 NASA 的真实贴图。
  - 天黑以后靠"眼睛适应黑暗"（后期曝光几秒里提高约 30 倍），把星星和银河提上来。
  - 字用思源宋体。
- **角色**：没有像素小怪。"你"是海边礁石上坐着的那个人：白天看海，天黑后是银河下的剪影。
- **声音**：
  - 环境声：太空的低鸣、黑洞边的嗡鸣、白天的海浪和海鸥、天黑以后只剩的浪声、结冰海面上的冷风和冰鸣、深海的闷响和热泉的嘶嘶声、太阳表面的低频翻滚。
  - 音效：太阳往里缩的"吸"声、镜头冲向黑洞的气流和闷响、倒计时出现的一声钟、快进的密集滴答、最后三秒一秒一下、黑暗扫过行星的低频、天黑的闷响、月亮灭的下滑音、星星出来的细碎闪光、冰裂、收藏卡的"叮"。
  - 成片约 −16 LUFS。

## 开头 3 秒是怎么设计的

| 时间 | 画面 | 旁白 / 屏幕上的字 | 为什么 |
|---|---|---|---|
| 0.0s（第一帧） | 金色的太阳占满画面中间：米粒组织、几组黑子、橙色的边。大字「WHAT IF · 第二集 / 如果太阳变成黑洞」 | 太阳变成黑洞， | 第一帧就有片名和全片最亮的画面 |
| 0.3–1.1s | 太阳缩成一个点，越缩越红、越暗（引力红移），点的周围已经有一圈被弯折的星光 | （同上） | 第一秒画面就在变 |
| 1.1–1.9s | 镜头冲过去：黑影从一个点长成大半个画面，背后的银河被弯成弧 | 地球会被吸进去吗？ | 替观众问出最常见的答案 |
| 2.9s | **切**：贴近地球，地球一弯亮边，远处一个小黑洞；大字「不会。」+「地球照样绕着它转」 | 不会。地球照样绕着它转。 | 当场推翻（不出字幕，打大字） |
| 5.5s | **切**：白天的海，大字「阳光还剩 08:20」 | 可你只剩 8 分 20 秒的阳光。 | 倒计时：等它走到 0 |

- 前 20 秒切镜头 5 次：2.9（黑洞 → 地球）、5.4（→ 白天的海）、8.3（→ 抬头看太阳）、11.5（叠化到太空）、19.2（→ 背对太阳的海）。`measure.sh` 测出 5.4、8.3、19.2 三次；2.9 秒两边都是黑底的太空，11.5 秒是叠化，测不出来。另外 0.3~1.9 秒是太阳缩小、镜头冲进去，画面一直在大变。
- 前 20 秒的线索：倒计时一直在跑，"下一个，就是地球"——到 0 会怎样，要看下去才知道。

## 关于事实与出处

| 片中的说法 | 依据 | 说明 |
|---|---|---|
| 太阳变成黑洞，地球不会被吸进去，照样绕着转 | 轨道只取决于中心天体的质量；质量相同的黑洞，在地球这么远的地方引力和太阳一模一样（牛顿引力，广义相对论在这个距离上也一样） | 假设的情景：太阳"突然"变成同样质量的黑洞。它的视界只有约 3 公里（史瓦西半径 2.95 km） |
| 只剩 8 分 20 秒的阳光 | 日地平均距离 1 天文单位 ÷ 光速 ≈ 499 秒 ≈ 8 分 19 秒 | 片中用常说的"8 分 20 秒"，倒计时按 500 秒走 |
| 水星、金星先黑 | 水星 0.387 天文单位（约 193 秒），金星 0.723（约 361 秒） | 这是上帝视角。从地球上看，所有行星都是在太阳"灭"之后才变黑，因为它们反射的光绕了远路 |
| 天一下子全黑 | 白天的蓝天是被大气散射的阳光，阳光一停，天光同时没了 | |
| 月亮多亮了一两秒 | 月亮离地球约 38 万公里，光走 1.3 秒；画面里是凸月，它比地球离太阳远一点，最后一束阳光到它那儿还要晚约 0.6 秒，加起来约 1.9 秒 | 片中月亮在天黑后 1.9 秒灭 |
| 白天也有满天的星星 | 星星一直在天上，白天被散射的阳光盖住了 | |
| 一个星期零下 18 度，一年后零下 73 度 | Popular Science《What would happen if the sun went out?》（Holly Otterbein，2008 年 11 月刊）：一周内全球平均地表温度降到 0°F（约 −18°C）以下，一年后约 −100°F（约 −73°C） | 文章没写这两个数是谁估的；别的估算有快有慢。画面上写了"估算"和出处，温度计旁注明是"全球平均气温" |
| 冰壳下面，深海热泉边的生命还活着，它们本来就不靠阳光 | 同一篇文章：海面结冰，冰反倒把下面的海水保温，海洋几十万年都冻不透；地壳里的一些微生物能活下来。深海热泉的生态靠化能合成：微生物用热泉冒出来的硫化物等化学物质取得能量，不靠阳光（海洋学的常识，如 NOAA 海洋探索的科普） | 片中画的是管虫（示意）。严格说，管虫呼吸用的氧最初也来自光合作用，只是海里存的氧够撑很久 |
| 真实的太阳太轻，变不成黑洞 | NASA：恒星要比太阳重约 20 倍，最后才可能变成黑洞；太阳约 50 亿年后变成白矮星 | 质量条只在画面上，不念数字 |
| 开头的黑洞样子 | 史瓦西黑洞：用光子轨道方程 u'' = −u + 1.5u² 数值积分，算出每条视线弯到哪个方向，再去取背后的银河和星星 | 从地球上看不到它（太小）；开头是从很近的地方看的样子 |

- 点名的研究 / 出处：Popular Science 的估算、NASA——2 项（"光走 1 个天文单位约 500 秒"是常识物理）。
- 外国人名、地名：没有。
- 关键数字：8 分 20 秒、零下 18 度、零下 73 度——3 组（"约 20 倍""50 亿年"只在画面的出处里，不念）。

## 旁白配音

- CosyVoice 3（Fun-CosyVoice3-0.5B-2512 的 RL 版）零样本合成女声。
  - 语速 1.15 倍。第 1 集用 1.1 倍，实测每秒 4.5 个字，偏慢；这集每秒约 4.9 个字。
  - FunASR 把每句转写回文字、按拼音和原稿比，再逐字对时间（`源码/narrate_cosy.py`）。
- 念法和字幕不一样的：
  - 数字写成汉字（八分二十秒、零下十八度、零下七十三度）。
  - "绕着它转"的"转"标 zhuàn，"冰壳"的"壳"标 ké，"变不成"的"变"标 biàn。
- 声调核对（`工具/tone_check.py`）：
  - w1 第一版"变不成"的"变"音高从 293 一路升到 482 Hz，转写成了"编不成"。标 `[b][iàn]` 重合成后，从 299 降到 212 Hz（四声），转写回到"变"。
  - 看过、不用改的：
    - h1 的变（biàn，318 → 234 Hz 下降）
    - 转（zhuàn，338 → 203 Hz 下降）
    - 壳（ké，先低后升到 362 Hz）
    - l1 的还（hái，236 → 368 Hz 上升）
    - 一下子的"一"（变调 yí，190 → 271 Hz 上升）
    - 跌（diē，高平略降）
- 转写里不算错的：
  - 同音字：它 / 他、它们 / 他们。
  - l1 的"好好地"转写成"好好的"：这里"地"本来就念 de；按拼音比时"地"按默认的 dì 算，所以这句报了 0.15 的读错率，三次都一样，不是真错。
- 成片转写：整条转写和逐句转写（工具/asr_full.py、工具/line_asr.py）：16 句按拼音全对，没有被音效盖住的字；唯一的出入是 l1 的"好好地"转写成"好好的"（这里本来就念 de）

## 制作方式

- 画面：`源码/js/`，WebGL2 全屏着色器，无头 Chromium（SwiftShader 软件渲染）逐帧算。
  - 每个镜头一个着色器：黑洞 / 太阳、太空、海边、深海、片尾。
  - 辉光、ACES 色调映射、调色、暗角、颗粒在最后一遍合成。
  - 镜头表和转场在 `js/main.js`，时间全从 `timeline.js`（按配音生成）来。
- 黑洞：`js/shots/blackhole.js`。在 JS 里按镜头离黑洞的距离，用 RK4 积分 1024 条光线，做成"视线角 → 最后飞出去的方向"的表，着色器查表。被压缩的地方用像素对应的天空角度把星星抹开，免得闪。
- 声音：`源码/audio.py`，numpy 合成；和画面用同一套时刻（太阳缩小、镜头冲过去、倒计时、天黑、月亮灭）。
- 地球贴图：NASA Blue Marble、夜光、海洋、云（公有领域），由 three-globe 2.45.6 的 npm 包分发，构建时下载并校验 sha256，不进仓库。
