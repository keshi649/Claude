# 资源清单

只列我认为最值得花时间的，每项一句话说明为什么。链接会变，按名字搜索即可。

## 宇树的开源代码（GitHub：unitreerobotics）

1. **unitree_sdk2 / unitree_sdk2_python**：宇树机器人的开发包，C++ 和 Python 两个版本，基于 CycloneDDS。所有开发的起点。
2. **unitree_ros2**：ROS 2 接口说明和示例，讲清楚了 SDK2 和 ROS 2 如何直接互通。
3. **unitree_mujoco**：基于 MuJoCo 的仿真器，接口和真机一致，带地形生成器。第 19 章项目一用它。
4. **unitree_rl_gym**：基于 Isaac Gym 的强化学习框架，含 Train → Play → Sim2Sim → Sim2Real 全流程。第 19 章项目二用它。
5. **unitree_rl_lab**：基于 Isaac Lab 的新一代强化学习框架。
6. **xr_teleoperate**：用 XR 头显遥操作人形机器人并录制数据。
7. **unitree_lerobot**：把宇树人形机器人的数据接到 LeRobot 训练和部署。
8. **unitree_sim_isaaclab**：和真机接口一致的 G1、H1-2 仿真环境。
9. **unifolm-world-model-action、unifolm-vla**：宇树开源的世界模型和 VLA 模型。

## 其他开源工具

10. **legged_gym**（苏黎世联邦理工学院）：GPU 并行训练腿足机器人的经典框架，unitree_rl_gym 的前身。
11. **LeRobot**（Hugging Face）：模仿学习和 VLA 的开源工具库，支持低成本机械臂。第 19 章项目三用它。
12. **MuJoCo**：精确、轻量的物理仿真器，免费开源。
13. **Isaac Lab**（英伟达）：GPU 并行的机器人学习平台。
14. **ROS 2 和 Nav2**：机器人软件框架和导航框架。
15. **elevation_mapping**（苏黎世联邦理工学院）：腿足机器人高度图的经典实现。

## 书和课

16. **Lynch、Park《现代机器人学》**（*Modern Robotics*）：运动学、动力学、规划、控制的系统教材，有免费在线版和配套视频课。
17. **梶田秀司《人形机器人》**（机械工业出版社中译本）：ZMP 和人形机器人行走控制的经典。
18. **Sutton、Barto《强化学习》**（第二版）：强化学习的标准入门书，作者公开了在线版。
19. **Russ Tedrake *Underactuated Robotics***：麻省理工学院的公开课和讲义，讲腿足、不稳定系统和优化控制。

## 一手资料

20. **宇树科技招股说明书**：上海证券交易所官网、巨潮资讯网可下载。读“业务与技术”“财务会计信息与管理层分析”“风险因素”三节。
21. **宇树开发者文档中心**：各型号的开发说明、接口定义和例程。

# 一页速查卡

## 参数速读：每个数字先问一句

| 参数 | 先问一句 |
|------|------------|
| 重量 | 带不带电池？ |
| 自由度 | 含不含手？是不是主动的？分布在哪？ |
| 最大关节扭矩 | 是哪个关节？峰值还是额定？ |
| 速度 / 负载 / 爬坡 | 在哪测的？持续还是极限？ |
| 电池 / 续航 | 换算成 Wh 是多少？什么工况？ |
| 算力 | 主控还是开发算力？TOPS 是什么精度？ |
| 传感器 | 有没有深度相机、力传感器？ |
| 二次开发 | 哪个版本才开放底层？ |

## 看演示视频：五个问题

1. 遥控、预编程，还是自主？
2. 剪辑了吗？倍速了吗？
3. 环境是不是布置过的？
4. 成功率多少？
5. 换个场景、换个物体，还能再来一次吗？

## 看一家机器人公司：三把尺子

1. **关节**：身体好不好、贵不贵、耐不耐摔？
2. **控制**：站得稳不稳，学新动作快不快？
3. **数据**：有没有办法持续、便宜地拿到真实世界的数据？

## 家里、实验室的机器人：安全六问

1. 固件是最新的吗？
2. 默认密码改了吗？
3. 不用时蓝牙、热点、远程访问关了吗？
4. 网络和重要设备隔离了吗？
5. 相机和麦克风的数据去了哪里？
6. 知道怎么一键急停吗？
