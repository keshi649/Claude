# 编辑记录（提示词 10–13：起草 → 发展性编辑 → 行文润色 → 事实核查）

每章写完后做了四件事：
1. **发展性编辑**（提示词 11）：按八个维度自评打分，挑出最该改的地方改掉。
2. **行文润色**（提示词 12）：用 `排版/检查书稿.py` 扫禁用词、长段落、小标题间距、半角标点，再人工去掉空话和 AI 腔。
3. **事实核查**（提示词 13）：正文里每个数字回到 `资料/事实库.md` 对出处；事实库里没有的，现查现补，查不到的改说法或删掉。
4. 重新跑检查脚本，问题清零才进下一章。

## 三、事实核查结论（提示词 13）

**已核实**：正文中所有财务、销量、单价、毛利、成本构成、客户、渠道、募资用途、产品参数、核心技术描述，均对上招股说明书（2026-05 上会稿）或宇树官网；开源仓库的命令、话题名、支持机型对上 GitHub 原文；安全事件对上 CVE 记录和 IEEE Spectrum；论文对上原文摘要。

**需要人工再核实（NEEDS MANUAL VERIFICATION）**：
1. XDog 2015 年获奖：只写"据公开报道""约 8 万元"，没写赛事名（各家说法不一）。
2. G1 关节减速比：两份第三方拆解（约 15:1、22.5:1）不一致，正文写"十几到二十左右"。
3. 四足机器人膝关节"挪到髋部、用连杆传动"：由 Go1 官网"C1-8×1.5 ratio"推断，宇树没有图示。
4. G1 的激光雷达和深度相机"装在头部"：广泛见于产品图，官网参数表没写位置。
5. 上市首日股价、市值：来自新闻，未查交易所原始行情。
6. 美国 2026 年限制联邦采购的法案：只写"据报道有议员提出"，未查最终进展。
7. 1X NEO 的价格和交付计划：来自科技媒体，未查 1X 官方页面。
8. 2025 年国内"数据采集训练场"：写成概括性描述，没有点名具体机构。

**事实可信度自评**：8/10。硬数字可靠；扣分在于部分细节只能靠第三方拆解和媒体报道。出版前最好请一位做过腿足机器人的工程师通读第 4–15 章。
