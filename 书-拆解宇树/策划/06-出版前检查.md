# 出版前检查（对应提示词 16）

规格：《拆解宇树：从一颗电机到会翻跟头的机器人》，甜菜 著。纸书 170×240 mm（小 16 开），黑白内文，平装胶订；电子书 EPUB 3。

原提示词的清单是照亚马逊 KDP 写的。这本是简体中文书，KDP 不收简体中文书（平装和电子书都不收），所以按"国内出版社 + 电子书平台"改写，KDP 相关的几项单独放在最后。

下面每一项都是实际量出来的（2026-10-23，构建命令 `bash 排版/build.sh all`，封面 `bash 排版/封面/做封面.sh`）。⚠ 是最容易漏的五项。

## 四、封面（`成品/封面-*.pdf/jpg`）

- [x] 正封 170×240 mm，四边各加 3 mm 出血。
- [x] 展开图 355.5×246.0 mm，算法是 3＋170＋9.5＋170＋3 毫米宽，加上下出血。
- [ ] ⚠ **书脊宽度要印厂确认**：9.5 mm 是按 80 克胶版纸估的（页数 ÷ 2 × 0.1 mm，再加 0.5 mm 封面纸）。换纸就要重算：改 `排版/封面/做封面.sh` 里的公式，重跑一遍。
- [x] 书脊文字：书名、副书名、作者都排在书脊中线上。书名用 16 pt，左右各留约 2 mm；书脊最后画，不会被正封的出血盖住。书脊如果变窄（比如换薄纸），书名字号也要跟着缩小。
- [x] 缩略图测试：100 像素宽时书名"拆解宇树"清楚可读，橙色的减速器盘一眼能看到；转灰度也清楚。副书名在这个尺寸下读不出来，这很正常。
