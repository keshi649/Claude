# 风格样张

用户问："如果让你自由发挥做视频，你会做什么内容？你会做什么视频风格？每个视频风格都要配一张图示例，不要参考之前的任何经验和内容。"

这里是那次的回答配的图：8 种画法，每种一张 1080×1920 的竖屏画面，都用代码画出来（HTML / SVG / Canvas / WebGL，Playwright 截图）。没有翻库里的旧视频、`短视频方法论.md` 和 `做视频经验.md`，也没用像素小怪。

总的方向是"镜头拍不到的东西"：太小的、藏在里面的、太久以前的、太远的、只能用数据看见的、心里发生的。每一类配一种画法。

## 重画

```bash
cd 风格样张/源码
npm install            # 字体（fontsource 的思源宋体/黑体、马善政、霞鹜文楷、站酷快乐体等），约 250 MB，不进仓库
node render.mjs        # 全部重画，图输出到上一级目录
node render.mjs ink    # 只画一张（名字见 render.mjs 里的 PAGES）
```

## 画的时候踩到的坑

- `@fontsource/lxgw-wenkai` 没有 400 字重，只有 300 / 500 / 700。链接 `400.css` 会 404，字会悄悄退回系统黑体。
- 在 canvas 上写字前要先 `document.fonts.load('字重 字号 "字体"', '要写的字')`，等加载完再画；fontsource 的中文字体按字切了很多小文件，不带上要写的字就加载不到。
- JS 里 `-x ** 2` 是语法错误，要写 `-(x ** 2)`。页面一报错，`window.__done` 永远等不到；`render.mjs` 现在一报错就停下并打印错误。
- 命令输出接了 `| grep` 会被缓冲，进程被杀之前什么都看不到。调试时别接管道。
- 2D canvas 每一笔都开 `filter: blur()` 极慢，截图直接超时。先画到离屏画布，再整张模糊一次叠回去（`micro.html` 的 `withLayer`）。
- 无头 Chromium 里 WebGL2 能用（SwiftShader，启动参数见 `render.mjs`）。黑洞 shader 用 RK4 积分光线，分块绘制，整帧约 10 秒。
- 孔版效果：每种油墨单独一张"版"只存浓度，最后按 颗粒阈值 × 套色偏移 × 正片叠底 合成；大块墨色不匀的低频噪声要双线性插值，不然会出现一格一格的方块。
- 杂志信息图的配色用 dataviz 技能的校验脚本过了一遍：暖灰序数色阶 `#5f584e / #878071 / #aca393` + 红 `#d23a1e`，最浅那档对纸色只有 2.16:1，所以图例和事件都直接标了字。
