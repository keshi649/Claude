# 短视频《原始人穿越奶茶店》

> 你的大脑，还住在山洞里。

一支约 2 分钟的竖屏科普短视频，讲**进化错配**：一个原始人穿越进奶茶店，第一口全糖奶茶下去，大脑就拉响了"一级警报"。在他的世界里，甜是奢侈品：野果又小又酸，一年只熟几周；蜂蜜得爬树、挨蜇才掏得到。所以大脑给甜写了一条铁律，"见到就吃光，存成脂肪"。这条铁律只教会大脑"别错过"，从没教过它"够了"。奶茶又把糖和油放在一起，对大脑来说就像丁伯根实验里那颗大得离谱的假蛋。最后镜头转向观众：你的大脑和他是同一款。跟它讲道理没用，能改的是环境。

| 文件 | 说明 |
|---|---|
| `原始人穿越奶茶店.mp4` | 成片：1080×1920，30fps，H.264 + AAC，约 126 秒，响度 −14 LUFS |
| `封面.jpg` | 封面（取自开头爆炸那一帧） |
| `脚本.md` | 开头 3 秒的设计、分镜、全部旁白，以及每个事实的出处 |
| `源码/` | 生成视频用的全部代码 |

## 怎么做出来的

- **配音**：`源码/voice.py` 里有全部台词。它调用 edge-tts（微软神经语音）合成每一句，再根据词边界算出每句、每段字幕的起止时间，写进 `timeline.json` 和 `timeline.js`。画面和声音都按这份时间轴对齐，所以改一句台词，前后的画面会自动跟着挪。
- **画面**：`core.js`（工具、文字、字幕）、`chars.js`（原始人、你、店员、原始大脑）、`props.js`（奶茶杯、奶茶店、野外、蜂巢、蛎鹬……）、`scenes1~3.js`（各场景）、`main.js`（转场、标题、逐帧入口）。`frame(t)` 只依赖时间 t。`render.cjs` 用 Playwright 逐帧截图，交给 ffmpeg 编码。
- **声音**：`源码/audio.py` 用 numpy 合成四种律动（奶茶店、远古木琴和鼓、深夜 lo-fi、结尾的明亮版）和几十个音效。原始人的声音是降调后再加一点失真。旁白开口时，音乐自动压低约 10 dB。
- **字体**：得意黑 Smiley Sans、思源黑体 Noto Sans SC（均为 SIL OFL）。构建时自动下载，不放进仓库。

## 重新生成

```bash
cd 源码
pip install numpy scipy edge-tts
NODE_PATH=$(npm root -g) ./build.sh      # 输出到 源码/out/原始人穿越奶茶店.mp4
```

预览某几个时间点的单帧：

```bash
NODE_PATH=$(npm root -g) node render.cjs preview 1.3,3,5.6 out/preview
```

配音缓存在 `源码/voice/`，不进仓库。只有缺失或改动过的句子会重新合成。
