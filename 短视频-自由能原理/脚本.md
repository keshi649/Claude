# 《大脑只做一件事》短视频脚本

- **题材**：卡尔·弗里斯顿（Karl Friston）的自由能原理
- **规格**：竖屏 1080×1920，30fps，时长 3 分 06 秒
- **风格**：深色霓虹线描。颜色有固定含义，全片统一：
  - **青色**：大脑的预测
  - **琥珀色**：感官信号 / 真实世界
  - **红色**：误差、意外
  - **绿色**：对上了
- **叙事方式**：没有配音。底部白字是旁白，关键词按上面的颜色标出；大标题用得意黑，正文用思源黑体
- **配乐**：全部程序合成。开场是越来越紧的节奏；正片是 96 bpm 的氛围电子：铺底、拨弦琶音和低音

## 开头三秒怎么抓人

开头不讲道理，先让观众**亲身经历一次「预测误差」**：

1. **第 0 帧**就有画面和声音，没有淡入：一颗发光的球正在下落，屏幕上方写着「盯住这个球。」，下面一行小字「别眨眼」。
2. 球按节奏弹了四下，每一下都配一个上行的马林巴音：sol、do、mi、sol。踩镲和低音一起推紧张感，观众会不自觉地等第五下。
3. **第 2.07 秒**：第五下本该落地，球却停在半空，**所有声音同时切断**，连胶片噪点都冻住了，看起来就像手机卡了。
4. **第 2.55 秒**：重低音砸下来，大字「**视频没卡。**」，接着是「是你的大脑，刚刚**猜错了**。」

观众刚才「咯噔」的那一下，正是这支视频要讲的东西。片尾会让同一颗球再弹一次、在同一个位置停下，回收这个开头。

## 关于科学准确性

为了好懂，片中做了几处简化，在这里交代清楚：

- **「意外」**：对应的是信息论里的「惊奇度」（surprisal），−ln p(o)，即某个观测结果在模型下有多不可能。开场的「咯噔」更接近**预测误差**带来的主观感受，用来引出概念。
- **「感官只送上来对不上的部分」**：这是预测编码（predictive coding）的说法。预测编码是实现自由能最小化的一种主流方案，但并非唯一方案。
- **盖子的比喻**：自由能 F = 惊奇度 + KL 散度。KL 散度 ≥ 0，所以 F 永远压在惊奇度上面，这就是片中「差距 ≥ 0」的意思。盖子先往下压到贴住液面，对应**更新信念**（感知），这一步只缩小差距、不改变意外本身；再继续往下压、把液面一起压低，对应**行动**和**学习模型**，这才真正降低了意外。这两步正好对应后面的「两条路」。
- **「≈ 预测误差的总和」**：在高斯假设下，自由能约等于按精度加权的预测误差平方和，再加上一个复杂度项，所以字幕写的是「大致」。
- **马尔可夫毯**：在统计意义上把系统内部和外部隔开的那组状态。细胞膜是最常用的直观例子。
- **黑屋子难题**：这是对自由能原理的经典质疑。标准回答有两条：一是生物体对「吃饱、体温正常」带有先验期望，所以饥饿本身就是意外；二是行动要最小化的是**预期自由能**，其中包含「信息增益」（认知价值）这一项，这就推出了探索和好奇。
- **争议**：自由能原理是否可证伪、能解释多少东西，学界一直有争论。片尾特意加了注释。
- **乱序汉字**：改编自网络流传的「研表究明」段子，用来演示自上而下的预测如何影响阅读，不代表任何具体研究结论。

## 制作方式

画面全部用 Canvas 代码绘制（`源码/film.js`），由 Playwright 逐帧截取，再用 ffmpeg 编码；配乐与音效由 `源码/audio.py` 用 numpy 合成。字体用的是思源黑体和得意黑，都是 SIL OFL 开源许可。重新生成的步骤见 `README.md`。
