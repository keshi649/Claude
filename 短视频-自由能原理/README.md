# 短视频《大脑只做一件事》

> 你看见的世界，是大脑最好的一次猜测。

一支 3 分 06 秒的竖屏科普短视频，讲卡尔·弗里斯顿的**自由能原理**。主要内容：
- 大脑关在漆黑的颅骨里，只能靠猜；
- 它真正处理的是「猜错了多少」；
- 活着就是把「意外」压到最低；
- 自由能是压在意外头顶上的一块盖子；
- 降低误差只有两条路：改猜测，或者改世界；
- 黑屋子难题怎么推出好奇心。

**开头三秒**：一颗球随着越来越紧的节奏弹跳，第五下本该落地时，球停在半空，声音全断，像手机卡住了。0.5 秒后打出大字「视频没卡。是你的大脑，刚刚猜错了。」也就是说，观众先亲身经历一次「预测误差」，再听解释。片尾让同一颗球再弹一次，回收这个开头。

## 怎么做出来的

- **画面**：`源码/film.js` 用 Canvas 2D 把每一帧画出来，`frame(t)` 只依赖时间 t，同一个 t 永远画出同一张图。`render.cjs` 用 Playwright 逐帧截取，再交给 ffmpeg 编码。
- **声音**：`源码/audio.py` 用 numpy 合成全部声音：马林巴、拨弦、铺底、低音、鼓，以及几十种音效（故障声、蜂鸣、水花、唱片刮擦、开门声……），时间点与画面对齐。开场的弹球放在单独一条总线上，定格那一刻连混响一起切掉，保证那 0.5 秒是真正的数字静音。
- **字体**：思源黑体 Source Han Sans SC 和得意黑 Smiley Sans，都是 SIL Open Font License。构建时自动下载，不放进仓库。

## 重新生成

```bash
cd 源码
NODE_PATH=$(npm root -g) ./build.sh      # 输出到 源码/out/大脑只做一件事.mp4
```

预览某几个时间点的单帧：

```bash
NODE_PATH=$(npm root -g) node render.cjs preview 0,2.3,15.8 out/preview
```
