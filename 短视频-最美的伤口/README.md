# MV《最美的伤口》

> 你要走的时候，我明明想挽留。

一支 42.9 秒的横屏像素动画 MV，配用户发来的《最美的伤口》（小睿）片段。故事、场景、镜头都是新的，画面全部由代码逐帧画出来；两个主角用的是甜菜之前视频里的 12×8 像素小怪："我"是原色，"你"是粉色、头上别一朵小白花。没有配音，只有原曲；成片和歌一样长。

**故事**：分开那天没说出口的"别走"，后来变成了心上一道金色的伤口。

- **雨夜**：路灯下，你拖着行李箱走了。我伸出手想挽留，却像木偶戏台上被线吊着的木偶；气泡里的"别走"碎成像素掉了下去。
- **空街**：线断了，我转过身，长街尽头的小粉点淡进雾里，路灯从远到近一盏盏灭掉。眼泪顺着脸流下来，滴进水洼。
- **回忆**：水里的倒影慢慢变暖，身边多出一个你。镜头扎进水里：牵着手走过热闹的夜市；同一条长街，灯全亮着、满街的人；灯笼飘起来，云里游出一条鲸鱼，驮着两个人游过大月亮。
- **世界尽头**：鲸鱼把我们放在世界尽头的浮岛上，走着走着，你化成粉色的光点散了，我一个人走到崖边。
- **最美的伤口**：抱在身前的心裂开，光点飞回来钻进裂缝，填成了金色。日出，金色的伤口在发光，天上的星星连成你的样子。

换镜头都落在小节线上（每句歌词 2 小节），歌词按演唱逐字亮起。

## 怎么做出来的

- **歌词**：原视频是一段编曲软件的录屏，底部字幕一个字一个字地出来；每 0.5 秒截一张拼起来读出 9 句歌词。原字幕的"熬油"按意思改成"遨游"。
- **节拍**（`源码/analyze.py`）：伴奏轨的 onset 包络上网格搜速度和相位，94.99 BPM（一小节 2.53 秒）；军鼓在 2、4 拍，镲片和每句开口都在 1 拍。第 1 小节的强拍在 1.485 秒，人声从这里开口。录屏里编曲软件显示的 140 BPM 和音频无关。
- **逐字时间**（`源码/align.py`）：Demucs 分出人声，torchaudio 的 MMS 强制对齐（拼音按字母对齐），每句按小节线开窗。对着人声频谱核对过；同一句"牵着你的手"唱两遍，相对小节线相差 ≤ 0.02 秒。结果在 `源码/timing.js`。
- **画面**：`frame(t)` 只依赖时间，`render.cjs` 用 Playwright 逐帧截图交给 ffmpeg，4 路并行渲染（1286 帧约 1.5 分钟）。
  - `core.js`：时间轴、工具、像素缓冲（场景画在 160×90 到 480×270 的小画布上，再最近邻放大 12 到 4 倍）、像素图元、柔和的光锥（按行量化透明度、screen 叠加，不用抖动）、光晕层、雨、1 位的像素字。
  - `sprites.js`：像素小怪（表情、手臂姿势、背影、转身、眼泪、湿袖子、小白花、按像素化成光点）、行李箱、心（裂缝和金色）、灯笼、鲸鱼。
  - `scenes1.js`：主歌——雨夜路灯、伸手、木偶戏台、"别走"碎掉、线断转身、透视长街灯一盏盏灭、眼泪、水洼倒影。
  - `scenes2.js`：副歌——夜市（三层视差）、热闹的长街、灯笼和鲸鱼、月亮和浮空城堡、世界尽头的浮岛、心和金色裂缝、日出和星座。
  - `main.js`：镜头表、闪白、歌词（逐字亮起、上一句淡出下一句淡进）、暗角、片尾字、水印、封面。
- **声音**（`源码/mix.py`）：只有原曲，按线性增益从 −16.8 调到 −16 LUFS，不剪不挪。
- **字体**：缝合像素字体 Fusion Pixel 12px（SIL OFL），构建时下载并校验 sha256，不放进仓库。

## 重新生成

歌曲音频不放进仓库。把用户发来的抖音视频（1600×720，音轨 42.887 秒）放到 `源码/audio/song.mp4`：

```bash
cd 源码
mkdir -p audio && cp 那个视频.mp4 audio/song.mp4
NODE_PATH=$(npm root -g) ./build.sh      # 输出 out/最美的伤口.mp4；超过 30 MB 会自动切成 out/最美的伤口_1.mp4 …
```

`timing.js` 已经在仓库里。换了音源才需要重新分析、对齐（要 demucs、librosa、torchaudio、pypinyin）：

```bash
ffmpeg -i audio/song.mp4 -vn -ac 2 -ar 44100 audio/song.wav
python3 -m demucs -n htdemucs --two-stems=vocals -o audio/sep audio/song.wav
mkdir -p audio/stems && cp audio/sep/htdemucs/song/*.wav audio/stems/
python3 analyze.py               # 节拍和强拍（结果写在 align.py 开头）
python3 align.py                 # 逐字对齐 → timing.js（第一次会下载 MMS 对齐模型，约 1.2 GB）
```

预览某几个时间点的单帧：

```bash
NODE_PATH=$(npm root -g) node render.cjs preview 0.5,9.5,22.6,30.5,38.9 out/preview
```
