# 歌词 MV《世界上的另一个我》Claude 版

> 世界上会有另一个你吗？——有。准确地说，还有 1,048,575 个。

一支 30 秒的横屏歌词 MV，配阿肆 / 郭采洁《世界上的另一个我》里"上一秒我在台北看烟火"那一段，风格接着上一支 Claude MV。

两只 Clawd，一只在台北看跨年烟火，一只在上海喝 mojito；后来一只去了柏林淋雨，一只在蒙古看星空。两边隔着分屏互相"感觉"，延迟 0 ms。唱到"是世界上的另一个我"时，中线变成一面镜子，`diff` 一下，0 处不同。最后镜头拉到太空，地球上亮起 1,048,576 个 Clawd。

歌词的每个字都踩在演唱的时刻上，换场落在乐句和小节上。

| 文件 | 说明 |
|---|---|
| `世界上的另一个我.mp4` | 成片：1920×1080，30fps，H.264 + AAC，30.4 秒，响度 −14 LUFS。**不在仓库里**：成片带着原曲音频，仓库是公开的；按下面的步骤重新生成 |
| `封面.jpg` | 封面（取自分屏那一段） |
| `脚本.md` | 分镜、歌词时间轴的来历、声音说明 |
| `源码/` | 生成视频用的全部代码 |

## 怎么做出来的

- **歌词时间轴**：先用 Demucs 分离人声，再用 Whisper 听写、wav2vec2 做 CTC 强制对齐，得到每个字的起唱时刻，最后对照音高和节拍网格（133 BPM）人工校正。结果写在 `源码/timing.js`，画面和音效都读这一份。
- **画面**：
  - `core.js`：工具、字效（砸下、弹出、掉落、3D 挤出、烟花成字）、Clawd 和它的表情与配件、HUD。
  - `worlds.js`：台北、上海、柏林、蒙古四个场景，以及像素地球。
  - `scenes.js`：七个镜头和歌词排版。
  - `main.js`：镜头编排和甩镜头转场。

  `frame(t)` 只依赖时间 t。`render.cjs` 用 Playwright 逐帧截图，交给 ffmpeg 编码。
- **声音**：原曲片段原样使用。`源码/mix.py` 用 numpy 给结尾补了几个小音效（风声、计数器的"嘀"、"叮"、气泡、打字声），最后用两遍 loudnorm 统一响度。
- **字体**：思源黑体 Noto Sans SC、JetBrains Mono、Pacifico（均为 SIL OFL）。构建时自动下载，不放进仓库。

## 重新生成

歌曲音频不放进仓库。`timing.js` 里的时间是按知洲给的那段 28 秒片段（6.4 秒前奏，接着唱"上一秒我在台北看烟火"）对的；把这段片段的音轨转成 `源码/audio/song.wav`：

```bash
cd 源码
mkdir -p audio && ffmpeg -i 你的视频.mp4 -vn -ac 2 -ar 44100 audio/song.wav
pip install numpy scipy
NODE_PATH=$(npm root -g) ./build.sh      # 输出到 源码/out/世界上的另一个我.mp4
```

预览某几个时间点的单帧：

```bash
NODE_PATH=$(npm root -g) node render.cjs preview 9.75,16.95,29.9 out/preview
```
