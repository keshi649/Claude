# 《世界上的另一个我》Claude 版歌词 MV 脚本

- **规格**：横屏 1920×1080，30fps，30.4 秒（歌曲片段 27.7 秒 + 结尾 2.7 秒反转）
- **歌曲**：阿肆 / 郭采洁《世界上的另一个我》，用的是这一段：上一秒我在台北看烟火 → 下一秒你在蒙古天际
- **风格**：延续上一支 Claude MV。主角是 Claude Code 的像素吉祥物 Clawd；画面四角固定放着歌名、小节计数和四拍灯、时间码、进度条、"知洲"水印
- **一句话**：情歌里的"另一个我"，在 Claude 这里是字面意思。开场问"世界上会有另一个你吗？"，结尾回答"有。准确地说，还有 1,048,575 个。"

---

## 时间轴怎么来的

1. 用 Demucs 把人声和伴奏分开，只拿人声做识别。
2. 用 Whisper（small、medium、large-v2、large-v3 四个模型）逐句听写，结果交叉核对；歌名和"喝 mojito"这句原词，用网上搜到的歌词确认。
3. 把确定好的歌词交给 wav2vec2 中文模型做 CTC 强制对齐，得到每个字的起唱时刻。
4. 用音高分段（pyin）和节拍网格人工复核。节拍是 133.0 BPM，第 0 拍在 0.412 秒，整段一共 16 小节。复核时发现，每句的"在/就"都落在小节强拍上。
5. 每个字比它开口的时刻早 0.05 秒（1.5 帧）弹出，看起来才像"踩在"字上。

## 声音

- 原曲片段原样使用，不做改动。
- 原曲在 27.7 秒淡出，后面补了几个程序合成的小音效：飞上太空的风声、计数器每翻一倍响一声"嘀"（音高逐级升高）、到 1,048,576 时一声"叮"、气泡弹出、打字声、眨眼时一声轻"哔"。
- 两遍 loudnorm，用线性增益把整体响度统一到 −14 LUFS。
