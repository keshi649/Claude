# 峡谷争锋 · 网页版 5V5 MOBA

一款类似《王者荣耀》玩法的 5V5 推塔对战小游戏，**单个 HTML 文件，打开网页即可游玩**，无需安装、无需联网、没有任何第三方依赖。

## 怎么打开

- **本地**：下载 `index.html`，用浏览器（Chrome / Edge / Safari / Firefox）直接双击打开。
- **手机**：把 `index.html` 发到手机上用浏览器打开，或部署到任意静态网站（如 GitHub Pages）。游戏固定横屏显示：竖着拿手机时画面会自动转成横屏，把手机横过来玩即可。
- 首次点击按钮后才会有声音（浏览器的自动播放限制）。

## 玩法

- 你加入蓝方，与 4 名 AI 队友对抗 5 名 AI 敌人。
- 三条兵线（对抗路 / 中路 / 发育路），每路 3 座防御塔（一塔、二塔、高地塔），必须按顺序推倒；任意一路高地塔被推倒后，敌方水晶才会失去无敌。**击碎敌方水晶即获胜。**
- 敌方塔附近没有我方小兵时，防御塔会减免英雄造成的伤害；在敌方塔下攻击敌方英雄会吸引防御塔的仇恨。
- 野区有蓝 buff（冷却缩减、回蓝）、红 buff（普攻灼烧减速）和普通野怪；河道中有 **暴君**（全队金币经验 + 增伤）和 **主宰**（召唤主宰先锋助推）。
- 草丛可以隐身，战争迷雾会隐藏视野外的敌人。
- 击杀播报：第一滴血、双杀、三杀……五杀、大杀特杀、超神、终结；浏览器支持中文语音时会有语音播报。
- 可以给 AI 队友发信号：进攻（更积极地开团）、撤退（退回己方塔后）、集合（向你靠拢）。
- 首局有新手提示与地面上的金色路线指引（可在暂停菜单关闭）；我方防御塔、水晶遭到攻击时会提示并在小地图上闪烁。
- 最后一击小兵、野怪才能拿到全额金币；装备可在任意位置购买，默认开启「自动购买推荐装备」（可在商店或暂停菜单关闭），左侧会一直显示下一件要买的装备和还差多少金币。
- 开局有 5V5 加载界面；阵亡时显示复活倒计时和击败你的英雄。
- 暂停菜单可设置：滑动屏幕移动视角、镜头视野较远、自动升级技能、自动购买、震动反馈等；切到后台会自动暂停。

## 操作

| | 电脑 | 手机 |
|---|---|---|
| 移动 | `W` `A` `S` `D` / 方向键，或鼠标右键点地 | 左侧按住拖动虚拟摇杆 |
| 普通攻击 | `J` / 空格 / 鼠标左键（按住连续攻击，英雄优先） | 右下角大按钮 |
| 补刀 / 推塔 | `K` 只打小兵和野怪 · `L` 只打防御塔和水晶 | 攻击键旁的两个小按钮 |
| 锁定目标 | 鼠标左键点敌人 | 轻触画面上的敌人 |
| 移动视角 | 按住鼠标中键拖动，`Y` 回到英雄；拖动小地图 | 在空白战场上滑动（松手有惯性），或拖动小地图；点「回到英雄」或一移动就自动回正 |
| 技能 1/2/大招 | `Q` `E` `R`（或 `1` `2` `3`），按住瞄准鼠标方向，松开释放，`Esc` 取消 | 轻点自动瞄准；按住拖动出现轮盘手动瞄准，拖到「取消施法」松开取消 |
| 学习 / 升级技能 | 点技能旁闪烁的 `+`，或 `Shift` + `Q` `E` `R` | 点技能旁闪烁的 `+` |
| 召唤师技能 | `F` | 「闪」等按钮 |
| 回城 / 恢复 | `B` / `H` | 「归」/「愈」 |
| 商店 / 战绩 / 托管 | `P` / `Tab` / `T` | 左侧金币按钮 / 右上「绩」/ 暂停菜单 |
| 指挥队友 | `Z` 进攻 · `X` 撤退 · `G` 集合 | 小地图右侧「进 / 撤 / 集」 |

摇杆、技能拖动的方向按屏幕方向换算，手指往哪推英雄 / 技能就朝屏幕上的哪个方向；冲刺途中按下的技能会在落地后自动放出（预输入）。

和王者荣耀一样手动加点：每升一级获得 1 个技能点，普通技能等级不能超过英雄等级的一半，大招在 4 / 8 / 12 级可升级（最高 15 级）。不想手动加点可在暂停菜单打开「自动升级技能」。

## 英雄

| 英雄 | 定位 | 特点 |
|---|---|---|
| 苍岳 | 坦克 | 冲锋击飞、护盾减速、跃击群体晕眩 |
| 燕赤霄 | 战士 | 全能吸血，回旋斩、突进、天降一剑 |
| 夜刃 | 刺客 | 影袭刷新、飞镖减速、瞬身斩杀残血 |
| 云汐 | 法师 | 火球消耗、冰霜禁锢、流星晕眩 |
| 灵羽 | 射手 | 分裂箭、穿透箭、跨半图的晕眩神箭 |
| 花语 | 辅助 | 禁锢、群体治疗、群体护盾与解控 |
| 雷鸣 | 法师 | 连锁闪电、落雷、雷牢，三层雷印晕眩 |
| 红莲 | 射手 | 灼烧普攻、翻滚强化、散射击退、火箭轰炸 |

召唤师技能可选 闪现 / 惩击（打野）/ 治疗；电脑难度可选 简单 / 普通 / 困难。

## 技术说明

- 纯 HTML5 Canvas 2D + 原生 JavaScript，全部代码在 `index.html` 一个文件里；美术（斜 45° 视角地形、关节骨骼角色、技能与装备图标）全部由代码实时绘制，音效由 WebAudio 合成。
- 标题字体从 Google Fonts 异步加载，加载不到（离线或网络受限）时自动使用系统字体，不影响打开和游玩。
- AI：兵线/打野/游走分工、团战强弱评估、残血撤退回城、躲技能、抢暴君主宰、后期抱团推进。
- 在地址后加 `?test` 会暴露 `window.__game` 调试接口（用于自动化测试，普通游玩无需理会）。
