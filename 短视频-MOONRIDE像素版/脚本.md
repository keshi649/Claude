# 《MOONRIDE》像素版 脚本

## 要求

- 用户发来 Hearts2Hearts《MOONRIDE》的官方 MV（1280×720，24fps，3 分 13.4 秒），原话："做成像素风"。
- 问过一次（三个问题，带推荐项）：
  - 做法：**照原片重画像素动画**（没选"给原片套像素滤镜"——画面还是原片的人和镜头，容易被判搬运；也没选"只用歌、讲新故事"）。
  - 角色：**画成像素女孩**（不用 Claude 像素小怪）。
  - 画幅：**横屏 1920×1080**，和原片一样。
- 照 CLAUDE.md 里 MV 的规矩：只放原曲，不加画外音、音效，成片和歌一样长；水印"甜菜"、片尾"甜菜 出品"、封面、文案照旧；只发完整版。
- 不翻库里旧视频的画面和代码（用户说过"不要参考库里面的视频"）：引擎、人物、场景全部新写。

## 怎么"照原片重画"

1. 用 ffmpeg 的 `select='gt(scene,0.28)'` 量出原片 124 个切点，每个镜头取中间一帧，带时刻拼成五张总表；长镜头（片头、屋顶、电梯井、车门、THE END、结尾）每 0.5 秒再拼一张，看清楚里面的动作。
2. 镜头表照原片的切点排（成片时间 = 歌曲时间），每个镜头画原片里的同一件事：同样的场景、构图、动作、颜色，用像素画重新画出来。原片里很短的镜头（0.4~0.9 秒）也保留，节奏和原片一样。
3. 人物不画真人的五官：八个成员只取发型、发色、衣服，画成同一套像素女孩。
4. 原片里车上的品牌、片头的电视台标志、结尾的公司标志都不画；结尾公司标志那 3.4 秒换成"甜菜 出品"片尾卡（写明歌曲、"照原版 MV 逐镜重画"、"像素画面：Claude 用代码生成"）。
5. 原片 173.5~182 秒（THE END、气球飞走）本来就没有声音，照原样留着。

## 开头怎么留人（原片的开头本来就很密，照着做）

- 第一帧：霓虹片名"MOONRIDE"（两个 O 是心）已经亮了一半，剩下的字母一个个闪着亮起来；底下是一个小光线追踪画的夜城大道，镜头往广场中间的心形喷泉推。
- 3.4 秒城里的灯一片片灭掉，整座城变成月光的蓝白色，只有喷泉的心还亮着（结尾 172.5 秒俯拍的心形雕塑回收它）。
- 前 20 秒照原片切 15 次：楼面上的窗拼成心、一格格灭 → 老电影院的光柱 → 窗又一格格亮起来 → 花丛里的车 → 举起相机、闪光 → 取景框里的紫色山丘 → 车里回头 → 粉色对讲机 → Need HEART 石碑 → 冰块里的她 → 霓虹心特写 → 湖边的毛绒小马 → 山顶冲过去的车。
- 伏笔：Need HEART（需要一颗心）→ 52~59 秒扛着心形大锤把冰块里的人砸出来；冰块和冻住的小马 → 后半段小马在花园里活过来、满天飞；车顶上的心形气球 → THE END 时从三辆车上飞走。

## 怎么做出来的

- 像素网格 480×270，出片时最近邻放大 4 倍到 1920×1080；全片像素一样大。
- 引擎是纯 Node（不开浏览器）：类型数组上的扫描线多边形、椭圆、粗线、心形、Bayer 抖动渐变、台阶状光晕、离屏层 + 描边 + 侧逆光、发光层模糊加回（泛光）。一帧约 40 毫秒，4 路并行整片 5802 帧约 2 分钟。
- 人物（`girls.js`）：半身像按像素判断头发 / 脸 / 衣服，五官用图元画（眼睛分小、中、大特写三档）；侧脸、背影、全身（关节角度摆姿势：站、走、跳舞、坐、挥手、抱东西）。
- 场景、道具（`props.js`、`scenes1~4.js`）：夜城（光线追踪）、楼面的窗、电影院、SUV（侧面、正面、车尾、顶视）、冰块、闪粉石碑、毛绒小马、心形锡箔气球、毛绒心、门、蘑菇、喷泉、云海、彩虹路、粉色小城、花园迷宫、沙丘。
- 声音（`mix.py`）：只有原曲，量出 −7.8 LUFS，线性增益 −8.2 dB 调到 −16 LUFS，不压缩、不剪。
