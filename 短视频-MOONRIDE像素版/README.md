# MV《MOONRIDE》像素版

> 霓虹的月亮城、冰块里的她、一把心形大锤、满天飞的毛绒小马——Hearts2Hearts《MOONRIDE》官方 MV，逐镜头重画成像素动画。

用户发来 Hearts2Hearts《MOONRIDE》的官方 MV，说"做成像素风"。问过以后定下：**照原片的镜头逐个重画成像素动画**（不是给原片套滤镜）、**成员画成像素女孩**、**横屏**。
一共 136 个镜头，切点照原片排（成片时间 = 歌曲时间），每个镜头画原片里的同一件事；八个成员只取发型、发色、衣服，画成同一套像素女孩，不画真人的五官。
只有原曲，没有配音、音效，成片和歌一样长。

## 怎么做出来的

- **一套像素网格**：整片画在 480×270 上，出片时 ffmpeg 最近邻放大 4 倍到 1920×1080。
- **纯 Node 的像素引擎**（`源码/engine.js`）：不开浏览器，在类型数组上画扫描线多边形、椭圆、粗线、心形、Bayer 抖动渐变、台阶状光晕；人物和道具先画在离屏层上，描边、加侧逆光再贴回去；发光层模糊后加回去做泛光，画在前面的东西会挡住身后的光。`frame(t)` 只看时间，4 路并行，整片 5802 帧约 2 分钟。
- **人物**（`girls.js`）：八个女孩的发型、发色（黑长直、橘色长卷、栗色波波头、黑发齐刘海、深棕长卷、蓝黑侧分、粉色长发、棕色空气刘海）；半身像、大特写、侧脸、背影、全身（站、走、跳舞、坐、挥手、抱东西）。
- **场景**（`scenes1~4.js`）：光线追踪画的夜城大道和霓虹片名、拼成心的窗、电影院、花丛里的车、取景框、闪粉的 Need HEART 石碑、冰块、心形谷地、钟楼门、薄荷绿展厅和胶囊电梯、红色天空和心形大锤、后视镜、云海上的柱子、毛绒心、对称的舞、车尾塞满毛绒心、天窗、车里长出的草地、飘着门的草地、紫色心形气球、修剪花园、彩虹路、心形云洞、粉色小城、毛绒小马的花园、THE END 和花园迷宫、粉色沙丘、片尾卡。
- **字**：缝合像素字体 Fusion Pixel 12px（SIL OFL）。用到的字已经取成点阵放在 `源码/glyphs.json`（`源码/mkfont.py` 生成，字体文件的 sha256 写在脚本开头），出片时不用下载字体。
- **声音**（`源码/mix.py`）：只有原曲，量出 −7.8 LUFS，线性增益 −8.2 dB 调到 −16 LUFS，不压缩、不剪。

## 重新生成

原曲不放进仓库。把原版 MV 的音轨导出来放在 `源码/歌曲.wav`：

```bash
cd 短视频-MOONRIDE像素版/源码
ffmpeg -i 原版MV.mp4 -vn -ac 2 -ar 44100 歌曲.wav
bash build.sh                                  # → out/MOONRIDE像素版.mp4（约 2 分钟）
node render.js sheet 1,18.6,83,174 预览.ppm 2 1   # 几个时刻拼一张预览图
node render.js cover 封面.ppm                      # 封面（1920×1080）
```
