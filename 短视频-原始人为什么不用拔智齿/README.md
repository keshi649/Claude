# 短视频《原始人为什么不用拔智齿？》

> 他们的下巴，是嚼大的。

进化错配系列的第二支，接着《原始人为什么不近视？》。一支约 2 分 37 秒的竖屏像素风科普短视频，**没有配音、没有配乐**，只有字幕和音效：字幕不再逐字对应讲解，而是直接解释画面和内容。

如今大约每 4 个人就有 1 个阻生智齿，可在工业化以前，这个比例不到 1/20。片子把下巴画成一排停车位：智齿是第三颗大磨牙，18～25 岁才到，来得太晚，后墙堵着，就斜着卡在半路。下巴的"后墙"要靠施工队一点点往后推，而施工队只在收到咀嚼信号时干活。原始人天天啃硬的，下巴长得够长；现代人吃得软，下巴少长了一截，智齿的车位就没了。证据有大鼠实验（吃糊的那组下巴短了约 16%）、世界各地头骨的比较，以及粗粮把牙磨小、整排往前挪的"磨耗"。最后给出攻略：拍片让牙医判断，长正了先观察，反复发炎的该拔就拔。

| 文件 | 说明 |
|---|---|
| `原始人为什么不用拔智齿.mp4` | 成片：1080×1920，30fps，H.264 + AAC，约 157 秒，约 14.6 MB（不超过 30 MB，不用分段）。声音只有音效和环境声，响度约 −18 LUFS |
| `封面.jpg` | 封面（取自开头那一帧，不带字幕） |
| `字幕文案.txt` | 全部字幕按段落排好，带出现时间；画面上的标题、对白气泡和片尾字用〔 〕标出 |
| `字幕.srt` | 带时间码的字幕文件，和成片里的字幕一字不差，可以导入剪映或上传成平台字幕。成片已经带字幕，配着它播放会出现两份 |
| `脚本.md` | 开头 3 秒的设计、分镜、全部字幕，以及每个事实的出处 |
| `源码/` | 生成视频用的全部代码 |

## 怎么做出来的

- **字幕与时间轴**：`源码/script.py` 里有全部字幕。没有配音，所以每条字幕的显示时长按字数估算（大约每秒读 6 个字），再写进 `timeline.json` 和 `timeline.js`。画面和音效都按这份时间轴对齐，改一条字幕，后面的画面会自动跟着挪。`subs.py` 再从时间轴导出 `字幕.srt` 和 `字幕文案.txt`。
- **画面**：`core.js`（工具、像素缓冲、像素字、游戏界面组件、两行字幕、对话气泡）、`sprites.js`（像素小怪）、`props.js`（牙齿、下巴、全景 X 光片、大鼠、食物、牙医行头）、`scenes1~3.js`（各场景）、`main.js`（场景编排、转场、顶栏读数、逐帧入口）。`frame(t)` 只依赖时间 t。`render.cjs` 用 Playwright 逐帧截图，交给 ffmpeg 编码。
- **声音**：`源码/audio.py` 用 numpy 合成几十个游戏音效（打字声、咔嚓、吸溜、推墙、盖章、倒带、牙钻……）和很轻的环境声（诊室、城市、草原、实验室），不含配音和配乐。最后按 EBU R128 把响度定在约 −18 LUFS（和上一集"只有音效"版一致），并做真峰值限幅。
- **字体**：缝合像素字体 Fusion Pixel 12px（界面、对话气泡）、得意黑 Smiley Sans（字幕），均为 SIL OFL。构建时从 npm 下载并校验 sha256，不放进仓库。

## 重新生成

```bash
cd 源码
pip install numpy scipy
NODE_PATH=$(npm root -g) ./build.sh      # 输出到 源码/out/：成片 mp4、字幕.srt、字幕文案.txt
```

预览某几个时间点的单帧：

```bash
NODE_PATH=$(npm root -g) node render.cjs preview 1,35,78 out/preview
```
