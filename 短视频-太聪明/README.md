# MV《太聪明》Claude 版

> 一个太聪明的 AI，总在猜你的心，总想再确认一次。

一支 4 分 24 秒的横屏像素 MV，配陈绮贞《太聪明》整首。画风学的是参考视频那支《等你下课》像素 MV：像素画、上下黑边、斜照的光柱和浮尘、开场一张写着歌名的卡片、下方黑边里的词曲字幕，以及最重要的一点——**歌词不做字幕，而是写在场景里**，随着演唱一个字一个字出现。

主角是 Claude 的像素形象 Clawd（按给的图画：12×8 格，`#CB7C5E`）。它太聪明了：在填字格里把自己写成一个谜，戴着问号纸袋装神秘，一会儿把空调开到 16 度一会儿 30 度；过安检时被 X 光照出胸口的一颗心；在夹娃娃机前算了半天角度还是没夹到；在便利店卖弄，小票机吐出一整条长长的歌词；最后在黄昏把自己的心埋进花盆。副歌里它猜她的心、弹出确认框、踩着十三本书的台阶越爬越高、离她越来越远；第二段副歌里歌词变成星座，星星连成一座桥，它走回她身边。天亮以后，花盆里开出一朵心形的花，它不再猜了，把花送给她。

每一句歌词都有自己的"载体"：填字格、霓虹招牌、窗上的霜、安检 LED 屏、娃娃机跑马灯、小票、小黑板、聊天气泡、确认框、书脊、传声筒的线、到站屏、灯箱广告、公交路牌、星座、便利贴、对话气泡、窗上的水汽。

## 怎么做出来的

- **歌词和时间轴**：发来的音频文件里带着一段音乐播放器的录屏，逐帧找滚动歌词高亮行的变化，得到 31 句歌词和每句的大致起点；Demucs 分出人声，wav2vec2 中文模型做 CTC 强制对齐，得到 344 个字各自的起唱时刻；节拍在 onset 包络上搜索，66.01 BPM，全曲没有漂移。结果写在 `源码/timing.js`，画面都读这一份。
- **画面**：320×150 的像素画，每个像素放大 6 倍（近景放大到 7.5–10.5 倍），正好铺满 1920×900 的画面区。摄像机的小数部分在放大时补上，所以镜头移动是顺滑的、像素依然是方的。
  - `core.js`：像素绘制、像素字（缝合像素字体，二值化后逐字缓存）、分层合成（视差、景深模糊）、光柱、泛光、浮尘、胶片颗粒、暗角、LED 点阵。
  - `chars.js`：Clawd（表情、举手、走路、腮红、汗、胸口的心）和"你"（站、走、坐、托腮、趴着睡、蹲、伸手）。
  - `props.js`：房间、窗外城市（夜 / 黎明 / 白天 / 黄昏 / 雨）、霓虹招牌、霜和水汽、花盆（发芽到开花）、小黑板、路人。
  - `scenes1.js`–`scenes5.js`：按时间顺序的各个镜头。
  - `main.js`：镜头表、转场（叠化、黑场）、片头字幕、开头结尾淡入淡出。

  `frame(T)` 只依赖时间。`render.cjs` 用 Playwright 逐帧截图，交给 ffmpeg 编码。
- **声音**：原曲整首原样使用。`源码/mix.py` 用 numpy 在开头合成 2 秒夜里房间的环境声（底噪、远处的车、钟的滴答），最后用两遍 loudnorm 统一响度。
- **字体**：缝合像素字体 Fusion Pixel 12px / 10px、思源宋体（均为 SIL OFL）。构建时自动下载，不放进仓库。

## 重新生成

歌曲音频不放进仓库。把整首歌（4:19，前奏 6.8 秒）转成 `源码/audio/song.wav`：

```bash
cd 源码
mkdir -p audio && ffmpeg -i 你的音频.m4a -vn -ac 2 -ar 44100 audio/song.wav
pip install numpy scipy
NODE_PATH=$(npm root -g) ./build.sh      # 输出到 源码/out/太聪明.mp4
```

`timing.js` 已经在仓库里。换了别的音源（比如开头多了几秒）才需要重跑分析，这一步要 librosa、soundfile、torch、torchaudio、transformers 和 demucs：

```bash
pip install librosa soundfile torch torchaudio transformers demucs
python3 analyze.py
```

成片太大发不出去时，平分成三段（每段约 88 秒，每段 26 MiB 左右）：

```bash
P=87.867
for i in 0 1 2; do
  for pass in 1 2; do
    ffmpeg -y -ss $(python3 -c "print($i*$P)") -i out/太聪明.mp4 -t $P -c:v libx264 -preset slow -b:v 2300k \
      -pass $pass -passlogfile out/p$i -pix_fmt yuv420p -c:a aac -b:a 160k -movflags +faststart \
      $([ $pass = 1 ] && echo "-an -f mp4 /dev/null" || echo "out/太聪明_第$((i+1))段.mp4")
  done
done
```

预览某几个时间点的单帧（成片时间，等于歌曲时间加 2 秒）：

```bash
NODE_PATH=$(npm root -g) node render.cjs preview 10.5,88,197,245 out/preview
```
