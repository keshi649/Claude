# 峡谷争锋（王者荣耀式 5V5 三维对战）

> 用户原话："做一个王者荣耀游戏"。第一版（`游戏-小怪峡谷`，像素小怪、像素画面）用户说"我要玩的是类似王者荣耀的游戏，你做的这个是什么玩意？你自己擅自做主张搞了很多东西，而且游玩的体验非常差"。
> 问过以后按用户选的重做：画面"3D 像王者"、模式"5V5 三路"，去掉"署名和名单、托管和集合、竖屏自动转"，播报语音留着。

一个打开就能玩的网页游戏（单个 HTML 文件，`峡谷争锋.html`；三维引擎 three.js 从 cdnjs 加载，要联网）。三维斜视角镜头，有光影；六个原创的人物英雄；玩法照王者荣耀的 5V5：三条路、每路三座塔、水晶、小兵、野区、红蓝 BUFF、小龙大龙、回城、恢复、闪现、出装、升级解锁技能、击杀播报。你在蓝方，另外 9 个英雄是电脑。

名字没用"王者荣耀"：那是腾讯的名字和商标，发布出去的网页不能用它的名字、图标和英雄形象，所以英雄、技能、装备都是新起的名字，英雄的样子也是自己设计的。

## 怎么玩

- **目标**：推掉右上角红方的水晶。每条路三座塔，外塔倒了才能打里面的；任意一座高地塔倒了，水晶才能打。小兵 0:30 出第一波，以后每 30 秒一波。
- **手机**：横着拿（竖着拿会提示横过来，对局自动暂停）。按键位置和用法照王者：
  - 左下按住是摇杆（按在哪儿出现在哪儿，推的方向那段圈会亮）。
  - 右下大圆键普攻：按住一直打，英雄优先；左下的小键是**补刀**（只打小兵和野怪，挑血最少的），右上的小键是**推塔**（只打塔）。
  - **锁定**：普攻打到的敌方英雄自动锁定；点屏幕上的敌人、或技能上方出现的敌方头像也能锁定；锁定的敌人头上有红箭头、脚下有红圈，普攻和点按放的技能都先打它；点空地取消。
  - 三个技能围着普攻键：点一下自动放（先打锁定的，再最近的敌方英雄）；按住拖动出现技能轮盘，地上画出范围、方向或落点，拖到右上的"取消施法"松手就不放。冲刺、跳起来的时候按下的技能，落地后接着放。
  - **技能要自己学**：开局有 1 个技能点，每升一级多 1 点，点技能左上角的金色"+"升级（小技能不超过英雄等级的一半，大招 4、8、12 级各能升一级）。
  - 左边一排是回城、恢复、闪现（闪现也能拖着瞄方向）。左上小地图按住能看别处；下面的金币是商店，再下面是推荐装备（钱够了发光，点一下就买）；右上是比分、时间、暂停（点比分也能看战绩）。
  - 残血时屏幕四周泛红；回城时下面有读条。
- **电脑**：WASD 移动，J / 空格普攻，K 补刀，L 推塔，1 2 3 放技能（朝鼠标），Shift+1 2 3 升级技能，F 闪现，H 恢复，B 回城，P 暂停；鼠标点敌人锁定。
- 最高 15 级。野区有红 BUFF（普攻减速、灼烧）、蓝 BUFF（冷却缩减、回血），杀了带 BUFF 的英雄会抢过来。河道里小龙 2:00 出现（全队加钱加经验），大龙 6:00 出现（三条路各出一个先锋帮你推塔）。
- 难度：简单 / 普通 / 困难。队友至少是普通水平，对面按难度来；困难时对面每秒金币多 10%。

你选一个，其余 4 个队友从剩下 5 个里自动排；对面 5 个随机。

## 实测

- 文件：`峡谷争锋.html` 约 590 KB（脚本 575 KB，其中 29 句播报语音的 mp3 共 190 KB）；three.js r128（600 KB）另从 cdnjs 加载。
- 一帧画多少：开局在泉水边约 33 次绘制、11 万个三角形；英雄、野怪一个一次绘制，小兵按兵种和队伍实例化（脚下的淡影子也是一次画完），地图上的树按区块合并；石崖、树、小兵不投实时影子（地上烘了影子）。
- 帧率：这里只有无头浏览器的软件渲染（SwiftShader，一帧几百毫秒），量不出手机上的真实帧率。页面里会自己调：手机从 1.5 倍像素起步，1.5 秒看一次，低于 48 帧先降分辨率再关实时影子，一直很流畅就往上加；画面在模拟的两步之间插值，屏幕 120 帧或掉到 40 帧走起来都不一顿一顿。
- 电脑打电脑（`test/simtest.js`，对局逻辑和第一版一样，只删了托管和集合）：普通难度 10 局 5:5，中位 17 分 49 秒（最短 13:56，最长 25:28），没有超时。第一版调平衡时的 60 局是 29:31。
- 触屏（`test/touch.js`，CDP 多指触摸）28 项全过：开局点"+"学技能、摇杆、摇杆按着同时普攻、补刀键、推塔键、点屏幕上的敌人锁定、点空地取消、敌方头像出现并点头像锁定、拖技能瞄准（技能轮盘跟手、地上有指示）、拖到"取消施法"不放、点技能自动放、闪现拖方向、恢复、回城回到泉水、按小地图看别处 / 松手回来、推荐装备一点就买、商店开关、暂停和继续。
- 键盘（`test/keys.js`）13 项全过：Shift+1 2 3 升级、K 补刀、L 推塔、WASD 走、1 2 3 朝鼠标放、F 朝鼠标闪现、H、B、P。
- 整局（`test/fullgame.js`，测试里让电脑替玩家打）：普通难度射手 12:29 赢、困难难度刺客 13:52 输，都走到结算画面，页面没有报错；显存里的几何体数到后半局稳定在 400 左右（第一次测出死掉的野怪没释放，修了）。
- 热更新（`test/hot.js`）：第一页打到 2:00 拿快照（45 KB），第二页用它启动直接回到这一局的暂停画面，点继续再打 30 秒没有报错。
- 播报：29 句打包后的 mp3 用 FunASR 再转写一遍，按拼音和原文比，0 句有出入；改名后重录的"欢迎来到峡谷争锋"看过每个字的音高（"谷"是低降的三声）。

## 文件

| 文件 | 说明 |
|---|---|
| `峡谷争锋.html` | 成品：一个文件，浏览器直接打开就能玩（语音嵌在里面；three.js 从 cdnjs 加载） |
| `src/data.js` | 地图（兵线、塔、墙、草丛、野怪营地）、英雄和技能数值、装备、难度 |
| `src/sim.js` | 对局逻辑：碰撞格和 A* 寻路、单位、伤害、技能、塔、小兵、野怪、经济、经验、视野（草丛、隐身）；不碰 DOM，node 里也能跑 |
| `src/ai.js` | 电脑英雄：对线补刀、打野抓人、团战判断（双方战力比）、残血撤退回城、守塔、打龙、10 分钟后抱团推进 |
| `src/models.js` | 三维模型：六个英雄（关节能动，烤成一个蒙皮网格）、小兵（拆成身子和两条腿，实例化）、野怪和龙；跑、普攻、放技能、眩晕、倒下的动画 |
| `src/scene.js` | 地图场景：混合四种贴图的地面、河和水面、石崖和树、草丛（会随风摆）、地图外的密林、塔、水晶、泉水、龙坑；镜头 |
| `src/render3d.js` | 每帧把对局同步进场景；弹道、地面特效、粒子、技能瞄准指示、脚下的队伍圈、塔的攻击范围；英雄头像 |
| `src/icons.js` | 技能、装备、召唤师技能的图标（画布上画） |
| `src/hud.js` | 游戏界面：小地图、比分、摇杆、技能键和冷却、推荐装备、血条、伤害数字、播报横幅、击杀记录 |
| `src/input.js` | 触屏（多指）、键盘鼠标；屏幕方向按镜头俯角换算成地上的方向 |
| `src/audio.js` | 音效（WebAudio 现场合成，噪声、正弦、调频 + 混响）、环境声（风、鸟叫，没有配乐）、播报语音 |
| `src/main.js` | 各个画面（开头、怎么玩、选英雄的三维展台、对阵、暂停、商店、结算）、主循环、事件变特效和播报、帧率跟不上时自动降画质、热更新时保住正在打的局 |
| `src/shell.html` | 页面骨架和菜单的样式 |
| `build.py` | 拼成 `峡谷争锋.html`：语音转 base64，每个文件先 `node --check` |
| `voice/` | 播报语音：`make_voice.py` 合成并核对，`retake.py` 给"双杀""四杀"这种两个字的短句多录几版挑，`pack.py` 裁静音、统一响度、压成 mp3，`check_mp3.py` 打包后再转写一遍；`voice_cv3/` 是合成结果（wav + 逐字时间），`mp3/` 是嵌进网页的版本 |
| `test/` | `simtest.js` 电脑打电脑统计（node）；其余是 Playwright：`sceneview.js` 地图、`gallery.js` 模型、`shots.js` 从开头点进对局、`battle.js` 打起来的画面、`touch.js` 多指触摸、`keys.js` 键盘鼠标、`fullgame.js` 整局、`hot.js` 热更新；`lib.js` 共用（拦下 cdnjs 的 three.js 换成本地文件） |

## 重新生成

```bash
cd 游戏-峡谷争锋
python3 build.py                                      # 输出 峡谷争锋.html
node test/simtest.js 10 1                             # 电脑打电脑 10 局：谁赢、几分钟、击杀、掉塔
NODE_PATH=$(npm root -g) node test/shots.js 截图目录 phone        # phone / desktop / portrait
NODE_PATH=$(npm root -g) node test/touch.js 截图目录
NODE_PATH=$(npm root -g) node test/fullgame.js 截图目录 1 marksman
```

测试第一次跑会把 three.js r128 下到 `vendor/`（校验 sha256，不进仓库）。

播报语音（要先 `bash 工具/setup_tts.sh` 搭好配音环境）：

```bash
cd voice
/home/user/tts/venv/bin/python make_voice.py /home/user/tts/CosyVoice /home/user/tts/models/CV3-RL [编号 ...]
/home/user/tts/venv/bin/python pack.py
/home/user/tts/venv/bin/python check_mp3.py
```

## 用到的别人的东西

- 三维引擎：three.js r128（MIT），网页里从 cdnjs 加载。
- 播报配音：CosyVoice 3（Fun-CosyVoice3-0.5B-2512 的 RL 版，Apache-2.0）合成，FunASR 转写核对。
- 其他（模型、贴图、界面、音效、数值、AI）都是代码现写的。
