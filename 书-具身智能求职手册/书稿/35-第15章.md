# 选公司和谈 offer

拿到 offer 是好事，但对具身智能这样一个热闹的行业，选错公司的代价可能比没拿到 offer 还大：入职半年，公司融不到下一轮钱，项目停了，你的简历上多了一段很难解释的经历。

这一章讲两件事：**先看公司能活多久，再看给多少钱**。这里不评价任何一家具体的公司，只给你一套自己判断的方法。

## 先看公司能活多久

一家机器人公司能不能活下去，主要看四样东西。

**1. 钱：融资和现金流**

公开渠道能查到大部分公司的融资轮次、时间和金额（媒体报道、企业信息查询网站）。看两点：最近一轮是什么时候；按公司的人数粗算，这笔钱大概能撑多久。一家三百人的公司，人均每年的人力加研发开支按几十万元算，一年就要花掉一两个亿。融资两年没有新进展，就要多问一句。

**2. 产品：有没有在卖，卖给谁**

只有演示视频、没有交付的公司，和已经批量交付的公司，风险完全不同。问清楚：现在卖出去多少台？主要客户是谁（科研、教育、展示，还是真正在干活的工业客户）？有没有回头客？

**3. 生意：能不能赚钱**

上市公司可以直接读招股书和年报。《拆解宇树》第 16 章示范过怎么读：看收入和销量的增长、平均单价的变化、毛利率、成本结构。还没上市的公司拿不到这些数据，就在面试里问：产品的毛利大概在什么水平？今年的收入目标是多少？面试官不一定会答，但答不答、怎么答，本身就是信息。

**4. 人和方向：团队稳不稳，方向变不变**

核心团队的背景，最近一年有没有核心人员离开；公司的技术路线和产品方向，一年里是不是换了好几次。方向频繁变，对你意味着做的东西随时可能作废。

::: note
**几个值得警惕的信号**

面试流程混乱、反复改时间；口头承诺很多期权，但不愿意写进 offer；岗位职责说不清楚，“进来再看”；只谈融资和估值，不谈产品和客户。单独一个信号说明不了什么，几个一起出现就要小心。
:::

## 把 offer 拆开看

一份 offer 通常包括这些部分，逐项问清楚：

| 项 | 要问清楚的 |
|-----|-----------------------------------|
| 月薪和薪数 | 月薪多少，一年发几个月（13 薪、15 薪、16 薪差别很大） |
| 年终奖 | 是写进合同的保底，还是看绩效；去年实际发了几个月 |
| 签字费 | 有没有；入职多久内离职要退回 |
| 期权或股票 | 数量、行权价、归属期（常见是 4 年、满 1 年才开始归属）、公司总股本或最近一轮估值、离职时怎么处理 |
| 社保公积金 | 按什么基数交；公积金比例 |
| 试用期 | 多长；试用期工资打不打折 |
| 竞业限制 | 有没有；范围、期限和补偿 |

: 表 15-1　offer 要问清楚的几项

期权最容易被高估。粗算一下：你的期权数量 ÷ 公司总股本 × 最近一轮估值，再减去行权成本，得到的是**纸面价值**，而且只有公司上市或被收购时才可能兑现。把它当成“可能有、可能没有”的奖励，别当成工资的一部分。

两条和法律有关的常识（以《劳动合同法》为准）：**试用期**有上限，三年以上的劳动合同，试用期不能超过六个月；**竞业限制**的期限不能超过两年，而且公司在竞业限制期间要按月给你经济补偿。签之前看清楚竞业限制的范围，避免以后换工作时整个行业都不能去。

## 怎么谈

1. **先了解行情**：第 1 章的薪资例子、身边朋友的情况、几家公司给你的报价。
2. **先让对方报价**：HR 问你期望薪资时，可以说“我更看重岗位和发展，想先听听公司的方案”。
3. **谈总包，不只谈月薪**：月薪谈不上去，可以谈签字费、薪数、期权、职级。
4. **用真实的竞争 offer**：手上有别家的 offer，可以如实告诉对方；不要编造。
5. **书面确认**：所有谈好的条件写进 offer 或者邮件里。

转行的人在谈薪时常常心虚，觉得自己“是来学的”，开价不敢高。机器人公司愿意给你 offer，是因为你能解决他们的问题，按你的价值谈。也要现实一点：从一个高薪行业转过来，第一份工作的月薪持平甚至略降都很常见，用第一年换一个更好的方向是值得的，但要提前想清楚自己能接受的底线（第 1 章“我的起点”表的第 7 行）。

## 比较两个 offer

拿到两个以上 offer 时，用一张表把它们放在一起，给每项打 1–5 分，再按你自己的权重算总分：

| 项 | 权重 | offer A | offer B |
|-----------------------------|----|----|----|
| 公司能活多久（钱、产品、生意） | 25% | | |
| 岗位和你的目标方向的匹配度 | 25% | | |
| 能学到什么（团队水平、真机条件） | 20% | | |
| 现金收入（月薪 × 薪数 + 保底年终） | 20% | | |
| 其他（城市、通勤、加班强度、期权） | 10% | | |

: 表 15-2　offer 比较表（权重按你自己的情况调）

权重没有标准答案。工作三年、想换方向的人，可以把“匹配度”和“能学到什么”加大；有房贷、家里需要稳定收入的人，可以把“公司能活多久”和“现金收入”加大。

::: examiner
**考官视角：HR 面也在看你**

HR 面问“你为什么离开上一家”“你手上还有别的 offer 吗”“你最看重什么”，是在判断你的稳定性和动机。如实回答，说清楚你的考虑。一边说“最看重成长”、一边只追问薪资，会让人觉得你说的和想的不一样。
:::

::: career
**转行者笔记：第一份机器人工作，看“能学到什么”**

对转行的人来说，第一份机器人工作最重要的是让你真正接触到机器人：有没有真机、能不能参与从设计到测试的完整过程、身边有没有懂行的人带。这些比多几千块月薪更能决定你两年后的位置。
:::

::: try
**动手试试：用表 15-2 比一次**

哪怕你现在只有一个 offer，或者一个都没有，也可以拿两家你最想去的公司试着填一遍表 15-2。填不出来的格子，就是你下次面试要问的问题。
:::
