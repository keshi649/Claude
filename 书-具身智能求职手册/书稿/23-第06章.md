# 强化学习岗：奖励、PPO 和 Sim2Real

上一章的运动控制是“先把模型推清楚，再设计控制器”。强化学习走的是另一条路：在仿真里让机器人摔几亿次，自己摔出一套走路的办法。现在机器狗的跑跳、人形机器人的翻跟头，大多是这么练出来的。

这个岗位的面试有个特点：公式题不多，但追问很深。面试官最想知道的是，你有没有真的训练过一个策略，碰到不收敛、奖励作弊、上真机就倒的时候，知不知道该怎么查。

对应的作品集项目是第 11 章的项目三：用 PPO 训练 MuJoCo 里的 Hopper，对照“加不加域随机化”。

## 这个岗位的一天

一个典型的一天（不是某个真人）：

早上看昨晚在 GPU 服务器上跑的训练：四千个仿真环境并行，曲线涨得不错。回放一看，机器狗学会了用膝盖蹭着地走，因为这样不容易摔、也不违反任何一条奖励。加了一项“膝盖碰地就结束回合”，重新开训。下午把上周的策略放进另一个仿真器 MuJoCo 里验证，发现关节顺序配错了一处。傍晚上真机，机器人在地毯上一走就打滑，你决定把地面摩擦系数的随机化范围往下扩。

## 招聘启事里怎么写

- 学历：多数要硕士，有论文或真机部署经验的优先；
- 算法：PPO、SAC 等常见算法，奖励设计，域随机化；
- 工具：PyTorch 或 JAX；Isaac Gym、Isaac Lab、MuJoCo；
- 基础：运动学、动力学、控制常识；
- 加分：人形、四足或灵巧手的真机策略部署经验。

## 面试题和参考答案

### 6.1　PPO 的核心思想是什么？“截断”在防什么？ {#q6-1}

**一句话**：PPO 是一种策略梯度方法，每次更新时限制新策略不能离旧策略太远，避免一步走太大把策略毁掉。

记新旧策略在同一个动作上的概率比为 $r_t = \pi_\theta(a_t|s_t) / \pi_{\text{旧}}(a_t|s_t)$，$A_t$ 是优势（这个动作比平均水平好多少）。PPO 的策略目标是：
$$L = \mathbb{E}\left[\min\left(r_t A_t,\ \operatorname{clip}(r_t, 1-\epsilon, 1+\epsilon)\, A_t\right)\right]$$

$\epsilon$ 常取 0.2。优势为正时，概率比超过 $1+\epsilon$ 就不再给奖励；优势为负时，低于 $1-\epsilon$ 就不再惩罚。这样一批数据可以反复用好几遍（通常 5–10 遍），又不会把策略推得太远。完整的损失里还有价值函数的误差项和一个可选的熵奖励。

**考官想听到**：概率比的含义；min 和 clip 的作用方向；为什么能多次复用同一批数据。

### 6.2　GAE 是什么？$\lambda$ 怎么影响偏差和方差？ {#q6-2}

**一句话**：GAE（广义优势估计）把多步的时序差分误差按 $\gamma\lambda$ 指数加权求和，在“偏差小”和“方差小”之间折中。

先定义一步的时序差分误差 $\delta_t = r_t + \gamma V(s_{t+1}) - V(s_t)$，优势估计为：
$$A_t = \sum_{l=0}^{\infty} (\gamma\lambda)^l\, \delta_{t+l}$$

- $\lambda = 0$：只看一步，$A_t = \delta_t$。方差小，但完全依赖价值函数，价值函数不准就有偏差。
- $\lambda = 1$：相当于用完整的蒙特卡洛回报减去基线。没有这部分偏差，但方差大。

常用 $\gamma = 0.99$、$\lambda = 0.95$。一个实现细节：回合因为超时被截断（机器人没摔倒，只是时间到了）时，不能把下一个状态的价值当成 0，要用最后一帧的价值去补，否则会把“活到最后”误当成“摔倒”。项目三的代码专门处理了这一点。

**考官想听到**：$\delta$ 和 $A$ 的公式；$\lambda$ 两个极端的含义；超时截断和真正终止的区别。

### 6.3　on-policy 和 off-policy 有什么区别？为什么足式机器人训练多用 PPO？ {#q6-3}

**一句话**：on-policy 只能用当前策略采的数据更新，off-policy 可以反复用旧数据。PPO 是 on-policy，样本效率低，但稳定、好调，而且能吃满大规模并行仿真。

SAC 这类 off-policy 算法把数据存进回放缓冲区反复使用，样本效率高，适合真机上采样很贵的场景。但在 GPU 并行仿真里，几千个环境同时跑，样本几乎不要钱，这时稳定性和吞吐量更重要。所以从 legged_gym 开始，足式机器人的仿真训练大多用 PPO。

**考官想听到**：两类方法的数据使用方式；为什么在仿真里样本效率不是主要矛盾。

### 6.4　训练四足走路，奖励函数一般有哪些项？ {#q6-4}

**一句话**：一项主要的“跟踪速度指令”奖励，加一串让动作像样、对机器有好处的惩罚。

常见的项（以 legged_gym 一类框架为例）：

- **跟踪奖励**：线速度、角速度跟上指令，用 $\exp(-\lVert e \rVert^2/\sigma)$ 这种形式，误差为 0 时最大；
- **姿态和高度**：机身不要歪、不要太低；
- **能耗和平滑**：关节力矩、关节加速度、相邻两步动作的变化量；
- **步态**：脚的腾空时间（奖励抬脚，防止拖着走），脚打滑的惩罚；
- **安全**：大腿、机身碰地就惩罚或者直接结束回合。

难点不在列出这些项，而在**权重**：跟踪奖励太大，动作会很难看、很耗电；惩罚太大，策略学会原地不动。通常先只用跟踪奖励加少量惩罚训出能走的策略，再逐项加约束。

**考官想听到**：跟踪奖励的形式；三四类正则项；权重怎么调的实际经验。

### 6.5　什么是奖励作弊？举个例子，怎么发现？ {#q6-5}

**一句话**：策略找到了奖励函数的漏洞，分数很高，但行为不是你想要的。

足式机器人里常见的例子：用膝盖或者机身蹭着地前进（不容易摔，又能跟上速度）；脚在地面上高频振动来“刷”腾空时间；利用仿真接触模型的瑕疵，在某个奇怪的姿态下获得额外推力。

发现的办法：

1. **一定要看回放视频**，不能只看总奖励曲线；
2. 把每一项奖励**分开记录**，看是哪一项在涨；
3. 检查物理上不合理的指标：关节速度、力矩、接触力有没有异常峰值；
4. 换一个仿真器验证（Sim2Sim），利用仿真瑕疵学出来的动作往往在另一个仿真器里立刻失效。

**考官想听到**：一个具体的例子；“分项记录加看视频”的习惯；作弊行为和仿真瑕疵的关系。

### 6.6　动作空间为什么常用“关节目标角度加底层 PD”，而不是直接输出力矩？ {#q6-6}

**一句话**：输出目标角度，让高频的 PD 控制器去处理刚度和阻尼，策略本身可以在较低频率（比如 50 Hz）运行，学起来更容易，动作也更平滑。

直接输出力矩，策略必须自己学会“弹簧和阻尼”，并且要以很高的频率运行才稳定，探索空间也大得多。用目标角度加 PD 的方式，相当于给策略加了一个合理的先验。代价是 PD 的 kp、kd 成了训练环境的一部分，**仿真里用什么增益，真机上就必须用一样的**，否则策略的行为会变。

动作通常还要乘一个缩放系数、加在默认站立姿态上：$q_{\text{目标}} = q_{\text{默认}} + s \cdot a$。这个缩放系数、默认姿态、关节顺序，是策略部署时最容易配错的三样东西。

**考官想听到**：低频策略加高频 PD 的分工；增益要和真机一致；动作缩放和默认姿态。

### 6.7　什么是域随机化？随机化哪些参数？范围怎么定？ {#q6-7}

**一句话**：训练时让仿真环境的物理参数在一个范围内随机变化，逼策略学会对这些变化不敏感，这样真机和仿真不一样时，它也能应付。

常见的随机化对象：质量和质心位置、地面摩擦、电机力气、关节阻尼和摩擦、控制延迟、传感器噪声、地形高低，以及随机推一把。

范围怎么定：从测量值出发加余量。比如实测摩擦系数在 0.6–0.9 之间，就随机到 0.4–1.1。范围太窄，真机一变就失效；范围太宽，策略会变得过分保守，平地上也走得畏畏缩缩。

项目三做了一组对照（3 个随机种子取平均，每个策略在每种环境里测 20 个回合）。不加随机化和加随机化的策略，在原始环境里得分差不多（2,792 分和 2,696 分），但换了环境就拉开了：躯干重 1.5 倍时是 1,031 分对 1,680 分，地面摩擦减半时是 364 分对 691 分，电机力气只剩八成时是 427 分对 1,327 分。

**考官想听到**：随机化哪些东西；范围的取舍；“原始环境里不吃亏、变了环境才见差距”这个规律。

### 6.8　Sim2Real 的差距通常来自哪里？怎么缩小？ {#q6-8}

**一句话**：最大的差距往往在执行器（电机和减速器）的动态，其次是接触、延迟和传感器。

主要来源：

1. **执行器**：真实电机有电流限制、发热降额、摩擦、背隙、带宽有限，仿真里的“理想力矩源”没有这些。
2. **延迟**：从传感器读数到电机出力，真机上有几毫秒到十几毫秒的延迟。
3. **接触**：仿真的接触模型是简化的，地面的软硬、摩擦和真实世界不一样。
4. **传感器**：IMU 噪声和零偏、编码器量化、状态估计的误差。
5. **模型参数**：质量、惯量、质心位置不准。

缩小的办法：系统辨识，把参数测准；对执行器单独建模，经典做法是苏黎世联邦理工学院 2019 年用真机数据训练一个“执行器网络”放进仿真；域随机化覆盖剩下的不确定性；先在另一个仿真器里做 Sim2Sim 验证，再上真机。

**考官想听到**：把执行器排在第一位；能说出执行器网络这类做法；Sim2Sim 是上真机前的必经一步。

### 6.9　什么是教师-学生训练（特权学习）？为什么有效？ {#q6-9}

**一句话**：先在仿真里训练一个“开卷考试”的教师策略，它能看到真机上拿不到的信息（地形高度、摩擦系数、接触状态）；再训练一个只看真实传感器的学生策略，去模仿教师的动作。

直接用真实传感器的观测训练很难：机器人要从关节和 IMU 的历史数据里自己推断“我踩的是什么地面”，强化学习的信号太弱。教师有特权信息，很容易学好；学生的任务变成监督学习（模仿教师），容易得多。学生通常要看一段历史观测，从中隐式地估计地形和摩擦。

这条路线的代表是苏黎世联邦理工学院 2020 年发表在《科学·机器人学》上的复杂地形四足行走工作；2021 年的 RMA 用类似的思路，让学生在线估计环境参数，实现快速适应。

**考官想听到**：教师和学生各看什么；为什么学生要看历史；和 DAgger 的关系（学生的训练数据最好来自学生自己的轨迹）。

### 6.10　为什么要几千个环境同时训练？并行环境数怎么影响训练？ {#q6-10}

**一句话**：PPO 每次更新都要新鲜的数据，GPU 并行仿真一次跑几千个环境，几分钟就能采到 CPU 上要跑几小时的数据量。

2021 年的 legged_gym 工作把几千只机器狗放在一块 GPU 上同时仿真：平地上的策略大约 4 分钟训出来，崎岖地形大约 20 分钟。并行环境数和每个环境每次采样的步数，决定了一批数据的大小：

- 环境多、每个环境步数少：数据多样，但每段轨迹短，长时间才见效的奖励不容易学到；
- 环境少、步数多：轨迹长，但数据相关性强，梯度方差大。

作为对照，项目三在 4 核笔记本的 CPU 上，单个环境每秒只能采约 1,200 步，训练 100 万步要 14 分钟左右。这就是为什么做足式机器人的团队都离不开 GPU 仿真。

**考官想听到**：并行仿真的意义；批量大小和轨迹长度的权衡；对训练时间有数量级的概念。

### 6.11　训练曲线不涨，或者涨了又崩了，你怎么排查？ {#q6-11}

**一句话**：先排查“工程 bug”，再怀疑“算法”。

按顺序查：

1. **奖励的符号和尺度**：惩罚项写成了奖励？某一项比其他项大几个数量级？
2. **观测归一化**：没有归一化，或者训练和测试用的统计量不一样；
3. **动作**：缩放是否合理，有没有被截断；
4. **终止条件**：太严，机器人一开始就全部结束；太松，学会了“趴着拿分”；
5. **策略的标准差**：探索噪声塌缩到 0，策略就不再探索；
6. **价值函数的损失**：一直很大，说明优势估计不可信；
7. **数值问题**：NaN、梯度爆炸，学习率太大。

有效的习惯：先在最简单的设置下跑通（平地、固定指令），再逐项加复杂度；固定随机种子，保证结果能复现；每次只改一个东西。

**考官想听到**：有顺序的排查清单；“先工程后算法”；能复现、一次改一处的习惯。

### 6.12　策略在 Isaac 里走得很好，放到 MuJoCo 里就站不住，可能是什么原因？ {#q6-12}

**一句话**：十有八九是两边的配置不一致，而不是策略不行。

常见的不一致：

- **关节顺序**：两个仿真器、两份模型文件里，关节的排列顺序可能不同；
- **正负号和零位**：关节转动方向、零位定义不同；
- **默认姿态、动作缩放、PD 增益**：任何一个对不上，策略输出的含义就变了；
- **控制频率和降采样**：策略 50 Hz、PD 1 kHz，降采样倍数写错；
- **观测**：重力向量的坐标系、角速度用的是机身坐标系还是世界坐标系、观测的缩放系数；
- **接触和求解器**：摩擦系数、仿真步长、接触参数。

排查办法：在两个仿真器里放同一个初始状态，喂同一串动作，逐个对比观测向量的每一维，第一个不一致的地方就是线索。《拆解宇树》第 19 章的 Sim2Sim 步骤，就是为了在上真机之前把这些错找出来。

**考官想听到**：关节顺序、默认姿态、增益、频率这几个高频坑；逐维对比观测的方法。

::: examiner
**考官视角：讲一个失败**

强化学习岗的面试里，“你遇到过最难查的问题是什么”几乎必问。最好的答案是一个具体的失败：现象是什么，你怎么定位，最后是什么原因，怎么验证修好了。比如项目三里，超时截断如果当成摔倒处理，价值估计会出偏差，这就是一个可以讲清楚的坑。只讲成功、不讲失败的候选人，面试官很难判断你是不是真的训练过。
:::

## 从哪些背景转过来最顺

- **强化学习方向的研究生**：算法现成，补机器人动力学和真机部署。
- **游戏 AI、推荐系统里做过强化学习的工程师**：训练和调参的经验能直接用上，要补的是物理仿真和机器人常识。
- **自动驾驶决策规划**：熟悉仿真、评测和长尾问题；补策略梯度和足式机器人的特点。
- **运动控制工程师**：懂机器人、懂真机，补强化学习后在 Sim2Real 上很有优势，这类复合型的人最抢手。

::: career
**转行者笔记：GPU 不是门槛**

很多人以为没有 GPU 就没法练强化学习。项目三只用笔记本的 CPU，半小时就能跑完一组有意义的对照实验。面试官看重的是你会不会设计实验、会不会读曲线、会不会查问题，而不是你用了多少张卡。
:::

::: try
**动手试试：先跑一个短的**

把项目三的训练步数改成 20 万步，十分钟以内就能看到 Hopper 学会往前跳。然后回放一遍，找找它有没有“作弊”的动作。
:::

::: takeaway
会调奖励不稀奇，能把策略搬上真机才值钱。面试里讲清楚一次失败，比讲十次成功更有说服力。
:::
