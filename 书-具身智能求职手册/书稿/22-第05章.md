# 运动控制岗：从 PID 到 MPC 和 WBC

运动控制是最典型的机器人岗位，也是面试最“硬”的岗位之一：面试官会让你推公式、画框图，再追问你在真机上调过什么。

这一章先讲这个岗位每天在干什么、招聘启事怎么写，再给一张知识地图和 12 道面试题。对应的作品集项目是第 11 章的项目一（让机器狗站起来）和项目二（倒立摆）。

## 这个岗位的一天

下面是一个典型的一天，不是某个真人。

上午，看昨天测试的日志：一台四足在湿地砖上打滑了两次，你把那两段的关节力矩、足端力估计和 IMU 数据调出来，发现打滑前摆动腿落地比计划早了 30 毫秒。中午在仿真里复现，改了接触检测的阈值。下午把机器人吊在架子上测新参数，再放到地上走斜坡。傍晚给 SDK 补一段文档，因为客户问了第三遍“步态切换的时候能不能不停”。

这个岗位一半时间在推公式和写代码，另一半时间在看数据、上真机。

## 面试题和参考答案

### 5.1　关节 PD 控制里的 kp 和 kd 分别像什么？调大调小各会怎样？ {#q5-1}

**一句话**：kp 像一根弹簧，kd 像一个阻尼器。力矩 $\tau = k_p (q_{\text{目标}} - q) - k_d\, \dot q$，就是在关节上装了一根虚拟的弹簧加阻尼。

- **kp 太小**：关节“软”，站不住或者站得低，负载一压就塌。项目一里 kp=10 时，Go2 根本站不起来，机身高度只有 0.15 m（目标约 0.27 m）。
- **kp 大**：站得准、负载下下沉小，但力矩需求大，对延迟更敏感。项目一里 kp=300 时膝关节误差只有约 1°，压上 60 牛的力只下沉 2 mm 左右。
- **kd 小**：振荡、超调。
- **kd 大**：在理想情况下更稳，但它放大速度测量的噪声，**有延迟时还会引起抖动**。

最后一点最容易答错。项目一里，同样 kp=300、控制延迟 5 ms：kd=3 稳稳站住；kd=8 时膝关节以大约 45 Hz 来回抖，力矩在正负极限之间来回打满，5 秒里有 4.8 秒处于饱和。

**考官想听到**：弹簧阻尼的类比；kd 在有延迟、有噪声时的副作用；能说出“真机上抖了，第一反应不该是加 kd”。

### 5.2　四足机器人为什么常用“PD 加前馈力矩”，而不是纯位置控制或者纯力矩控制？ {#q5-2}

**一句话**：前馈力矩负责“已知的那部分”（重力、规划好的接触力），PD 负责“意料之外的误差”，两者合起来既准又柔。

很多四足的底层关节指令有五个数：目标角度、目标角速度、kp、kd、前馈力矩，关节驱动板按 $\tau = k_p(q_d - q) + k_d(\dot q_d - \dot q) + \tau_{\text{ff}}$ 算出电机力矩。《拆解宇树》第 9 章讲过，宇树的底层指令就是这五个字段。

- **纯位置控制**（kp 很大）：腿很硬，落地冲击大，对地面高度误差毫无容忍度。
- **纯力矩控制**（kp=kd=0）：完全依赖上层模型准确，模型一有误差就飘。
- **PD 加前馈**：支撑腿上，MPC 算出的足端力通过 $\tau_{\text{ff}} = J^\top f$ 变成前馈力矩，PD 增益设得低一点，让腿保持柔顺；摆动腿上，增益设高一点，保证轨迹跟得准。

**考官想听到**：前馈和反馈的分工；支撑腿和摆动腿的增益为什么不同；$J^\top f$ 的来历。

### 5.3　线性倒立摆模型怎么推？时间常数是多少？捕获点是什么？ {#q5-3}

**一句话**：假设质心高度 $z$ 不变、腿没有质量，质心水平位置满足 $\ddot x = \frac{g}{z}\, x$，偏差按 $e^{\omega t}$ 发散，$\omega = \sqrt{g/z}$。

推导：支撑点在原点，腿对质心的力沿着腿的方向。竖直方向受力平衡（高度不变），水平分量和竖直分量之比等于 $x/z$，于是水平加速度 $\ddot x = g\,x / z$。

质心高 0.6 m 时，$\omega \approx 4.0\ \text{s}^{-1}$，时间常数约 0.25 s：偏差每过四分之一秒放大约 $e$ 倍。个子越高，时间常数越长，留给控制器的反应时间越多。

**捕获点**：$x_{\text{捕获}} = x + \dot x / \omega$。把下一步踩到这里，机器人就能停下来。直觉是：速度越快，要往前多迈一些，多迈的量是“速度除以 $\omega$”。

**考官想听到**：两个假设（质心高度不变、腿无质量）；$\omega$ 的物理意义；捕获点的公式和直觉。

### 5.4　ZMP 是什么？它在什么情况下不适用？ {#q5-4}

**一句话**：ZMP（零力矩点）是地面上的一个点，地面反力对它的水平力矩为零。只要 ZMP 落在支撑多边形里面，脚就不会绕着边缘翻转。

传统人形机器人（比如本田的 ASIMO）的走法就是：先规划 ZMP 轨迹，让它始终在脚掌范围内，再反推质心轨迹。这种方法稳，但动作保守。

ZMP 判据的前提是：所有接触都在同一个平面上、脚不打滑、一直有脚着地。以下情况不适用或者不够用：

- 腾空阶段（跑、跳、翻跟头），没有支撑面；
- 接触不在同一平面，比如手扶着墙、脚踩在台阶边缘；
- 摩擦不够、会打滑，ZMP 在支撑面里也可能滑倒；
- 动态步态，比如四足的对角小跑，支撑多边形退化成一条线。

**考官想听到**：定义说得准；能说出三种以上不适用的情况；知道为什么现在的足式机器人更多用 MPC 和强化学习。

### 5.5　四足机器人的 MPC 一般怎么建模？为什么用单刚体模型？ {#q5-5}

**一句话**：把整个机器人看成一个刚体，四只脚的接触力是控制输入，在未来零点几秒里优化这些力，让机身的位置和姿态跟上目标；每次只执行第一步，下一周期重新算。

典型做法（以 MIT Cheetah 3 的凸 MPC 为代表）：

1. **模型**：单刚体，状态是机身位置、速度、姿态、角速度；输入是各支撑脚的地面反力。腿的质量相对机身小，忽略掉。
2. **线性化**：假设横滚和俯仰角不大，把姿态动力学在当前偏航角附近线性化，整个问题变成一个线性系统。
3. **约束**：每只支撑脚的力要满足摩擦锥（见下一题）和力的上下限；摆动脚的力为零。
4. **求解**：目标是跟踪误差加力的大小，整体是一个二次规划（QP），可以在几毫秒内解完。

为什么用单刚体：完整模型是非线性的，求解慢，不能保证实时；单刚体模型加线性化以后是凸问题，有可靠的快速解法，又保留了“力怎么影响机身运动”这个核心。

**考官想听到**：输入是接触力而不是关节力矩；线性化的假设；凸 QP 的好处；滚动时域“只执行第一步”。

### 5.6　摩擦锥约束怎么写？为什么常常线性化成“摩擦金字塔”？ {#q5-6}

**一句话**：脚不打滑，要求切向力不超过摩擦系数乘以法向力：$\sqrt{f_x^2 + f_y^2} \le \mu f_z$，同时 $f_z \ge 0$（地面只能推不能拉）。

这个约束在三维力空间里是一个圆锥，属于二阶锥约束，普通的 QP 求解器处理不了。把它换成内接的四棱锥就变成线性不等式：
$$|f_x| \le \mu f_z, \qquad |f_y| \le \mu f_z, \qquad f_z \ge 0$$

为了保守，$\mu$ 通常取得比实际摩擦系数小一些，比如实测 0.8 时取 0.5–0.6，留出余量。湿滑地面上 $\mu$ 设错，是机器人打滑的常见原因之一。

**考官想听到**：圆锥变金字塔的原因；$f_z \ge 0$；$\mu$ 取保守值。

### 5.7　WBC 是什么？它和 MPC 是什么关系？任务优先级怎么实现？ {#q5-7}

**一句话**：WBC（全身控制）在完整的动力学模型上，把上层给的目标（机身加速度、足端力、摆动腿轨迹）变成每个关节的力矩，同时满足动力学、摩擦和力矩限制。

动力学方程是 $M(q)\ddot q + h(q, \dot q) = S^\top \tau + J_c^\top f$，其中 $J_c$ 是接触雅可比。WBC 通常也写成一个 QP，优化变量是 $\ddot q$、$\tau$、$f$。

**和 MPC 的关系**：MPC 在简化模型（单刚体）上、以几十到一百多赫兹的频率规划未来零点几秒；WBC 在完整模型上、以几百赫兹到一千赫兹的频率，把 MPC 这一刻的规划落实成关节力矩。一个管“往哪走”，一个管“这一刻每个关节出多少力”。

**任务优先级**两种实现：

- **加权**：所有任务放进一个目标函数，重要的权重大。简单，但重要任务也可能被别的任务“拉偏”；
- **严格分层**：先满足高优先级任务（比如不摔倒、接触脚不动），再在它的零空间里满足低优先级任务（比如手臂姿态）。可以用零空间投影，也可以按优先级依次解一串 QP（分层 QP）。

**考官想听到**：动力学方程写得出来；MPC 和 WBC 的频率、模型分工；加权和严格分层的区别。

### 5.8　LQR 和 PID 有什么区别？LQR 的 Q 和 R 怎么调？ {#q5-8}

**一句话**：PID 是单输入单输出的误差反馈，靠调参；LQR 是基于线性模型的全状态反馈，通过最小化“状态误差加控制代价”自动算出最优增益。

LQR 求的是 $u = -Kx$，使 $\int (x^\top Q x + u^\top R u)\,dt$ 最小，$K$ 由 Riccati 方程解出。Q 越大，越在意状态误差，控制越激进；R 越大，越在意控制量，越省力、越温和。实践中先按“每个状态能容忍多大误差”的倒数平方设 Q 的对角元，再调整整体比例。

项目二用小车倒立摆比较过两者：只管摆角的 PID 能让杆立住，但小车回不到原点，8 秒里漂出去 0.46 m；LQR 同时管四个状态，杆和小车都回到原位。LQR 对模型误差很宽容：实际的杆比模型重 5 倍也照样稳；但对延迟敏感：控制延迟 80 ms 还能撑住，100 ms 就倒了。

**考官想听到**：全状态反馈和单变量反馈的区别；Q、R 的含义；知道 LQR 依赖线性化，离工作点远了会失效；延迟比模型误差更危险。

### 5.9　控制频率怎么选？延迟对稳定性有什么影响？ {#q5-9}

**一句话**：采样频率一般要比闭环带宽高一个数量级；延迟相当于给系统加了一个随频率增长的相位滞后，会吃掉相位裕度，增益越高越危险。

一台腿足机器人里通常是几层频率套在一起：

- 关节电流环：十几到几十千赫兹，在驱动板上；
- 关节 PD 和全身控制：几百赫兹到一千赫兹；
- MPC：几十到一百多赫兹；
- 步态和路径规划：几赫兹到几十赫兹。

延迟 $\tau_d$ 在频率 $\omega$ 处带来 $\omega \tau_d$ 弧度的相位滞后。增益调高，闭环带宽变大，同样的延迟吃掉的相位裕度就更多，系统开始振荡。这就是项目一里“kp=300、5 ms 延迟、kd=8”出现抖动的原因。

**考官想听到**：几层频率的数量级；延迟和相位裕度的关系；高增益和延迟不能兼得。

### 5.10　真机上一条腿在高频抖动，你怎么排查？ {#q5-10}

**一句话**：先采数据看抖动的频率和发生条件，再按“控制、传感、通信、机械”的顺序逐个排除，不要一上来就改参数。

1. **记录数据**：关节角、角速度、指令力矩、实际电流、控制周期的时间戳。算出抖动频率。
2. **看是不是控制问题**：抖动时力矩有没有饱和、来回打满？临时把 kd、kp 降一半，抖动是否消失？抖动频率是否和控制延迟对得上？
3. **看传感器**：角速度是不是由编码器差分得来、噪声很大？加一阶低通滤波，或者降低 kd。
4. **看通信**：控制周期的抖动和丢包，偶发的几毫秒延迟就足以让高增益系统振荡。
5. **看机械**：减速器背隙、螺丝松动、线缆拉扯、结构共振。共振的频率一般固定，和增益关系不大。
6. **看温度**：电机发热后电阻变大，同样电流下扭矩下降，表现可能是“越调越软”或者保护动作。

**考官想听到**：先测量再改参数；能分清控制振荡和机械共振；提到饱和、延迟、速度噪声这三个常见原因。

### 5.11　摆动腿和支撑腿的控制有什么不同？落脚点怎么选？ {#q5-11}

**一句话**：支撑腿管“推地面”，做力控；摆动腿管“把脚送到下一个落脚点”，做轨迹跟踪。

- **摆动腿**：从离地点到落脚点规划一条笛卡尔空间的曲线（常用贝塞尔曲线或摆线，中间抬高几厘米避免绊脚），用较高的 PD 增益或笛卡尔阻抗控制跟踪。
- **支撑腿**：MPC 算出这条腿该出的地面反力，通过 $\tau = J^\top f$ 变成关节力矩，PD 增益很低。
- **落脚点**：最经典的是雷伯特启发式，$p_{\text{落脚}} = p_{\text{髋}} + \frac{v\,T_{\text{支撑}}}{2} + k\,(v - v_{\text{目标}})$：前一项让脚落在支撑期中点正下方，后一项按速度误差修正，跑快了就多往前踩一点。

还有两个工程细节：**落地检测**（靠足端力传感器或者用关节力矩估计接触），以及**早落地和晚落地**的处理：没到计划时间就碰到地面，要立即切到支撑模式；到了时间还没碰到，要继续往下探。

**考官想听到**：两种腿的控制目标和增益差别；雷伯特公式；落地检测和异常处理。

### 5.12　让你从零给一台四足写一个能站立、能慢走的控制器，你会怎么分步做？ {#q5-12}

**一句话**：先站，再原地踏步，再走；每一步都先在仿真里跑通，再上吊架，最后落地。

1. **状态估计**：IMU 给姿态，腿的运动学加“支撑脚不动”的假设给机身速度，用卡尔曼滤波融合（第 7 章、项目四）。
2. **站立**：关节 PD 加重力补偿，从趴下的姿势平滑过渡到站立姿势（项目一）。
3. **步态调度**：对角小跑，固定周期，每条腿在支撑和摆动之间切换。
4. **摆动腿**：落脚点用雷伯特公式，轨迹用贝塞尔曲线。
5. **支撑腿**：先用一个简单的力分配（按重量平均分到支撑脚），能走以后再换成 MPC。
6. **安全**：力矩、速度、关节角限位；摔倒检测（姿态角超过阈值就进入阻尼模式）；急停。
7. **测试顺序**：仿真 → 吊架上空跑 → 落地站立 → 原地踏步 → 平地慢走 → 斜坡和台阶。

**考官想听到**：模块划分清楚；先简单后复杂；安全措施和测试顺序。这道题考的是工程思路，不是某个公式。

**考官视角：运控面试最常见的三个错答**

一是“kd 越大越稳”，忽略了噪声和延迟；二是把 MPC 说成“预测未来”，说不出优化变量、约束和滚动执行；三是只会讲论文，被问到“真机上遇到过什么问题”时答不上来。第三个最致命。没有真机，就用项目一的“延迟加高 kd 会抖”这类在仿真里复现过的问题来答，并且说清楚你是怎么发现、怎么验证的。

- **控制、机械、机器人方向的研究生**：理论现成，补真机和工程能力。
- **自动驾驶规划控制**：MPC、优化、C++ 都能直接用上；要补的是接触动力学和腿足特有的问题（摩擦锥、步态、落地冲击）。
- **工业机器人和机械臂控制**：动力学、伺服调参经验很值钱；要补浮动基和接触切换。
- **无人机飞控**：状态估计、串级控制、实时系统都是现成的；腿足的接触是新东西。
- **电机控制**：最懂“真机怎么调”，能从关节和底层控制切入，再往上学 MPC 和 WBC。

::: career
**转行者笔记：先在仿真里把一个问题吃透**

运控岗位最看重真机经验，但没有真机的人也不是没机会。把项目一和项目二做透：每个现象都能复现、能解释、能给出改法，面试时比“调过真机但说不清原理”的候选人更有说服力。
:::

::: try
**动手试试：换一组参数**

跑项目一，把 kp 和 kd 换成你自己选的几组值，再把延迟改成 0、2、5、10 毫秒，记下哪组开始抖。面试时被问到“kd 怎么调”，你就有自己的数据可以讲。
:::

::: takeaway
运控面试考的是“为什么这么设计”：每个公式背后的假设，每个参数调大调小的后果，以及真机上出了问题你怎么查。
:::
