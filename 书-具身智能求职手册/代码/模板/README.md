# 模板（附录 D 的电子版）

| 文件 | 用在哪 | 说明 |
|---|---|---|
| `01-我的起点.md` | 第 1 章 | 八行自我盘点，后面几章都会回来查 |
| `02-岗位打分表.csv` | 第 2 章 | 接得上、够得着、有人要、想干，各 1–5 分 |
| `03-一页简历.md` | 第 13 章、附录 D.1 | 每个目标岗位各改一份 |
| `04-项目README.md` | 第 12 章、附录 D.2 | 结果图放最上面 |
| `05-面试复盘表.csv` | 第 14 章、附录 D.3 | 面完当天填 |
| `06-投递记录表.csv` | 第 16 章、附录 D.4 | 每投一家记一行 |
| `07-offer比较表.csv` | 第 15 章、附录 D.5 | 权重按自己的情况调 |
| `08-访谈提纲.md` | 附录 D.6 | 向已经转进来的人请教 |
| `打分和比较.xlsx` | 第 2、15 章 | 岗位打分和 offer 比较两张表，填完分数自动算合计；岗位打分会提示“接得上或够得着只有 1 分，先不选” |

CSV 文件是 UTF-8 带 BOM 的，Excel、WPS、Numbers 直接打开不会乱码。
