# 《拆解宇树》宣传片

给甜菜的书《拆解宇树：从一颗电机到会翻跟头的机器人》做的竖屏宣传片：1080×1920，30 fps，76.5 秒。

- 成片：`成片/拆解宇树-宣传片.mp4`；封面图：`成片/封面.jpg`；发布文案：`成片/发布文案.txt`
- 分镜和每句文案的出处：`分镜.md`
- 画面全部用代码生成（three.js 三维 + Canvas 字幕层 + 自己写的后期着色器），在无头 Chromium 里逐帧渲染；配乐和音效全部用 Python 原创合成（加 FluidR3 GM 音色库的弦乐、合唱、定音鼓、钢琴），没有用任何现成的音乐、音效、图片和视频素材。
- 机器人是自己设计的通用造型，不仿任何真实产品，也没有任何公司的标志。书封用的是书自己的封面文件。

## 结构

跟书一样分六部，每部一张标题卡，中间穿插冲击、转场：

| 时间 | 内容 |
|---|---|
| 0–10 秒 | 春晚舞台慢动作“弹射空翻” → 时间冻住，三个问题 → 炸成零件 → 片名 |
| 10–16 | 01 认识它：参数表“先问一句”、看演示视频的五个问题 |
| 16–28 | 02 拆开它：钻进关节，拆成六片，530 克、23.7 N·m，减速器 ×6.33，10 厘米的杆吊起 20 多千克 |
| 28–44 | 03 让它动：掌心立扫帚、几百只虚拟狗一起学走路、动作捕捉、多机位后空翻 |
| 44–50 | 04 让它懂：激光雷达边走边画图、端不稳一杯水，瓶颈是数据 |
| 50–56 | 05 看懂这门生意：售价往下、毛利率往上；安全六问 |
| 56–62 | 06 走进来：六种背景接到机器人身上、90 天上车 |
| 62–76.5 | 高潮蒙太奇 → 零件飞回去装成关节 → 书转进来，片尾 |

## 怎么出片

```bash
cd 宣传片-拆解宇树/源码
npm install                               # three 0.186.1、Bebas Neue、JetBrains Mono（版本写死在 package.json）
pip install numpy scipy soundfile pyloudnorm mido
apt-get install fluidsynth fluid-soundfont-gm   # 弦乐、合唱、定音鼓、钢琴
bash build.sh                             # 配乐 + 四路并行渲染 + 合成，约半小时
```

检查用：

```bash
node render.js --stills 1.5,8.2,33.9 --stilldir 检查 --scale 0.5   # 出几张静帧
python3 audio/score.py build/audio.wav                              # 只出配乐（另有分轨 build/stems/）
```

## 源码

- `js/core/`：引擎（镜头调度、转场、整片冲击效果）、着色器、字幕和 HUD 画法、三维特效
- `js/models/`：人形机器人、机器狗、关节电机（六个零件，行星齿轮按真实齿数和转速啮合）
- `js/shots/`：每一部的镜头；`js/timeline.js` 是总时间线，切点都卡在 120 BPM 的拍子上
- `audio/`：`synth.py` 合成工具，`score.py` 编曲、音效、混音、母带
- 字体：得意黑（`fonts/`，SIL OFL 1.1）、思源黑体、Bebas Neue、JetBrains Mono（都是开源字体）
