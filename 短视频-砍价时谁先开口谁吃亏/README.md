# 短视频《砍价时，谁先开口谁吃亏？》

> 做过功课，先开口的占便宜；报个带零头的数，别报整的。

用户说"在做一个有关生活的，依旧反常规"。约 ⟨DUR⟩ 的竖屏像素风科普短视频：

- **旁白有配音**：CosyVoice 3 合成的女声，字幕按配音的逐字时间出现
- 角色台词出在游戏对话框里，不配音，只有打字音
- 有音效和环境声，**没有配乐**
- 角色用用户给的 12×8 像素小怪："你"戴红领巾；摊主戴草帽
- 一个比喻讲到底：第一个数是一只锚，成交价是绕着它转的小船

片子讲的是：

- **开头**：夜市的旧货摊，"你"看上一把吉他，摊主问"你先说个价？"："砍价时，谁先开口谁吃亏？"——"对，让他先报！"第 2.85 秒（"错"字开口前）盖章"先开口赢"。科学家让人两两谈买卖，不管买家还是卖家，谁先报价，成交价就偏向谁：第一个数像扔下去的锚，后面怎么砍都绕着它转。还有个细节：这个数，别报整的。
- **别报整的**：eBay 上 1050 万件能砍价的商品，标价是整百的，最后卖得便宜 5% 到 8%，不过卖得更快；整数像在说"我急着卖"，带零头的数像算过的。"那我挂 5000 的吉他……"——换成 4870，对方会觉得你做过功课，还价就不敢砍太狠。
- **对方先开口**：别顺着他的数砍，先想想自己心里的价，再报自己的。
- **攻略卡**：做过功课，就先开口；报个带零头的数；对方先开口，先想自己的目标价。
- **结尾**："你"抱着吉他摆摊："那我先开口：这把吉他 4870！"——"评论区说说：你砍价都是谁先开口？"

## 发布时

- 标题：「砍价时，谁先开口谁吃亏？」，话题带 #砍价 #谈判技巧 #闲置 #谈工资。
- 置顶评论："你砍价都是谁先开口？下次挂闲置、谈工资，试试先开口、报个带零头的数。"
- 勾选"AI 生成"。

## 怎么做出来的

流程、工具和踩过的坑见仓库根目录的 `做视频经验.md`。

- **旁白配音**：`源码/narrate_cosy.py`（CosyVoice 3 合成，FunASR 转写核对、逐字对时间）。
- **画面**：`frame(t)` 只依赖时间 t；`render.cjs` 用 Playwright 逐帧截图，交给 ffmpeg 编码。
  - 背景画在 216×384 的像素缓冲上、放大 5 倍；小怪按 15 倍画，和背景的像素对齐。
  - `props.js`：夜市的旧货摊（彩灯、遮阳棚、挂着的旧货、逛摊的人、烤串摊的烟）、木吉他、会说话的价签、傍晚的海（锚和小船）、二手交易 App 的商品页、晚上的家。
  - `scenes1~3.js`：各个场景；封面在 `scenes1.js` 的 `coverArt`。
- **声音**：`源码/audio.py` 用 numpy 合成：盖章、价格条的滑音、价签弹出、柱子变短的滑音、手机"叮"、锚"咚"地砸下来、"叮"；夜市、会议室、海浪、办公室、晚上的家的环境声。短促的音效都不压旁白的字头（`工具/sfx_check.py` 查过）。
- **字体**：缝合像素字体 Fusion Pixel 12px、得意黑 Smiley Sans，均为 SIL OFL。构建时从 npm 下载并校验 sha256，不放进仓库。

## 重新生成

配音已经在 `源码/voice_cv3/` 里，不用再合成：

```bash
cd 源码
pip install numpy scipy
mkdir -p out && NODE_PATH=$(npm root -g) ./build.sh > out/build.log 2>&1   # 输出 out/砍价时谁先开口谁吃亏.mp4 和 out/旁白文案.txt
```

预览某几个时间点的单帧：

```bash
NODE_PATH=$(npm root -g) node render.cjs preview 1,20,45 out/preview
```
