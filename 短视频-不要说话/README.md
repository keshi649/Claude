# MV《不要说话》

> 你有没有喜欢过一个人，从来没说出口？

一支 4 分 41 秒的横屏动画 MV，配陈奕迅《不要说话》整首（作词、作曲：小柯，编曲：Mac Chew）。故事、角色、场景都是原创的，**整支片子像用一支黑铅笔在纸上画出来的一出"沉默舞台剧"**——这个画风来自歌词"用一支黑色的铅笔，画一出沉默舞台剧"。画面全部由代码逐帧画出来。

**故事**：海边一座小剧场。

- **她**是剧场里管灯光的女孩，耳朵上总架着一支黑铅笔。**他**是默剧演员，穿条纹衫，台上从不说话。她也从不说话。
- **第一段主歌**：夜里，她坐在栈桥尽头画海。心飘走了，飘到路灯下——女主演正把一封信递给他，说喜欢他。她不知道躲到哪里，就用铅笔的橡皮把自己擦掉了，只剩一支黑铅笔掉在桥面上。
- **主歌 B**：白天排练，他在台上演"看不见的墙"，她在灯光室的玻璃后面不知不觉把手也贴了上去；她从追光灯的瞄准圈里看他；速写本里画的全是他。每天清晨，她冲一杯咖啡，悄悄放在台口他站的那个"X"上，在杯套上画一个小月亮。
- **第一遍副歌**：黑铅笔在纸上一拉，一座纸舞台立了起来。演出的晚上，她推上推子，追光落在他身上，光像两只手臂把他抱住；她躲在角落哼歌，沙哑的音符飞过观众席绕着他转，他听不见。他按住胸口，她把手指放在嘴唇上。
- **第二段**：秋雨、冬天的演出、换了一个又一个季节。春天的清晨，她在杯套上写下"我喜欢你"，又用橡皮擦掉了。
- **第二遍副歌**：夜里，她在桌上用纸板搭了一个小剧场，台灯一照，两个纸人抱在一起，墙上的影子也抱在一起；她的歌变成纸鸟，飞过海，飞进剧场。
- **间奏**：书页往回翻——"那天晚上，我走得太早了。"她没看见的后半段：他把信推了回去，举起那杯画着月亮的咖啡；他在栈桥尽头捡起了她的黑铅笔；每天清晨他都躲在最后一排看她；化妆间的墙上钉满了她的杯套。他用她的铅笔斜着轻轻涂过那张被擦掉的杯套，**被擦掉的字压出的凹痕涂不上颜色，"我喜欢你"一点点白了出来**。
- **第三遍副歌**：最后一场散了，他拿着她的铅笔走上空舞台，在空中画出她画过的那片海，朝灯光室比了个"开灯"。追光亮了，他把光抱住，用默剧把她做过的事演了一遍；最后捂住嘴摇摇头——"请原谅我，不会说话"——举起那张杯套。翻过来，背面是他写的"我也是"。
- **最后一遍副歌**：她跑下来，接过铅笔，在他那面"看不见的墙"上画了一扇门。两个人在追光里抱住；坐在台边一起哼歌，音符飞出天窗变成星星；回到开头的栈桥尽头，两杯咖啡，她想开口，他把手指轻轻放在她嘴唇上——"爱是用心吗，不要说话"。
- **尾声**：镜头拉远，原来这是速写本里的一页。两只手握着同一支铅笔，在月光的路上画了一颗心。本子合上，最后一句："你没说出口的那句话，是什么？"

歌词在画面下方，像用铅笔写字：整句先淡淡地起稿，唱到哪个字，哪个字就被描深；暗的画面上，字底下会被橡皮擦出一道浅浅的底，保证看得清。

## 怎么做出来的

- **歌曲分析**
  - `源码/analyze.py`：Demucs 分出人声和伴奏；在伴奏的 onset 包络上网格搜索恒定速度和相位，得到 67 BPM（4/4 拍，一小节 3.582 秒，第 0 小节的强拍在歌曲 0.840 秒），全曲各段的相位偏差都在 ±12 毫秒以内；哪一拍是强拍，看和弦变化（偶数个半小节处变化大）和低频鼓点。
  - `源码/align.py`：歌词行从用户发来的音频里那条歌词滚动的视频轨读出来；逐字时间用 torchaudio 的 MMS 强制对齐（汉字转成不带声调的拼音）：每段整段对齐一次，每句再放宽 0.5、0.8、1.1 秒各对齐一次，每个字取中位数；副歌唱了四遍，同一句各遍的字按节奏型核对，偏得多的换成中位数。结果写进 `lyrics.js`。
- **画面**：`frame(T)` 只依赖时间，`render.cjs` 用 Playwright 逐帧截图交给 ffmpeg，4 路并行渲染。
  - `pencil.js`：铅笔画引擎。纸（暖白底、纤维、纸的颗粒）；石墨线（沿弧长抖动、两头收尖、压力有轻重、叠两遍，像手画）；排线贴图（每种疏密三套，可以无缝平铺）；"上调子"＝先揉一层软灰再顺着方向排线；用纸色"擦亮"做高光（月亮、月光的路、星星）；光（追光、灯泡、月光）用 screen 叠暖色或冷色——**整支片子只有光有颜色**：暖的是追光、咖啡、灯，冷的是月光。所有线条每 4 帧换一套抖动（三套循环），像手绘动画"线在呼吸"。
  - `figures.js`：三个人物的二维骨骼（髋、躯干、头，胳膊、腿两节，手腕能弯），按姿势表摆动作，走路和跑步按相位生成；她的开衫和 A 字裙会跟着坐姿、蹲姿变形；正面半身像（贴玻璃的手、"嘘"、捂嘴）。
  - `props.js`：黑铅笔（削过的木头、星星贴纸）、速写本、纸心、带杯套和小涂鸦的咖啡杯、对话泡泡、信、哼出来的沙哑音符；她和他的侧脸特写。
  - `world.js`、`world2.js`：海边（夜空、月亮、海、月光的路、栈桥、剧场外墙、路灯、灯塔）；剧场里（舞台、幕布、灯光室、调光台、追光灯和光柱、守夜灯、剖面图）。
  - `scenes1~8.js`：71 个镜头，按小节和逐字时间排好；`main.js`：镜头表、转场（翻页、橡皮擦、揉开、倒带、黑场）、逐字描深的歌词、水印、封面。
  - `test_fig.html` + `test_fig.js`：人物测试页（`PAGE=test_fig.html node render.cjs preview 0 out/fig`）。
- **声音**：`源码/mix.py`。原曲剪掉开头 1 秒的数字静音原样使用；两句画外音（`narrate_cosy.py`，CosyVoice 3 + FunASR 核对）；numpy 合成的音效（铅笔、橡皮、翻页、纸、木门、追光、掌声、雨、海浪……）按画面里登记的动作时刻放，唱的时候让开，每 0.5 秒不许比歌响；成片 ⟨LUFS⟩ LUFS，真峰值 ⟨TP⟩ dBTP。
- **字体**（都是 SIL OFL）：小赖字体 Xiaolai SC（歌词和画面上的字，像铅笔写的）、龙藏体 Long Cang（他写的"我也是"）。构建时从 npm 下载并校验 sha256，不放进仓库。

## 重新生成

歌曲音频不放进仓库。把整首歌（4:45.6，开头有 1.1 秒静音）转成 `源码/audio/song.wav`，并用 Demucs 分出人声（混音时音效要躲开人声）：

```bash
cd 源码
mkdir -p audio && ffmpeg -i 你的音频.m4a -vn -ac 2 -ar 44100 audio/song.wav
pip install numpy scipy soundfile pyloudnorm demucs
python3 -m demucs --two-stems=vocals -n htdemucs -o out/demucs audio/song.wav
NODE_PATH=$(npm root -g) ./build.sh      # 输出 out/不要说话.mp4，超过 30 MB 再切成 out/不要说话_1.mp4 …
```

`lyrics.js`、`timing.js` 和 `voice_cv3/` 已经在仓库里。换了别的音源（开头的静音长度不一样）才需要重跑分析和对齐（要 librosa、torchaudio、pypinyin）：

```bash
python3 analyze.py     # 节拍、强拍、每小节的人声和伴奏响度
python3 align.py       # 逐字对齐歌词 → lyrics.js（第一次会下载 MMS 对齐模型，约 1.2 GB）
```

画外音要重新合成的话，先在后台跑 `bash ../../工具/setup_tts.sh`，再：

```bash
/home/user/tts/venv/bin/python narrate_cosy.py /home/user/tts/CosyVoice /home/user/tts/models/CV3-RL
```

预览某几个时间点的单帧（成片时间，秒）：

```bash
NODE_PATH=$(npm root -g) node render.cjs preview 0,5.5,85,190 out/preview
```
