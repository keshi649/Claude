- **规格**：横屏 1920×1080，30fps，4 分 41 秒（281.1 秒）（整首歌 4:45.6，剪掉开头 1.0 秒的数字静音；歌尾自然淡出，最后 2.5 秒是片尾卡）

- **字幕**：歌词在下方居中，小赖字体 56px，像铅笔写的。整句先用很淡的线"起稿"，唱到哪个字，哪个字就被描深（0.14 秒从左往右写出来，轻轻一跳）；唱完揉淡、往上飘走。暗的画面上，字底下被"橡皮"擦出一道浅底（背景越暗擦得越亮），所以任何画面上都看得清。

## 歌曲是怎么分析的

- **节拍**：`源码/analyze.py`。在伴奏的 onset 包络上网格搜索恒定速度和相位：134 BPM 的拍子网格，各段相位偏差 ≤ 12 毫秒，全曲不漂移。按和弦变化看，偶数个"半小节"处变化大（0.26 对 0.12），所以是 **67 BPM、4/4 拍，一小节 3.582 秒，第 0 小节的强拍在歌曲 0.840 秒**。
- **歌词**：用户发来的 m4a 里有一条视频轨，是播放器的歌词滚动画面。按 10fps 抽帧，找出每一帧里对比度最高的一行（高亮的那句），连续不变 0.8 秒以上的算一句，裁出来拼成图，读出全部歌词和每句亮起的时刻。那份歌词少了最后一句"爱是用心吗 不要说话"，用 FunASR 转写人声轨确认了它在 248 秒左右。
- **逐字时间**：`源码/align.py`，Demucs 人声轨 + torchaudio 的 MMS 强制对齐（汉字转成不带声调的拼音）。每段整段对齐一次，每句再放宽 0.5、0.8、1.1 秒各对齐一次，四次取中位数；副歌唱了四遍、主歌 B 唱了两遍，同一句的各遍按节奏型核对，偏离中位数 0.35 秒以上的字换掉（第二遍副歌"画一出沉默舞台剧"第一次对到了上一句里，就是这样修好的）。

## 声音

- **原曲**：整首原样使用，只剪掉开头 1.0 秒的数字静音（歌曲第 1.1 秒才有声音），结尾 1.5 秒淡出（歌本身在这里已经淡到 −48 dB 以下）。整体降 6 dB（原曲是 −10.2 LUFS 的响母带）。
- **画外音**：两句，CosyVoice 3 合成的女声（语速 0.95，一点点混响），每句 −16.5 LUFS：
  - 开头"你有没有喜欢过一个人，从来没说出口？"：0.45 秒开始，前奏里念完（前奏这时很轻，再压低 3 dB）
  - 结尾"你没说出口的那句话，是什么？"：4:35.3 开始，歌已经淡下去了；念完 3 秒内结束
  - 两句都转写回来和原稿 0 处出入；"没、说、那"三个多音字看过音高：没 méi（上升）、说 shuō（高平）、那 nà（高降）
- **音效和环境声**：numpy 合成（`源码/mix.py`），没有另加配乐。画面里每个动作在镜头函数里用 `sfx()` 登记时刻，`render.cjs sfx` 导出给混音用，画面节奏改了声音自动跟着走。
  - 铅笔在纸上的沙沙声（画海、写"我喜欢你"、在空中画）、橡皮擦、斜着涂的铅笔声、翻页、合上本子、纸心掉下去、铅笔掉在木板上
  - 海浪、清晨的海鸥、雨、空剧场的低嗡、化妆镜灯泡的电流声
  - 门、脚步、纸杯放在地板上、推子、追光亮起的"咔哒"和嗡声、幕布、掌声、纸鸟扑翅膀、图钉
  - 唱的时候整体压低约 8 dB；再按每 0.5 秒一块"封顶"：不许比这一块的歌响（歌 −7 dB 以下），画外音念的时候还要在画外音 −13 dB 以下；短促的音效落在画外音字头 0.12 秒以内的，挪到字头之前
- **响度**：成片 ⟨LUFS⟩ LUFS，真峰值 ⟨TP⟩ dBTP（4 倍过采样找峰值，限幅到 −1.0 dBTP）。
