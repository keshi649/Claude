# 短视频《从你家往下挖，挖穿地球会到哪？》

> 北京往下挖，是阿根廷。

"如果……会怎样"系列第 1 集（用户挑的方向），约 ⟨DUR⟩ 的竖屏像素风科普短视频：

- **旁白有配音**：CosyVoice 3 合成的女声，字幕按配音的逐字时间出现
- 角色台词出在游戏对话框里，不配音，只有打字音
- 有音效和环境声，**没有配乐**
- 角色用用户给的 12×8 像素小怪："你"戴红领巾，跳之前换上银色的防火服；美国小孩是戴棒球帽的蓝色同款小怪；奶牛是本片画的
- 照用户对画面的要求（`做视频经验.md` 第二十节），每个画面多铺几层、每层都有在动的东西，开头埋了伏笔（洞里冒出的奶牛，后面在阿根廷的草原上回收）

片子讲的是：

- **开头**：黄昏的院子里，"你"在挖洞："从你家挖穿地球，会到哪？"——"当然是美国！"第 ⟨stamp⟩ 秒盖章"阿根廷"，洞里冒出一头奶牛。
- **为什么**：美国小孩以为能挖到中国，结果是印度洋。北半球挖下去，只能从南半球出来：北京、上海、广州都是阿根廷，成都是太平洋。
- **真跳下去会怎样**：
  - 人类挖过最深的洞才 12 公里，不到地球半径的 0.2%；
  - 地心约 6000 度，跟太阳表面差不多；
  - 就算真有这么个洞，掉到对面要 38 分钟（你家是傍晚，那边正是清晨）；
  - 没抓住洞口又会掉回去，洞里要是真空，就在两边来回掉，永远停不下来。
- **你家对面是哪**：纬度北纬换成南纬；经度用 180 减，东经换成西经；再去地图上搜一下。
- **结尾**："那我在阿根廷往下挖，能挖回家吗？"——"能，不过得先去阿根廷。评论区说说，你家对面是陆地还是海？"

## 怎么做出来的

流程、工具和踩过的坑见仓库根目录的 `做视频经验.md`。

- **旁白配音**：`源码/narrate_cosy.py`（CosyVoice 3 合成，FunASR 转写核对、逐字对时间）。
- **画面**：`frame(t)` 只依赖时间 t；`render.cjs` 用 Playwright 逐帧截图，交给 ffmpeg 编码。
  - 背景画在 216×384 的像素缓冲上、放大 5 倍；小怪按 10 倍画，和背景的像素对齐。
  - `props.js`：黄昏的院子（云、鸟、亮窗的楼、电视塔、树、晾衣绳、草）、洞和铲子、太空和地球的剖面、机场和翻牌子的出发屏、深洞、钻井、隧道、阿根廷清晨的草原。
  - `sprites.js`：像素小怪，这一支加了防火服和奶牛。
  - `scenes1~3.js`：各个场景。
- **声音**：`源码/audio.py` 用 numpy 合成：铲土、盖章、奶牛"哞"、扑通、翻牌子、地底的轰隆、钻井、岩浆、越来越尖的风声；黄昏、太空、机场、清晨的草原、夜里的蛐蛐。短促的音效都不压旁白的字头（`工具/sfx_check.py` 查过）。
- **字体**：缝合像素字体 Fusion Pixel 12px、得意黑 Smiley Sans，均为 SIL OFL。构建时从 npm 下载并校验 sha256，不放进仓库。

## 重新生成

配音已经在 `源码/voice_cv3/` 里，不用再合成：

```bash
cd 源码
pip install numpy scipy
mkdir -p out && NODE_PATH=$(npm root -g) ./build.sh > out/build.log 2>&1   # 输出 out/挖穿地球会到哪.mp4 和 out/旁白文案.txt
```

预览某几个时间点的单帧：

```bash
NODE_PATH=$(npm root -g) node render.cjs preview 1,20,45 out/preview
```
