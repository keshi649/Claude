# MV《后来》像素版

> 她是 1P，他是 2P。后来，存档无法改写。

一支 5 分 15 秒的横屏像素动画 MV，配用户发来的刘若英《后来》。故事、镜头都是新做的（和上一支《后来》MV 不一样），画面全部由代码逐帧画出来；两个主角是甜菜之前视频里的 12×8 像素小怪。没有配音、没有音效，只有原曲，成片和歌一样长。

**故事**：很多年以后，她搬家时翻出一台旧掌机，存档里是十七岁的夏天——栀子花落在她的蓝色百褶裙上，他轻声说"爱你"，两台掌机用一根连接线连着。后来两个人都太倔强，连接线断了。她钻进游戏一路跑到那棵栀子花树下，想读档回到那个路口改一次选择，"存档无法改写"。天亮了，她回到母校，掌机也没电了。可那年夏天，确实有一个男孩爱着那个女孩。

- **开头（前奏 12 秒）**：曲速星空，1.35 秒在第一个强音上刹住 → 镜头从星空坠向城市里一扇亮着的窗 → 屋里她吹掉旧掌机上的灰、按下开关 → 掌机特写，心形标志落地 → 镜头推进屏幕，液晶正好铺满画面 → 游戏里栀子花树下两个小怪看星星，2P 闪烁、碎成上千个像素，飞上天拼成片名"后""来"（各踩在唱的那个字上）。
- **回忆**在游戏里：亮色的夏天，像素粗，顶上有 1P / 2P 状态栏（"2P 等待加入""2P 已加入！""2P 已断开连接"，心会填满、会裂开）。**现在**是冷色的城市夜，像素细。
- 一路贯穿：掌机和存档、连接线、双棒冰棍（一人一半 → 他递给空座位 → 她给了一个哭着的小孩）、栀子花、星星。
- 歌词按演唱逐字亮起；换镜头落在小节线或歌词开口前。

## 怎么做出来的

- **歌词和逐字时间**：和上一支《后来》（`短视频-后来/`）是同一个音源。先用那一支的 `kara.py` 把这次发来的视频重新量了一遍，475 个时刻一个不差、响度也一样，就直接复用那一支的 `timing.js`（Demucs 分人声 + MMS 强制对齐，副歌四遍互相核对过）。
- **节拍**：74.9 BPM，一小节 3.204 秒；前奏钢琴的强音（1.35、2.96、6.61、8.89、9.79、11.37 秒）给开头的特效踩点。
- **画面**：`frame(t)` 只依赖时间，`render.cjs` 用 Playwright 逐帧截图交给 ffmpeg，4 路并行。
  - `core.js`：时间轴、工具、像素缓冲（场景画在 80×70 到 480×270 的小画布上，再最近邻放大 4~24 倍）、像素图元、星空、银河、流星、萤火虫、雨雪、光晕层、1 位的像素字、液晶格子、马赛克、故障。
  - `sprites.js`：像素小怪（大号 24×16、小号 12×8；表情、手臂姿势、走路、坐、跳、凑近；蓝色百褶裙、呆毛、毛线帽、脸红、眼泪；碎成像素）、双棒冰棍、栀子花、心、横握的掌机（液晶 16:9）、连接线。
  - `world.js`：夜空、城市天际线、楼的立面、她的房间（搬家的纸箱）、栀子花树和花丛、山坡、长椅、路灯、夏天的草地和教学楼、叶子、花瓣。
  - `ui.js`：游戏界面：像素框、对话框、选项菜单、提示条、获得道具、1P / 2P 状态栏、电量、读取条。
  - `scenes1.js`~`scenes7.js`：镜头表里 62 个镜头，按歌的顺序（开机那一个里面先是屋里、再是掌机特写；间奏是一整条跑跳关卡）。
  - `main.js`：镜头表、转场（闪白、抖动溶解、马赛克、圆形开合、故障、地图逐行读出）、歌词、状态栏、水印、片尾字、封面。
- **声音**（`源码/mix.py`）：只有原曲，按线性增益从 −9.2 调到 −16 LUFS，不剪不挪。
- **字体**：缝合像素字体 Fusion Pixel 12px（SIL OFL），构建时下载并校验 sha256，不放进仓库。

## 重新生成

歌曲音频不放进仓库。把用户发来的抖音视频（1080×1440，315.5 秒）放到 `源码/audio/song.mp4`：

```bash
cd 源码
mkdir -p audio && cp 那个视频.mp4 audio/song.mp4
NODE_PATH=$(npm root -g) ./build.sh      # 输出 out/后来像素版.mp4；超过 30 MB 会自动切成 out/后来像素版_1.mp4 …
```

预览某几个时间点的单帧：

```bash
NODE_PATH=$(npm root -g) node render.cjs preview 1.4,9.7,13.5,73.5 out/pv
```
