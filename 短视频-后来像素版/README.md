# MV《后来》像素版（第二版）

> 一张撕成两半的照片，一朵干掉的栀子花。后来，我总算学会了如何去爱。

一支 5 分 15 秒的横屏像素动画 MV，配用户发来的刘若英《后来》。主角是用户给的 12×8 像素小怪（Claude 小怪兽）：她是 Claude 橙，他是青蓝色、头顶翘一撮毛。
没有配音、没有音效，只有原曲，成片和歌一样长。

**为什么有第二版**：第一版交付后，用户说"质量不行：别人做的画面每一帧的元素都很多、很丰富、很吸引人，开头一段时间的画面很多元，各种特效、各种埋点伏笔"，
又说"不要参考库里面的视频，我全部不满意"。第二版从故事、分镜到画法、代码全部重做，没有沿用库里任何一支视频（包括第一版）的东西；只留了歌的逐字时间（`源码/timing.json`，是对这首歌量出来的数据）。

**故事**（详见 `脚本.md`）：雨夜的城市，她一个人撑着透明伞，头上别着一朵干栀子花，桌上一张撕掉一半的照片。十七岁的夏天，栀子花落在蓝色百褶裙上，他轻声说爱你，把花戴在她头上；
仲夏夜的流星雨下，他在大月亮前吻了她。后来一场暴雨，黄伞被风卷走，照片撕成两半，两个人在两座城市的深夜里各自留着一半。她每年回母校的栀子树下站一会儿，
想发"你还好吗"又删掉，追到站台车门正好关上。天亮了，长椅上坐着新的一对十七岁；她把发夹留在树下，扔出纸飞机。原来那年夏天，真的有一个男孩爱着那个女孩。

- **开头**：0~9.7 秒十三个闪回，跟着钢琴一拍一个，全是后面会出现的镜头（伏笔），每个都像旧录像（取景框、REC、胶片日期戳，切进来有色差和闪光），换法各不相同；
  然后闪回变成小照片卷进漩涡、炸开，几千个像素拼出片名「后来」，正好踩在唱"后来"的那一下；字化成雨，一滴雨荡开进雨夜的城市。
- **每一帧都铺满**：远、中、近、前景几层，每层都有在动的东西（雨、霓虹、轻轨、路人、花瓣、萤火虫、烟花、光斑、光束），统一调色、泛光、暗角。
- **伏笔和回收**：发夹、半张照片（'09 7 17）、"今夜 流星雨"、会眨两下的星、"下一站：仲夏"、黄伞、一只耳机、17 路公交、纸鹤、冰棍……对照表在 `脚本.md`。

## 怎么做出来的

- **一套像素网格**：整片画在 480×270 的画布上（一个像素 = 成片里 4×4），出片时 ffmpeg 最近邻放大到 1920×1080，所以全片像素大小一致，没有半个像素。
- **逐帧只看时间**：`frame(t)` 只依赖 t，`render.cjs` 用无头 Chromium 画好一帧就把 480×270 的 PNG 交给 ffmpeg 存成无损 FFV1；4 路并行，整片 9464 帧约 3 分钟画完。
  - `core.js`：数学、噪声、颜色（暗部偏蓝紫、亮部偏暖）、像素图元（扫描线多边形、Bayer 抖动、抖动渐变）、台阶状光晕、字符画精灵、描边、像素字（缝合像素 12px，Scale2x 放大做标题）、3×5 小字。
  - `chars.js`：小怪（一格放大成 s×s，加顶光、暗边、体积抖动、眼睛高光、侧逆光、描边；裙子、发夹、翘毛、脸红、眼泪；身上滑落的雨珠和扫过的光）、猫、伞、栀子花、心。
  - `world.js`：天空、星星、银河、月亮、像素云、流星、雨和水花、水面倒影、树和叶团、草、花瓣、萤火虫、鸟、蝴蝶、光束、焦外光斑、烟花、灯笼、海面。
  - `city.js`：城市楼群（按噪声成片亮窗、玻璃楼、屋顶水箱天线红灯、霓虹招牌、雾）、近处细画的楼面（阳台、盆栽、晾衣服、空调、管子）、楼间小灯串。
  - `shots1.js`~`shots6.js`：八十多个镜头，按歌的顺序（前奏、副歌一、主歌一和现在、主歌二和他、副歌二和间奏、副歌三四和尾声）。
  - `fx.js`：调色、泛光、暗角、色差、故障，和十几种转场（闪白、像素溶解、马赛克、圆形开合、水滴涟漪、台阶擦、甩镜头、碎块、百叶、胶片烧、倒带）。
  - `main.js`：镜头表、歌词（逐字亮起、跳一下）、水印、片尾字、封面。
- **声音**（`源码/mix.py`）：只有原曲，线性增益从 −9.2 调到 −16 LUFS，不剪不挪。
- **字体**：缝合像素字体 Fusion Pixel 12px（SIL OFL），构建时下载并校验 sha256，不放进仓库。

## 重新生成

歌曲音频不放进仓库。把用户发来的抖音视频（1080×1440，315.5 秒）放到 `源码/audio/song.mp4`：

```bash
cd 短视频-后来像素版/源码
NODE_PATH=$(npm root -g) ./build.sh        # 画面 → 放大编码 → 配原曲 → 超过 30 MB 切段，产物在 out/
```

看效果：`node render.cjs sheet 输出.png 列数 倍数 t1 t2 …`（几个时刻拼一张图）、`node render.cjs crop 输出.png t x y w h 倍数`（放大看局部）。
