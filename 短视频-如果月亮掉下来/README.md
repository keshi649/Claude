# 短视频《如果月亮掉下来》（"如果……会怎样"系列第 1 集）

> 以后的月亮，只会越来越远。

新系列"如果……会怎样"的第一集，约 1 分 19 秒 的竖屏短视频。用户先看了三种画风的样张（`样张/`：电影感、水墨、极简海报），选了**电影感**：三维着色器逐帧算光，太空镜头用 NASA 的真实地球贴图。

- **旁白有配音**：CosyVoice 3 合成的女声，字幕按配音的逐字时间出现
- 开头的常见答案"它会越变越大？"在屏幕上逐字打出、不配音，旁白一说"不"就被红线划掉
- 有音效和环境声，**没有配乐**

片子讲的是：

- **开头**：黄昏的海上升起一个巨大的月亮。"如果月亮掉下来"——"它会越变越大？"——"不。你最先发现的，是海。"
- **先变的是海**：距离近一半，月亮看上去只大一倍，拉海水的力气却是 8 倍（潮汐力按距离的三次方变）；海边的街道一天要被淹两回。
- **被扯碎**：它一圈圈往里绕，可永远砸不到你头上——离地球大约 1.8 万公里（洛希极限），地球拉它近的一面比远的一面狠得多，月亮会被活活扯碎；《流浪地球》里差点撕碎地球的就是这条线。
- **地球的光环**：碎块铺成一圈，地球有了光环；地上抬头，一道光环横跨夜空，夜夜都是流星雨。
- **火卫一**：这不全是想象，火星的卫星火卫一正在往里绕，几千万年后会碎成火星的光环（Black & Mittal 2015）。
- **真实的月亮**：它正在离开，每年远 3.8 厘米，跟你指甲长得差不多快。结尾一张三条小结的收藏卡，"要月亮，还是要光环？评论区站个队。"

## 发布时

- 标题：「如果月亮掉下来，你最先发现的不是它变大」，话题带 #月亮 #洛希极限 #流浪地球 #宇宙。
- 置顶评论：「要月亮，还是要光环？」

- 勾选"AI 生成"。

## 怎么做出来的

流程、工具和踩过的坑见仓库根目录的 `做视频经验.md`（这种电影感着色器的做法见第二十二节）。

- **画面**：`源码/js/`。每个镜头一个 WebGL2 全屏着色器，在无头 Chromium（SwiftShader 软件渲染）里逐帧算：
  - `shots/sea.js`：海、巨大的月亮（程序生成的月海和环形山）、大气消光、长曝光的海面倒影、前景礁石和人
  - `shots/city.js`：夜里的海边城市、潮水、快进一天两次漫过海堤
  - `shots/space.js`：地球（NASA 贴图、夜光、云、海面反光、大气）、月亮沿螺旋绕近、洛希极限的虚线圈、被拉长和裂开、碎块（点精灵，按开普勒速度差拉开成环）、光环和它投在地球上的影子
  - `shots/nightring.js`：地上看光环（按北纬 30° 观测者算的真实几何）和流星雨
  - `shots/mars.js`：火星、火卫一、火星的光环
  - `shots/endcard.js`：尺子和指甲、收藏卡、站队按钮、片尾卡
  - `main.js`：镜头表和转场；`overlay.js`：字幕（按配音的逐字时间）、标注、出处、水印；`gl.js`：渲染、辉光、调色、颗粒
- **旁白配音**：`源码/narrate_cosy.py`（CosyVoice 3 合成，FunASR 转写核对、逐字对时间）。
- **声音**：`源码/audio.py` 用 numpy 合成海、城市、太空低鸣、夜风、碎裂、闷响、流星、钟声等；短促的音效都放在旁白的停顿里（`工具/sfx_check.py` 查过）。
- **字体**：思源宋体 Noto Serif SC、Cormorant Garamond（SIL OFL），npm 包。
- **地球贴图**：NASA Blue Marble、夜光、海洋、云（公有领域），由 three-globe 2.45.6 的 npm 包分发；构建时下载并校验 sha256，不放进仓库。

## 重新生成

配音已经在 `源码/voice_cv3/` 里，不用再合成：

```bash
cd 源码
pip install numpy scipy
./build.sh > out/build.log 2>&1      # 输出 out/如果月亮掉下来.mp4、out/旁白文案.txt、out/封面.jpg
```

预览某几个时刻的单帧（可以缩小出图）：

```bash
node render.js stills 1,4.6,20,33 out/pv --scale 0.5
```
