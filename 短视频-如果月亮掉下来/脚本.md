# 《如果月亮掉下来》短视频脚本（"如果……会怎样"系列第 1 集）

- **规格**：竖屏 1080×1920，30fps，时长约 ⟨DUR⟩
- **形式**：
  - **旁白有配音**：CosyVoice 3 合成的女声，字幕按配音的逐字时间一段段出现；旁白全文见 `旁白文案.txt`
  - 开头替观众说出的常见答案（"它会越变越大？"）在屏幕上逐字打出来，不配音，旁白一说"不"就被一道红线划掉
  - 有音效和环境声，**没有配乐**
- **为什么是这个系列**：前几支讲解类和体验类之后，用户在几个系列方向里选了"如果……会怎样"，并要"艺术感、高级感"。先出了三种画风的样张（电影感、水墨、极简海报，见 `样张/`），用户选了**电影感**。
- **风格**：电影感。三维着色器逐帧算光：低处的月亮因为大气消光发橙，天边有地影和粉色的"金星带"，海面是长曝光的样子；太空镜头用 NASA 的真实地球贴图（白天、夜光、海洋、云），光环按地球赤道面的真实几何算，连地球投在光环上的影子都是算出来的。整片暖色高光、偏青的暗部，加辉光、暗角和细颗粒。字用思源宋体。
- **角色**：这一集没有像素小怪：主角是月亮，"你"是开头和结尾礁石上那个看月亮的人、山脊上指着光环的人。
- **声音**：黄昏的海、贴着海面的浪、夜里海边城市的车流和堤下的水拍、太空里很低的嗡鸣、山上的夜风和虫鸣；音效有浪拍过来、条形图弹出的"嗒"、快进时密集的钟声、两次漫过海堤的涌水、越来越响的低频轰鸣、岩石裂开的咔嚓、月亮碎掉的闷响和碎石、光环铺开的细碎闪光、流星的"嘶"、收藏卡的"叮"。成片约 −16 LUFS。

## 开头 3 秒是怎么设计的

| 时间 | 画面 | 旁白 / 屏幕上的字 | 为什么 |
|---|---|---|---|
| 0.0s（第一帧） | 黄昏的海上升起一个巨大的月亮，礁石上站着一个人，城市的灯在左边海岸；镜头慢慢推近。大字「WHAT IF / 如果月亮掉下来 / 第一集」 | 如果月亮掉下来， | 第一帧就有大字问题和正在动的画面 |
| ⟨d1⟩ | 片名让位，屏幕上逐字打出「它会越变越大？」 | （不配音） | 替观众说出最常见的答案 |
| ⟨h2⟩ | 一道红线把「它会越变越大？」划掉 | 不。你最先发现的， | 当场推翻（不出字幕，红线代替盖章） |
| 4.6s | **切**：贴着海面的浪，侧倾的镜头，月亮在左上；大字「是海。」 | 是海。 | 抛出线索：为什么是海？后面马上揭晓 |

- 前 20 秒切了 4 次镜头：黄昏的海 → 浪（4.6s）→ 海边城市（8.8s）→ 推近到海堤、快进一天（14.0s）→ 太空（17.2s）。
- 前 20 秒的线索："它永远砸不到你头上"（0:20）——为什么砸不到，要看到后面的洛希极限才知道。

## 关于事实与出处

| 片中的说法 | 依据 | 说明 |
|---|---|---|
| 距离近一半，看上去大一倍，拉海水的力气是 8 倍 | 潮汐力与距离的三次方成反比，视直径与距离成反比（教科书物理） | 画面标「示意」。"一天被淹两回"是说半日潮一天涨两次，海边的街道被淹是推演 |
| 离地球大约 1.8 万公里会被扯碎 | 地月系统的洛希极限：流体情形 18,381 km，刚体情形 9,492 km（从地心算）；现在的地月平均距离 384,399 km，约是流体洛希极限的 21 倍 | 片中取常用的流体值，"不到现在的二十分之一"；画面出处里两个值都写了。真实的月亮介于两者之间 |
| 碎块铺成一圈光环 | 卫星在洛希极限以内被潮汐撕开、碎块沿轨道散成环，是行星环成因的标准解释之一 | 片中的"一圈圈往里绕"是假设的情景：真实的月亮在远离地球。散开的过程按开普勒速度差算（内圈快、外圈慢），时间大大加快了 |
| 《流浪地球》里差点撕碎地球的就是它 | 电影里地球掠过木星时差点进入木星的洛希极限 | 只提片名，没用电影里的任何画面 |
| 火卫一正在往里绕，几千万年后碎成火星的光环 | Black & Mittal 2015, *Nature Geoscience*（DOI 10.1038/ngeo2583）：火卫一预计在 2000 万～4000 万年后解体，形成火星环 | 片中只说"几千万年后"，不念具体的数（关键数字只用三组）。火卫一在画面里放大了，标「示意」 |
| 月亮每年远 3.8 厘米 | 阿波罗登月留下的反射镜做的激光测距（NASA） | |
| 跟指甲长得差不多快 | 指甲平均每月长 3.47 毫米（Yaemsiri 等 2010，22 名美国年轻人），一年约 4.2 厘米 | "差不多"是常见的通俗比较；画面上写"一年约长 4 厘米" |

- 点名的研究 / 出处：洛希极限的数值、Black & Mittal 2015、阿波罗激光测距（指甲的出处只在画面上）——3 项。
- 外国人名、地名：洛希（Roche）1 个。
- 关键数字：8 倍（配"大一倍"的比较）、1.8 万公里（配"二十分之一"）、3.8 厘米（配指甲）——3 组。

## 旁白配音

- CosyVoice 3（Fun-CosyVoice3-0.5B-2512 的 RL 版）零样本合成女声，语速 1.1 倍；FunASR 把每句转写回文字、按拼音和原稿比，再逐字对时间（`源码/narrate_cosy.py`）。
- 念法和字幕不一样的：数字写成汉字（八倍、一点八万、三点八厘米），"指甲长得快"的"长"标成 zhǎng，句末的"越来越远"标成 yuǎn。
- 声调核对（`工具/tone_check.py`）：
  - w3 第一版的"远"音高只降到 220 Hz 就往上走，转写成了"越来越圆"；标 `[y][uǎn]` 重合成后降到 107 Hz 再升，转写回到"越来越远"。
  - w2 的"远"降到 172 Hz（三声），转写成"圆"是转写模型的问题，没重合成。
  - 看过、不用改的：长（zhǎng，降到 150 Hz 低平）、差（chà，差点：升到 362 后往下掉）、铺（pū，高平）、落（luò，降）、横（héng，先低后升）、绕（rào，降）。
- 转写里的同音字不算错：它 / 他、洛希 / 洛溪、火卫一 / 火卫衣。

## 制作方式

- 画面：`源码/js/`，WebGL2 全屏着色器，无头 Chromium（SwiftShader 软件渲染）逐帧算。每个镜头一个着色器（海、城市、太空、夜空、火星、片尾），碎块是点精灵；辉光、ACES 色调映射、调色、暗角、颗粒在最后一遍合成。镜头表和转场在 `js/main.js`，时间全从 `timeline.js`（按配音生成）来。
- 声音：`源码/audio.py`，numpy 合成；和画面用同一套时刻（碎掉的时刻、潮水两次漫过海堤）。
- 地球贴图：NASA Blue Marble、夜光、海洋、云（公有领域），由 three-globe 2.45.6 的 npm 包分发，构建时下载并校验 sha256，不进仓库。
