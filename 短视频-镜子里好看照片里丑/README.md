# 短视频《为什么镜子里好看，照片里丑？》

> 你不是不上镜，你只是还没看惯别人眼里的自己。

一支约 1 分 33 秒的竖屏像素风科普短视频，不属于进化错配系列：

- **旁白有配音**：CosyVoice 3 合成的女声，字幕按配音的逐字时间出现
- 角色台词出在游戏对话框里，不配音，只有打字音
- 有音效和环境声，**没有配乐**
- 人物都是本片自己画的像素小人，没有用像素小怪

片子讲的是：

- **开头**："你"说出最常见的想法："镜子里才是真的我！"第 3.14 秒盖章"反了"。镜子里是左右翻转的**镜像版**，照片里才是别人每天看到的**原版**。
- **为什么镜像版更顺眼**：
  - 没有谁的脸是完全对称的。
  - 你每天照镜子，看了半辈子的是镜像版；别人看的是原版。
  - 大脑看得越熟越顺眼，这叫曝光效应。
- **实验**：研究者把每个人的照片洗成原版和镜像版两张。
  - 挑自己的照片，七成的人挑了镜像版。
  - 挑好朋友的照片，七成多挑了原版。
  - 所以照片里的你不是丑，是不熟。
- **两个帮凶**：
  - **定格**：镜子里的你一直在动，照片只抓一瞬间；看视频往往比看截图更好看。
  - **离太近**：30 厘米自拍，鼻子显宽三成左右；离到一米半就几乎不变形。
- **上镜攻略**：
  - 退远一点，用 2 倍镜头拍
  - 连拍几张，挑最自然的一张
  - 照片多看几眼，看熟了自然就顺眼

| 文件 | 说明 |
|---|---|
| `镜子里好看照片里丑.mp4` | 成片：1080×1920，30fps，H.264 + AAC，约 93 秒，9.3 MB（不用切分）。旁白有配音，对话框不配音，有音效和环境声，没有配乐；响度约 −16 LUFS |

## 怎么做出来的

- **旁白配音**：`源码/narrate_cosy.py`，做法和第六集一样。
  - CosyVoice 3（Fun-CosyVoice3-0.5B-2512 的 RL 版）零样本合成女声。
  - 每句用 FunASR 转写回来按拼音核对，读错就换随机种子重来。
  - 再用时间戳模型给每个字对上时间。
- **时间轴**：`源码/narration.py` 里有全部旁白和对话框台词，读配音的逐字时间排字幕，写进 `timeline.json` / `timeline.js`。
- **画面**：`frame(t)` 只依赖时间 t；`render.cjs` 用 Playwright 逐帧截图，交给 ffmpeg 编码。
  - `sprites.js`：本片的人物。
    - "你"的大脸（48×48 像素，七种表情，近拍时按透视把鼻子一带撑宽）。
    - 全身小人：头发偏分、右脸一颗痣、左边嘴角高、右边星星发卡。
    - 两个朋友。
    - 不翻转是原版，翻转是镜像版。
  - `props.js`：镜子、手机、相片、相机、闪光、胶片、各种背景和小图标。
  - `scenes1~3.js`：各个场景。
  - `core.js`、`main.js`：工具、字幕、对话框、转场、逐帧入口。
  - 关键的字都放在安全区里，字幕中心在 x=500。
- **声音**：`源码/audio.py` 用 numpy 合成。
  - 游戏音效：快门、闪光、镜子的闪亮声、翻转、放映机、定格、票数条上涨……
  - 很轻的环境声：洗手间、摄影棚、房间。
  - 混音：
    - 说话时音效压低约 8 dB。
    - 短促的音效不压在旁白字头上。
    - 成片约 −16 LUFS，做真峰值限幅。
- **旁白文案**：`源码/export.py` 从时间轴导出 `旁白文案.txt`。
- **字体**：缝合像素字体 Fusion Pixel 12px、得意黑 Smiley Sans，均为 SIL OFL。构建时从 npm 下载并校验 sha256，不放进仓库。

## 重新生成

配音已经在 `源码/voice_cv3/` 里，不用再合成：

```bash
cd 源码
pip install numpy scipy
mkdir -p out && NODE_PATH=$(npm root -g) ./build.sh > out/build.log 2>&1   # 输出 out/镜子里好看照片里丑.mp4 和 out/旁白文案.txt
```

改了旁白要重新合成那几句（环境怎么搭见 `narrate_cosy.py` 开头）：

```bash
venv/bin/python narrate_cosy.py CosyVoice目录 模型目录 s2 k3   # 只合成编号是 s2、k3 的两句
```

预览某几个时间点的单帧：

```bash
NODE_PATH=$(npm root -g) node render.cjs preview 2,20,90 out/preview
```
