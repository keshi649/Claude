# 短视频《为什么你总觉得别人在看你？》

> 别人没空看你，他们都在忙着担心：别人在看他们。

一支约 1 分 31 秒的竖屏像素风科普短视频，不属于进化错配系列：

- **旁白有配音**：CosyVoice 3 合成的女声，字幕按配音的逐字时间出现
- 角色台词出在游戏对话框里，不配音，只有打字音
- 有音效和环境声，**没有配乐**
- 角色用回用户给的 12×8 像素小怪："你"戴红领巾，其他人是换了颜色、帽子的同款小怪

片子讲的是：

- **开头**：食堂里奶茶洒了一身，"你"说出最常见的想法："完了，全场都看见了！"第 2.88 秒盖章"想多了"。
- **证据**：研究者让大学生穿上过气歌手的大头 T 恤，走进一屋子同学中间。穿的人猜一半的人会注意到，实际不到四分之一。
- **为什么**：你脑子里一直开着一盏聚光灯。
  - 你是自己人生的主角，头发翘了、说错一个字，自己看得清清楚楚。
  - 大脑从自己的感受出发去猜别人看到了多少，往回调总是调不够。
  - 台下每个人也有自己的聚光灯，照的都是他们自己。
- **第二次反转**：
  - 你以为紧张全写在脸上，台下其实看不太出来。
  - 演讲实验里，被告知"你紧张，别人看不太出来"的那组更放松，台下打分也比只听"别紧张"的更高。
  - 就算真出了糗，别人对你的评价也比你想的宽容得多。
- **社恐救急卡**：
  - 你以为的人数，砍掉一半
  - 上台前默念：紧张写不到脸上
  - 出糗了想想：你记得别人的糗吗？

## 怎么做出来的

- **旁白配音**：`源码/narrate_cosy.py`，做法和第六集一样。
  - CosyVoice 3（Fun-CosyVoice3-0.5B-2512 的 RL 版）零样本合成女声。
  - 每句用 FunASR 转写回来按拼音核对，读错就换随机种子重来。
  - 再用时间戳模型给每个字对上时间。
- **时间轴**：`源码/narration.py` 里有全部旁白和对话框台词，读配音的逐字时间排字幕，写进 `timeline.json` / `timeline.js`。
- **画面**：`frame(t)` 只依赖时间 t；`render.cjs` 用 Playwright 逐帧截图，交给 ffmpeg 编码。
  - `sprites.js`：像素小怪。本片给它加了低头看手机、大头 T 恤、奶茶渍、翘起来的头发、紧张时的汗和红脸、几种嘴型。
  - `props.js`：食堂、剧场、观众席、聚光灯、大眼睛、放大镜、讲台、便利贴、好感度血条等。
  - `scenes1~3.js`：各个场景。
  - `core.js`、`main.js`：工具、字幕、对话框、转场、逐帧入口。
  - 关键的字都放在安全区里，字幕中心在 x=500。
- **声音**：`源码/audio.py` 用 numpy 合成。
  - 游戏音效：奶茶泼出来、被盯着的低音、盖章、聚光灯开关、心跳、讲稿散落、获得情报……
  - 很轻的环境声：食堂、剧场、房间。
  - 混音：
    - 说话时音效压低约 8 dB。
    - 短促的音效不压在旁白字头上。
    - 成片约 −16 LUFS，做真峰值限幅。
- **旁白文案**：`源码/export.py` 从时间轴导出 `旁白文案.txt`。
- **字体**：缝合像素字体 Fusion Pixel 12px、得意黑 Smiley Sans，均为 SIL OFL。构建时从 npm 下载并校验 sha256，不放进仓库。

## 重新生成

配音已经在 `源码/voice_cv3/` 里，不用再合成：

```bash
cd 源码
pip install numpy scipy
mkdir -p out && NODE_PATH=$(npm root -g) ./build.sh > out/build.log 2>&1   # 输出 out/为什么总觉得别人在看你.mp4 和 out/旁白文案.txt
```

改了旁白要重新合成那几句（环境怎么搭见 `narrate_cosy.py` 开头）：

```bash
venv/bin/python narrate_cosy.py CosyVoice目录 模型目录 s2 n3   # 只合成编号是 s2、n3 的两句
```

预览某几个时间点的单帧：

```bash
NODE_PATH=$(npm root -g) node render.cjs preview 2,20,90 out/preview
```
