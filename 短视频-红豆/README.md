# MV《红豆》（像素版）

> 最后一张纸条写着：陪你看细水长流。

一支 3 分 52.6 秒的横屏像素动画 MV，配用户发来的方大同版《红豆》。主角是之前视频里的 Claude 像素小怪（他是原色，她是粉色、头上别一朵小白花），画面全部由代码逐帧画出来：每个镜头先画在一块小画布上，再最近邻放大 6~12 倍。只有原曲，不加配音、音效和片头片尾，成片和歌一样长。

第一版是自己画的绘本风人物（用户当时说"主角还是你自己画吧"）。交付后用户说"我不喜欢 用之前的 claude小怪兽 做一个像素风的"，于是整支重画成了现在的像素版；故事、分镜和歌词时间沿用。

**故事："还没清单"**：歌词几乎每句都是"还没……"。两只小怪把还没一起做的事写在纸条上，系上红线，插进一罐红豆里，然后一件件去做。

- **冬天**：她写下"一起看一场雪"。雪花一边落一边开成小花，路灯下一条红围巾围两个人，两个人中间一杯热茶。
- **牵手**：两只小怪从两边伸出手，手上系着的红线一碰就亮起来。黄昏的沙丘上牵手走，篝火边把一颗红豆举向银河。
- **时间在走**：沙漏里流的是红豆，雪人化了。站台上分别，红线从关上的车门缝里穿过去，跨过一片屋顶，一直连到夜车上的她。早晨她回来，扑上去抱住他。
- **在一起的日子**：红豆倒进锅里，他端锅烫了手，她拉着他的手吹。一碗汤两把勺子，分隔两地时同一个月亮，早晨碰一碰额头，山坡上她拉着风筝跑。
- **一切有尽头**：长椅上一年过去，两个人坐到了长椅两头。雨夜吵架，她转身走了，罐子摔碎在地上。他一颗颗捡，她回来握住他的手，红线重新系上。
- **很多年**：四处风景，溪边的日落。院子里种下的红豆长成了树，两只小怪慢慢变老，墙上的照片越来越多。
- **最后一张纸条**："陪你看细水长流"。两只老了的小怪再一次伸出手，还是那条溪、那块石头，红豆顺水漂走。窗外又下雪了，罐子里多了一张新纸条——"明年还一起看雪"。

开头 16 秒的前奏：一颗像素红豆一直落在画面中间，背后一拍左右换一个"未来"的世界（都是后面真的会出现的镜头），9 种像素风的转场，最后落进她举起的手里，片名出来。

## 怎么做出来的

- **歌词**：原视频是播放器的录屏，歌词面板里正在唱的那一行加粗。逐帧截出那一行，换行时截一张拼起来读出 40 句歌词和每句大致的时刻；Whisper 转写人声交叉核对。
- **节拍**（`源码/analyze.py`）：61.14 BPM（一小节 3.93 秒），第 0 小节强拍 1.72 秒。间奏和第三遍副歌鼓很少、网格不准，镜头都按歌词的逐字时间切。
- **逐字时间**（`源码/align.py`）：Demucs 分出人声，torchaudio 的 MMS 强制对齐，每句单独开窗。
  - 三句的窗口、六个字按人声音高和清辅音手修过。
  - `源码/spec_check.py` 把频谱和每个字的时刻画在一起，逐句核对。
  - 结果在 `源码/lyrics.js`。
- **画面**：`frame(t)` 只依赖时间，`render.cjs` 用 Playwright 逐帧截图交给 ffmpeg，4 路并行渲染（6979 帧约 5 分钟，每路每秒约 6 帧）。各文件做什么见 `脚本.md` 的"制作方式"。
- **声音**（`源码/mix.py`）：只有原曲，整体线性降 0.17 dB 到 −16 LUFS，不压缩、不剪不挪。
- **字体**：缝合像素字体 Fusion Pixel 12px（SIL OFL 1.1），构建时从 npm 上 @fontsource 的固定版本下载并校验 sha256，不放进仓库。

## 重新生成

歌曲音频不放进仓库。把用户发来的视频（1152×720，音轨 3:52.64）放到 `源码/audio/song.mp4`：

```bash
cd 源码
mkdir -p audio && cp 那个视频.mp4 audio/song.mp4
NODE_PATH=$(npm root -g) ./build.sh      # 输出 out/红豆.mp4；超过 30 MB 切成 out/红豆_1.mp4 …
```

`timing.js`、`lyrics.js` 已经在仓库里。换了音源才需要重新分析、对齐（要 demucs、librosa、torchaudio、pypinyin）：

```bash
ffmpeg -i audio/song.mp4 -vn -ac 2 -ar 44100 audio/song.wav
python3 analyze.py               # 分人声（第一次跑 Demucs）、节拍 → timing.js
python3 align.py                 # 逐字对齐 → lyrics.js（第一次会下载 MMS 对齐模型，约 1.2 GB）
python3 spec_check.py            # 每句的频谱和字的时刻 → out/spec_*.png
```

预览某几个时间点的单帧、看小怪和道具：

```bash
NODE_PATH=$(npm root -g) node render.cjs preview 0.5,14.6,33.4,128.3,197.0 out/preview
PAGE=test.html NODE_PATH=$(npm root -g) node render.cjs preview 0,1 out/ptest    # 像素小怪和道具的测试页
```
